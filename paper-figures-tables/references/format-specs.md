# 图表排版规格：三档

**先问投哪里，再定规格。** 顺序反了就要返工。

| 档 | 适用 | 谁说了算 |
|---|---|---|
| `apa7` | 英文期刊、多数国际会议 | APA 第 7 版第 7 章 |
| `zh` | 中文期刊 | GB/T 7713 与各刊稿约 |
| `custom` | 学位论文、特定期刊 | **目标文件本身** |

> APA 手册有版权，本文件不摘录原文，只写规格要点与自制样例。
> 具体措辞与边界情形，以手册第 7 章的官方样例表为准。

---

## 一、最容易错的一处：图题放上还是放下

| | 表题 | 图题 |
|---|---|---|
| **APA 7** | 在表**上方** | 在图上**方** |
| **中文期刊** | 在表**上方** | 在图**下方** |

中文期刊把图题放在图下方是通行做法（GB/T 7713），而 APA 放在上方。
**学生混投时最常犯的就是这个错**：图做好了，题注位置照英文期刊放，投中文刊被打回。

## 二、APA 7（`apa7`）

### 表

| 要素 | 规格 |
|---|---|
| 表号 | `Table 1`，**加粗**，左对齐，独占一行 |
| 表题 | 表号下一行，**斜体**，标题式大写（Title Case），左对齐 |
| 表号与表题之间 | 双倍行距 |
| 列标题 | 居中；首列（stub）可左对齐 |
| 分组表头 | 跨列合并，居中 |
| 边框 | **仅三条横线**：顶线、列标题下、底线。**无竖线、无内部横线** |
| 字体 | 与正文一致，或 8–14 pt 无衬线 |
| 表注 | 表下方，分三级（见下） |
| 长表跨页 | **重复表头行**（`tblHeader`），数据行不被分页切开（`cantSplit`） |

### 表注的三级结构

1. **通用注**：`Note.` 斜体起头，说明样本量、缩写、括号含义等。
2. **具体注**：上标小写字母 a、b、c，对应单元格里的标记。
3. **概率注**：`*p < .05. **p < .01. ***p < .001.`

顺序固定：通用注 → 具体注 → 概率注。

### 图

| 要素 | 规格 |
|---|---|
| 图号 | `Figure 1`，**加粗**，左对齐，在图**上方** |
| 图题 | 图号下一行，**斜体**，标题式大写，左对齐 |
| 图幅宽 | 整幅 ≤ 6.5 in；半幅 ≤ 3.25 in |
| 图注 | 图**下方**，`Note.` 斜体起头 |
| 坐标轴 | 只画左轴与下轴，不画上/右边框，无网格线 |

### 数字格式

| 情形 | 写法 |
|---|---|
| 不超过 1 的统计量（r、p、α、β、相关系数） | **省略前导零**：`.53`，不是 `0.53` |
| 均值、标准差、一般测量值 | **保留前导零**：`4.21`、`1.08` |
| 大于 1 的统计量（F、t、χ²） | 正常写，保留两位小数 |
| 空单元格 | 用破折号 `—`，并在通用注里说明 |

> 这一条在两档之间是**相反**的：中文期刊通常保留前导零。同一张表投不同刊要改。

## 三、中文期刊（`zh`）

| 要素 | 规格 |
|---|---|
| 表题 | `表 1 变量描述统计与相关系数`，**居中**，置于表上方 |
| 表题字体 | 黑体或宋体加粗，五号（10.5 pt） |
| 表内文字 | 宋体，小五（9 pt）或六号（7.5 pt，视刊物） |
| 边框 | 三线表：顶线与底线 **1.5 pt**，表头下线 **0.75 pt**，无竖线 |
| 图题 | `图 1 概念框架`，**居中**，置于图**下方** |
| 表注 | 表下方，小五，以 `注：` 起头（不用斜体） |
| 数字 | **保留前导零**：`0.53` |
| 显著性标记 | `*` `**` `***`，必须在注中说明对应水平 |

### 常见中文刊的额外要求

- **表随文走**：表格排在首次提及它的段落之后，不集中放文末（学位论文相反，常集中放）。
- **量与单位**：数值与单位之间空一格；百分号紧跟数字。
- **表格跨页**：跨页时重复表头，并在续表标「续表 1」。
- **图中文字**：不小于六号（7.5 pt），中文用宋体、西文用 Times New Roman。

## 四、学位论文与特定期刊（`custom`）

**必须先拿到目标文件。** 常见差异点：

| 可能不同的地方 | 常见取值 |
|---|---|
| 表题位置 | 有的要求表题在表格上方居中并加「表 1-1」章节编号 |
| 图题位置 | 多数在图下方；少数与 APA 一致放在上方 |
| 三线表线宽 | 1 pt / 1.5 pt / 2 pt 都见过 |
| 字号 | 五号、小五、六号 |
| 图表编号 | 连续编号（表 1、表 2）或分章编号（表 3-1） |
| 图表清单 | 是否需要单独一页「图表目录」 |
| 附录 | 大体量表是否移入附录 |

**做法**：向用户索取《学位论文格式规范》（PDF / Word / 截图均可），按五步建一个 profile。

1. **只抽与表、图有关的条款**，逐条对应到 `table` / `figure` 的字段；
2. 每个字段在 `source_clauses` 里**记条号或页码**——没有出处的取值，明天没人知道它哪来的；
3. 规范没写的字段保持默认，记进 `unspecified_defaults`，并在回复里列出请用户确认；
4. 有歧义的记 `pending_confirmation`（附「当前暂按」），工具做不到的记 `unsupported`，
   需人工的记 `manual_checks`——**这四类每次运行都会打到 stderr，不会被悄悄忽略**；
5. 存成独立 `.json`，`status` 改 `documented`。之后生成与检查共用这一份规则：

```json
{"profile": "C:/path/to/school.json", "number": "3-1", "columns": [...]}
```

```bash
python scripts/check_figure.py out.docx --profile C:/path/to/school.json
```

不要凭「一般学校都这样」去猜——各校差异比想象中大，猜错要整篇返工。
没有原文时用 `thesis-template`（status=template，每次运行都会警告「版式未经核对」），
它自带一份 `_todo` 清单告诉你还缺什么。

## 五、spec 里怎么写

```json
{
  "profile": "zh-journal",
  "style": {
    "size": 10.5,
    "rule_top": 12,
    "rule_header": 6,
    "rule_bottom": 12
  }
}
```

`profile` 可以是内置名（`apa7` / `zh-journal` / `thesis-template`）或 `.json` 路径；
不写时按 `format`（旧写法 `apa7` / `zh` / `custom`）取，`custom` = APA 底 + `style` 覆盖。
`style` 里的字段名写错会直接报错——静默忽略拼错的键是这类工具最坏的行为。

`rule_*` 的单位是 **1/8 pt**：`8` = 1 pt，`12` = 1.5 pt，`6` = 0.75 pt。

## 六、估计图与多面板图

### 估计图（点图 + 误差棒）

| 要素 | 规格 |
|---|---|
| 形态 | 默认**点图**；柱状图只用于 0 有意义的量（比例、频次、份额） |
| 点 | 实心圆，半径 2.9 pt；多系列用圆 / 方 / 三角 / 菱形区分，**不靠颜色** |
| 误差棒 | 线宽 1 pt，端帽半长 3.2 pt；必须在注中说明是 95% CI 还是 SE |
| 参考线 | 虚线 `3 2`、线宽 0.75 pt；标签放在绘图区上方，不压数据 |
| 行距 | 每类 20 pt；只有 2 类时改用表更省版面 |
| 轴 | 只画左轴与下轴；**刻度与刻度文字在轴的外侧** |
| 分类标签 | 右端对齐到轴、距轴 7 pt；超过 150 pt 自动折行 |
| 显著性标记 | 写在区间右端外 4 pt，`*` / `**` / `***`，注中说明对应水平 |

**区间怎么算**：`M ± t(.975, n−1) · SE`，不是 `M ± 1.96 · SE`。
n = 11 时 t = 2.23，用 1.96 会把区间画窄 12%；n = 30 时仍有 4% 的差。
`make_estimate_plot.py --data` 已按 t 分布实现（不完全 Beta 函数求分位数，
不依赖 scipy）。

**两条不要**：不要给点图加网格线；不要画单侧误差棒——读者会把它读成
「下界是 0」。

### 多面板图

| 要素 | 规格 |
|---|---|
| 标注 | `(a)` `(b)`，9 pt，每个面板左上角、面板上方 4 pt |
| 图题 | 整幅共用一条，写在 Word 里（APA 在上、中文刊在下），**不画进 SVG** |
| 面板间距 | 18 pt；缩放时**间距不缩** |
| 缩放 | 等比、所有面板同一系数；只缩不放 |
| 字号下限 | 缩放后仍须 ≥ 8 pt，否则把面板画窄或拆图 |
| 图注 | 整幅一条，说明各面板共同的误差棒、样本量、缩写 |

面板按正文提及顺序标注（先 (a) 后 (b)），每个面板承担一个论证任务。

## 七、交付前自检清单

自己生成的产物用 `check_figure.py`；**别人做好的表**用 `audit_table.py`——
两者共用 `scripts/table_checks.py` 里的同一批判据，不会出现「自己生成的说没问题、审别人的说有问题」。

机器能查的（`check_figure.py` 会做）：

- [ ] 图宽不超过 6.5 in
- [ ] 图内字号 8–14 pt，没有小于 8 pt 的
- [ ] 数据线线宽 ≥ 0.4 pt
- [ ] **文字没有超出画布**（超出后导出即缺字）
- [ ] 轴的刻度与刻度文字在轴的**外侧**
- [ ] 表格 left / right / insideV 边框为 nil
- [ ] 表头行有下边线
- [ ] **合并单元格的宽度与列网格一致**（跨列标题要真的跨过去）
- [ ] **每个单元格放得下它最长的单词**（否则 Word 从词中间断开，形同拼错）
- [ ] **表宽不超过版心**（横向页的版心是「页高 − 左右边距」，不是 6.5 in）
- [ ] **一格多行时各行都能放下自己的单词**（断词同样按行查）
- [ ] **表内每个数字都能在来源材料中找到**（`check_numbers.py`，抄录后跑）
- [ ] 单元格无残留空 run
- [ ] 前导零与所选档一致
- [ ] 同一列小数位一致
- [ ] **位图 DPI 达标**（无 DPI 元数据时报「无法判定」，不算通过）
- [ ] **位图无透明通道**（PNG color type 4/6 或 tRNS）
- [ ] **PDF 字体已嵌入、无 Type 3**
- [ ] **无替换字符、私用区字符、未分配码位**
- [ ] **声明的字体含所用字形**（中文字符最常出问题）
- [ ] 同一张图的 SVG / PDF / PNG 物理尺寸一致
- [ ] **PDF 页面上确实有东西**（空白页会一路通过字体与 DPI 检查）

机器查不了、必须人看的：

- [ ] 图题位置（上/下）与目标刊一致
- [ ] 表注三级齐全，概率注有对应的星号
- [ ] 空单元格用破折号，并在注里说明
- [ ] 图里没有表里已有的重复数字
- [ ] 缩写在首次出现处或表注中定义
- [ ] 表号、图号在正文中被逐一提及（不能有「孤儿图表」）
- [ ] 误差棒说清了是 95% CI 还是 SE
- [ ] 多面板的 (a)(b) 顺序与正文提及顺序一致
- [ ] 长表跨页后第二页仍有列名

## 列定义：写表格规格时每个字段是什么

`make_table.py` 的输入是一个 JSON。顶层字段：

| 字段 | 说明 |
|---|---|
| `number` | 表号，如 `"1"`（只写数字，不写「表」字） |
| `title` | 表题。APA 斜体、中文刊正体，脚本按 `format` 自动处理 |
| `format` | 旧写法：`apa7` / `zh` / `custom`。新写法用 `profile`（内置名或 .json 路径） |
| `profile` | 版式 profile。优先于 `format`；生成与检查共用同一份 |
| `panels` | 多面板表：`[{label, stub, columns:[{label, span}], rows:[{label, values}]}]`。各面板的 `span` 之和必须相等；用了它就不要顶层 `columns` |
| `columns` | 列定义数组，见下表 |
| `rows` | 数据行数组，每行是一个以列 `key` 为键的对象。值可以是字符串，也可以是**字符串数组**（一格多行，按元素分段） |
| `spanners` | 分组表头：`[{"label": "信度", "span": ["a", "cr", "ave"]}]` |
| `notes` | `{"general": "N = 344.", "probability": "**p < .01."}` |
| `widths` | 手动指定列宽（pt 数组）。不写就按内容自动分配 |
| `table_width` | 表格总宽（pt）。不写就铺满版心：纵向 Letter 468、横向 648；A4 分别是 451.5 / 697.5 |
| `landscape` | `true` 时整份文档设为横向页（表过宽时用）。版心随之变成「页高 − 左右边距」 |
| `style` | `format=custom` 时逐项覆盖，键见上面的 `merge_style` 默认值 |

列定义字段：

| 字段 | 说明 |
|---|---|
| `key` | 与 `rows` 里的键对应，必填 |
| `label` | 表头文字，缺省用 `key` |
| `align` | `left` / `center` / `right` / `decimal`。数据列默认 `right` |
| `decimals` | 该列数字统一到几位小数。**只在显式写时才格式化** |
| `thousands` | `true` 时四位数以上加千分位（`10,109.33`）。AIC/BIC 这类要用 |
| `leading_zero` | 覆盖档位的前导零规则（APA 省略、中文刊保留） |

### 关于 `align: "decimal"` 与 `decimals`

APA 要求数字列**按小数点对齐**。右对齐只在各格小数位相同时才等价于小数点对齐，
所以：

- 只写 `align: "decimal"` → 右对齐，**不猜小数位**（把 `.5` 自动补成 `.500`
  等于替作者声明了并不存在的精度）
- 写 `decimals: 2` → 该列统一两位小数，保留显著性星号（`.53**` 不会被改坏）
- 两者都写 → 格式化 + 右对齐，最稳

小数位不一致时 `check_figure.py` 会报警。这是投稿件里最常见的硬伤之一：
`.5` 和 `.53` 混排，右对齐后小数点错开一格，排版编辑一眼就能看出来。

`decimals` 只对「纯数字 + 星号」的单元格生效。`(.85)`（AVE 平方根）、`—`、
`< .001`、`NA` 一律原样保留——这些不是数字，自动格式化会把它们改坏。

## 行内标记、图件格式与字体

### 行内标记

单元格、表头、表注都支持 `<i>` `<b>` `<sup>` `<sub>`：

```json
{"label": "<i>B</i>"}
"notes": {"general": "<i>N</i> = 344. <i>SE</i> in parentheses."}
```

**斜体规则（APA）**：*M*、*SD*、*N*、*n*、*r*、*t*、*F*、*p*、*B*、*SE*、*R*²、*d* 斜体；
**希腊字母 β、α、χ²、η² 不斜体**。这一条是投稿件里最显眼的格式错误，纯文本表做不到。

带标记的单元格不参与 `decimals` 格式化——补零会改坏标签。`--tex` 会转成
`\textit{}` / `\textsuperscript{}`。

### 图件格式

| 格式 | 用途 | 说明 |
|---|---|---|
| `.svg` | 默认，插 Word / 转 EPS | 内置渲染器直接产出，零依赖 |
| `.pdf` | 投稿（矢量） | matplotlib；字体嵌入，无 Type 3 |
| `.png` / `.tiff` | 投稿（位图） | 600 dpi，不透明 RGB；TIFF 需 Pillow |
| `--gray` | 黑白印刷核对 | 按亮度转灰，确认各系列仍分得清 |

**字号按最终尺寸计算，不要画大了再缩。** 图按目标宽度（整幅 6.5 in / 半幅 3.25 in）直接绘制，
插入文档后不再缩放。

### 图题不画进图里

APA 的图题在图**上方**、中文期刊在**下方**，都写在文档里，不是图的一部分。
`make_diagram.py` 的 `title` 字段只用于单独预览或幻灯片；正式投稿时应留空，
把标题写进 Word 的图题段落。图题若画进图内，脚本会检查它有没有压住节点或调节变量框。
