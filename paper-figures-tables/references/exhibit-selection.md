# 展示形式的选择

先定形式，再动手做。形式选错，做得再精细也是白费。

## 一条总规则

**表用来查数，图用来看形。**

读者想核对「这个系数是 .53 还是 .35」→ 表。读者想看出「高承诺组随信任上升得更快」→ 图。
两者都能做到的时候，选表——因为表的信息密度更高，而且审稿人核对数字更方便。

## 该用表的情形

| 情形 | 典型表 |
|---|---|
| 描述统计与相关矩阵 | Table 1 |
| 信度、收敛与区分效度（α / CR / AVE / HTMT） | Table 2 |
| 路径系数与假设检验汇总 | Table 3 |
| 中介效应、条件间接效应 | Table 4 |
| 多研究概览（样本、设计、操纵、结论） | Table 1（多研究论文） |
| 文献编码矩阵（作者、样本、方法、变量、结论） | 综述论文核心表 |
| 实验刺激材料与操纵检验 | 附录表 |

判断标准：**单元格里的数字需要被逐项阅读或核对**。

### 三张最常写的表的列模板

列不要凭感觉定。下面三张是营销/管理论文里出现频率最高的，列的含义固定，
换掉一列读者就会找不到熟悉的信息。

**Table 1 描述统计与相关矩阵**

```
变量 | M | SD | α | CR | AVE | 1 | 2 | 3 | …
```

- 对角线放 AVE 平方根（区分效度的常用检查），不放在别处
- 相关系数标显著性星号；样本量写在表注
- 变量名带序号（`1. Brand trust`），序号与相关系数列的编号对应

**Table 2 测量模型（信度与收敛效度）**

```
构念 | 题项 | 标准化载荷 | α | CR | AVE
```

- 一个构念占多行，构念名只在第一行写，其余留空（视觉上自然分组）
- 载荷低于 .50 的题项单独标出并说明是否删除
- CR 与 AVE 的判定门槛（.70 / .50）写进表注，不要让读者去猜标准

**文献编码矩阵**（综述论文的核心表）

```
作者(年份) | 理论视角 | 样本与情境 | 方法 | 自变量 | 因变量 | 主要发现 | 局限/空白
```

- **按理论视角或结论分组**，不要按年份堆；分组本身就是在讲你的综述逻辑
- 「局限/空白」一列是这张表的价值所在——它直接通向你的研究问题
- 列宽给「主要发现」最多，其余收窄；这一列写不下一句话说明编码没做透
- 超过 25 行就考虑拆成两张（按子主题），或把「方法」等次要列移到附录

三张表都可以直接用 `make_table.py` 生成，列定义见 `format-specs.md` 的「列定义」一节。

判断标准：**要传达的是形状、方向或结构，而不是具体数值**。

### 几组均值怎么比：点图，不是柱状图

四组以上的均值比较，**默认画点图（dot plot）加 95% 置信区间**，不要柱状图。
理由不是审美：

1. **柱状图必须从 0 起**，而均值的零点常常没有意义（5 点量表、标准化系数）。
   从 0 起的代价是组间差异被压成柱顶的一小截——读者看见的是「差不多高」。
2. **柱子的面积会骗人**：两倍高会被读成两倍多，而均值是位置量，不是面积量。
3. **点图把不确定性放到和估计值同一个层级**。两组区间重叠多少，
   读者一眼能判断，不必去翻 t 检验的 p 值。
4. 期刊印黑白时，柱子靠灰度区分，印出来常常一个样；
   点图靠**位置**与**形状**区分，黑白也读得出。

柱状图仍有正当用途：**比例、频次、份额**（这些量的 0 有意义），
或原始设计就是分组、读者预期看到柱子。这时用 `"style": "bar"`。

**误差棒不能省，也不能由脚本猜。** 只给均值不给区间时
`make_estimate_plot.py` 会直接报错——区间长度本身是结论的一部分
（n = 15 与 n = 500 的同一个均值，含义完全不同）。有原始数据时用
`--data` 让它按 t 分布算：**不要用 1.96 代替 t**。n = 11 时 t = 2.23，
用 1.96 会把区间画窄 12%。

## 反向规则：这些情况不要画图

1. **少于 3 个数值，不画柱状图。** 两个数写进句子里就行：「A 组高于 B 组（4.21 vs. 3.78）」。
2. **不要饼图。** 人对角度的判断远不如对长度的判断；超过 3 个扇区基本读不出差异。改用表或条形图。
3. **不要 3D、不要阴影、不要渐变。** 透视会扭曲长度，阴影不携带任何信息。
4. **不要双 Y 轴。** 两个纵轴的比例可以任意调，读者无法判断两条线谁涨得快。要么换成同一量纲，要么拆成两幅图。
5. **不要用图展示相关矩阵。** 相关矩阵是查数的，必须用表。
6. **不要网格线。** APA 图表默认无网格；刻度足够。
7. **不要在图里重复表里已有的数字。** 图表达形状，表承载数值，两者分工。

## 一幅图只讲一件事

常见错误：把概念框架、测量模型、结构模型三样塞进一幅图，读者无从下手。
正确做法：概念框架一幅（只有构念与路径），测量模型一幅（只有题项与载荷），
结构模型一幅（只有路径系数与显著性）。三幅图各自承担一个论证任务。

## 版面预算

- 正文图表总数：实证论文一般 4–7 个。超过 8 个说明没做取舍。
- 每个假设在正文里**至少**有一处对应的表或图，但不能一个表塞三个不相干的假设。
- 附录放：刺激材料、题项全文、稳健性检验、额外模型。

## 一句话判定表

| 你想说的是 | 用 |
|---|---|
| 「这些变量之间两两相关」 | 表（相关矩阵） |
| 「这个量表的信度够」 | 表（α / CR / AVE） |
| 「这条路径显著」 | 表（路径系数）+ 图（结构模型，可选） |
| 「信任对购买意愿的作用随承诺增强」 | 图（交互效应）+ 表（简单斜率） |
| 「X 通过 M 影响 Y」 | 表（中介效应：a、b、c′、间接效应与 CI） |
| 「X 通过 M 影响 Y，而这个中介本身随 W 变化」 | 表（**有调节的中介**：index + 条件间接效应，见 `table-types.md` 第 5 节） |
| 「我的理论模型是这样」 | 图（概念框架） |
| 「题项是这样载荷到构念上的」 | 图（测量模型） |
| 「这个效应在四个研究里都成立」 | 表（多研究概览） |
| 「检索与筛选过程是这样」 | 图（PRISMA 流程图） |
| 「三年来的趋势」 | 图（折线） |
| 「样本的基本构成」 | 表（描述统计），不要饼图 |
