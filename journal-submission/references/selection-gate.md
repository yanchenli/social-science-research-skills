# Gate 0 — 四层排除与查证流程

> **这一关先于一切推荐。** 未过 Gate 0 的期刊不得进入候选，也不得列入"仅供参考"。

---

## 一、四层排除

### L1 出版社 / 巨型 OA（机构政策）

| 对象 | 层级 | 排除理由 |
|---|---|---|
| **MDPI** | 出版社级（全部期刊） | 高发文量、特刊驱动、审稿周期极短 |
| **Frontiers** | 出版社级（全部期刊） | 同上；互动式评审导致选择性偏低 |
| **PLOS ONE / SAGE Open / Scientific Reports / Heliyon** | 期刊级 | 巨型 OA，"技术正确即发表"，不以贡献重要性为门槛 |

**为什么后四者单列期刊级**：其所属出版社（PLOS、SAGE、Springer Nature、Elsevier）
旗下有大量合规好刊，出版社级排除会误伤。

> L1 是**使用者所在机构的政策**，不是学术共同体的定论。机构有明确允许清单时，以机构规定为准。

### L2 数据库异动：Clarivate "On-Hold"（一票否决）

**这是比中科院预警更致命、也更滞后被察觉的一层。**

| 项 | 内容 |
|---|---|
| 查询入口 | `https://mjl.clarivate.com`（Web of Science Master Journal List） |
| 状态含义 | 期刊被列入 **On Hold** = 正在被重新评估；**挂起期间新发表的内容不予索引** |
| 两种结局 | 复审通过 → 解除挂起并补录；复审不通过 → **Editorial De-listing**，历史指标（含 JIF）一并移除 |
| 为什么最危险 | 投稿时还在 SSCI，**录用或见刊时已被剔除** → 论文不被检索，直接影响毕业与考核 |

**一票否决**：只要 MJL 显示 On Hold，直接排除，不进入候选。

> 中科院预警名单**一年才更新一次**，滞后明显；MJL 是动态状态，能更早暴露问题。
> 两者不是替代关系，**必须都查**。
>
> 本文件不给出"多少比例最终被剔除"的具体数字——没有可靠的公开统计，
> 编一个百分比只会让这条规则显得精确而不可信。

### L3 官方名单

**中国科学院文献情报中心《国际期刊预警名单》**，由期刊分区表团队发布。

| 项 | 内容 |
|---|---|
| 更新频率 | **每年一次**，通常在 3 月前后 |
| 查询入口 | `https://ewl.fenqubiao.com` |
| 2025 版情况 | 收录 **5 本**，全部因"论文工厂"，**不再区分风险等级** |

> ⚠️ **必须现查最新版。** 本文件不列出具体刊名——列出来就会变成"事实上的清单"。
> 判断某刊是否在列，唯一可靠的做法是去官网查当期版本。

### L4 运营红旗（掠夺性特征 + 特刊陷阱）

| 信号 | 具体表现 |
|---|---|
| 承诺极短周期 | "2 周内见刊""guaranteed publication within 30 days" |
| 主动约稿 | 未经请求的邮件邀请，措辞模板化 |
| 编委造假 | 编委名单里有无法核实的人，或有学者**未经同意**被列名 |
| 影响因子可疑 | 自称有 IF 但 JCR 查不到；或 IF 两年内暴涨数倍 |
| APC 异常 | 远高于同类；或要求汇款至个人账户 |
| 刊名泛化 | "International Journal of …" 类空泛刊名，且网站有语法错误 |
| **特刊占比警报** | 近一年特刊发文量 ≥ 正刊发文量，且客座编辑缺乏业内公认的资深学者 → **直接判高风险** |
| 发文量异动 | 近三年年发文量**激增 200% 以上** → 打「稳健度警示」（见第三节） |
| 接受率异常 | 接受率 > 70% 且审稿周期 < 4 周 |
| 被第三方收录 | Predatory Reports、Cabells 有记录 |

**判定规则（与 L1–L3 不同）**：

- 命中 **1 条** → 高风险，**需人工确认**后才可进入候选（弱信号如"刊名泛化"单条不足以否决）
- 命中 **2 条及以上** → **直接排除**
- 命中**强信号**（承诺极短周期 / 编委造假 / APC 汇个人账户 / 被 Predatory Reports 收录
  / 特刊占比警报）→ **1 条即排除**

> L1–L3 是名单判断，L4 是特征推断。特征推断需要更强证据，否则会误伤新刊与小刊。

## 二、强制联网验证动作（不可省略）

**在生成任何推荐之前，必须执行真实检索，而不是"回忆"名单内容。**

```
Search: 中国科学院文献情报中心 国际期刊预警名单 <当前年份>
Search: "<候选刊名>" "on hold" Web of Science
Search: site:mjl.clarivate.com "<候选刊名>"
Search: "<候选刊名>" 预警 黑名单
```

- 检索做过，才能进入下一步；
- 检索无结果或无网络 → 走第五节的降级路径，**不得凭记忆作答**；
- **禁止**直接输出"根据预警名单，X 不在其中"这类未经验证的断言。

> 这一条是为模型本身设的。没有显式检索指令时，模型倾向于用训练记忆里的旧名单强行作答，
> 而旧名单读起来完全合理——**这正是最危险的地方**：错误看起来像答案。

**查证时记录五件事**（写进交付报告）：

1. 预警名单查的是哪一版（年份）
2. MJL 查到的状态（在刊 / On Hold / 已除名）
3. 查询日期
4. 查询来源（官网 / 转载）
5. 结论

## 三、特刊陷阱：正规刊也会踩

近几年大量**正规期刊（含 ABS 3 星）**被中介"包库"操作 Special Issue，
单年发文量暴增数倍，随后被预警或降级。这类刊不在 L1–L3 的名单上，只能靠 L4 识别。

### 三条可操作的红线

| 红线 | 判定 | 动作 |
|---|---|---|
| **特刊 ≥ 正刊** | 近一年特刊发文量 ≥ Regular Issue 发文量 | 高风险；如仍要投，**只投 Regular Issue** |
| **客座编辑同质化** | 某一期特刊的 Guest Editor 与作者单位高度重合（如全来自同一机构） | 高风险，避开该特刊 |
| **发文量激增** | 近三年年发文量增长 **> 200%** | 打「稳健度警示」，说明理由，不必然排除 |

### 怎么查（给用户的具体步骤）

1. 期刊官网 → `Special Issues` 页，列出近 12 个月的特刊期次；
2. 数每期的发文量，与同期正刊对比；
3. 逐一核实 Guest Editor 的履历与所属机构；
4. 官网 `Archive` 页按年份看总发文量，做三年趋势。

> **"只投 Regular Issue" 是一条实用建议**：同一本刊，正刊与特刊的审稿标准可能差很远。
> 投稿系统里选文章类型时就要选对，不要被"特刊更容易中"吸引。

## 四、一个会让规则静默失效的坑：品牌 ≠ 期刊身份

**按出版社名字排除，会随改名、并购、停用品牌而失效，而且失效时没有任何提示。**

实例：**Hindawi**——Wiley 于 2023 年 12 月宣布停用该品牌，约 200 种期刊在 2024 年中
并入 Wiley 其他系列。一份写着"排除 Hindawi"的清单，在 2024 年之后**基本失效**：
那批期刊仍在出版，只是不再挂 Hindawi 的牌子。

**正确做法**：

1. 排除记录**以 ISSN 为主键**，品牌名只作辅助标签；
2. 每次核查确认"这本刊现在属于哪个出版社、是否换过名"；
3. 清单写**复核日期**，超过一年即视为需重新验证。

> 任何静态黑名单都会随时间腐坏，而腐坏是静默的——名单还在，规则看起来还在生效，
> 实际已经不匹配现实了。

## 五、官网不可达时的降级路径（不是豁免）

铁律的意思是"必须查过"，不是"必须从官网查到"。

| 步骤 | 做法 |
|---|---|
| 1 | 换网络/换浏览器重试；用当期页面而非首页 |
| 2 | 改用**高校科研处转载的当期名单**（须确认当年版本，记录来源与日期） |
| 3 | 报告中标注「**非官网核验，置信度较低**」，建议投稿前自行复核 |
| 4 | 若转载版也找不到，**不得跳过**：只核验已有候选，不主动推荐新刊，并向用户说明原因 |

**降级不等于豁免。** 不能因为"查不到"就当作"不在名单上"。

## 六、边界情形

| 情形 | 处理 |
|---|---|
| 期刊**曾经**在预警名单上，最新版已移出 | 可进候选，但报告注明"曾于 X 年在列，最新版已移出" |
| 期刊**曾被 On Hold，现已解除** | 可进候选，但注明"曾于 X 月至 Y 月在 On Hold，已解除"；并提示检查挂起期内的论文是否被补录 |
| 在其他高校黑名单上，但不在中科院名单 | 以使用者机构规定为准；无规定则作风险提示 |
| 期刊是**新刊**，尚无影响因子 | 可考虑，但看编委、出版社、已发表文章质量；不得因"新"而默认安全 |
| **作者坚持要投被排除的期刊** | 见下——**记录不等于推荐** |

### 作者坚持要投怎么办

- **技能不会把该刊列入候选清单，也不会为它写 cover letter 或做匹配度论证。**
- 但技能**可以记录**：写明命中了哪一层、理由、风险。
- 报告里单列一节「作者坚持的候选（本技能不推荐）」，**与三档清单分开**。

> 推荐 = 我认为这是好选择；记录 = 我告知你这不是，但你仍可决定。技能只做后者。

## 七、给学生解释时的措辞

必须把三件事分开说，否则一查就穿帮：

- ✅「**我们按所在机构的政策**，不推荐 MDPI 与 Frontiers 旗下期刊。」
- ❌「MDPI 是被中科院预警的期刊。」——2025 版名单里没有 MDPI，这句是错的。

- ✅「这本刊在 2025 版《国际期刊预警名单》上。」
- ✅「这本刊目前在 Web of Science 的 **On Hold** 状态，发表后可能不被检索。」
- ❌「这本刊是掠夺性期刊。」——除非有 Predatory Reports 等第三方记录；
  "被预警""On Hold""被认定为掠夺性"是三件不同的事。
