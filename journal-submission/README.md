## 它解决什么问题

投稿失败有两种，代价完全不同：

- **写坏了**——审稿意见说方法不行、贡献不够。这类失败有反馈，能改。
- **投错了**——稿子其实够 3 星，却拿去撞 4 星被 desk reject，或者反过来，够得着 4 星却投了 2 星。
  这类失败**没有反馈**，只损失三到六个月。

第二种更常见，也更没人教。这个技能处理的就是第二种：**在选刊之前先判断这篇稿子的真实档位**，
再据此推荐冲刺 / 匹配 / 保底三组期刊。

---

## 核心理念

**先盲评六维，再看期刊。**

顺序反了就会出事：先定目标刊，再把评语写得刚好够到那一档——这是自欺，而且编辑一眼看得出。

| 铁律 | 含义 |
|---|---|
| **最弱的一维决定上限** | 不取平均。理论贡献强、方法弱的研究投 4\* 会被 desk reject——编辑看短板 |
| **「强」可以来自任何一维** | 4 档要两维强，不必非由方法维度提供；真正被卡住的是 4\* |
| **学术线与考核线并列给出** | 有些刊同行声誉极高却不在本校目录里，反之亦然。两条线的优先级由使用者决定 |
| **不内置任何榜单清单** | 榜单每年调整，写死就会错。每本候选刊现场查官方列表，查不到就写「未能核实」 |

## 工作流程

### 第 0 关 · 四层排除（先于一切推荐）

命中即排除，与档位高低无关：

1. 出版社级（MDPI、Frontiers 等）
2. 期刊级（Web of Science On-Hold 状态一票否决）
3. 官方预警名单（中科院《国际期刊预警名单》）
4. 机构黑名单（使用者所在单位的规定优先于一切）

> **两个容易失效的地方**：2025 年预警名单只有 5 本、**不含 MDPI**——禁 MDPI 是机构政策，
> 不是官方结论；Hindawi 品牌已停用（并入 Wiley），**按出版社名排除会静默失效**，排除要落到 ISSN。

### 阶段 0 · 两次分流（决定用哪把尺子）

| 分流 | 分什么 |
|---|---|
| **学科流派** | A 微观行为 / B 档案计量 / B2 资产定价 / C 实践 / D 质性 / E 概念综述 / F 构型 QCA |
| **输入完整度** | 全稿 / 只有摘要——后者只能做「理论上限评估」，**必须明说** |

> **按方法分轨，不按学科分轨。** 战略研究用档案数据走 B，用问卷走 A，用 QCA 走 F。

### 阶段 1 · 六维定档

理论贡献 / 方法严谨性 / 数据与样本 / 分析深度 / 写作完成度 / 读者契合，每维判「强 / 中 / 弱」并附证据。

**维度 2 判的是「威胁有没有被处理」，不是「贴了什么标签」。**
看到 DID/IV 就给强、看到固定效应/PSM 就给中，是常见错误——同一个设计，做得认真与套模板可以差两档。

### 阶段 2–5 · 检索、匹配、投稿准备、交付

候选刊检索（必须联网）→ 逐本匹配度与 desk reject 风险 → cover letter、材料清单、格式与匿名化、
被拒后的转投策略 → 选刊报告。

## 用法示例

```
我是营销方向博士生，这篇稿子想投 SSCI。
数据是 CSMAR 面板，做了 DID，但没做平行趋势检验。
帮我看看能投什么档，列几本具体期刊。
```

技能会先做 Gate 0 排除，判流派（B 档案计量），逐维给证据，指出「方法维度卡在缺平行趋势检验」，
再给三档候选刊并标注榜单位置。

---

## 边界与注意事项

- **不保证录用。** 定档是投稿前的初筛，不是录用预测。
- **榜单位置必须现场查。** 技能不内置清单，查不到就写「未能核实」，不猜。
- **B 轨判据尚未经领域内人审。** 档案计量那一轨的判据骨架来自 Roberts & Whited (2013) 等文献，
  并做过一次系统审核（AI 审，非真人同行）——**「某档期刊的审稿人实际会追问什么」这类判断仍需真人把关**。
  该轮审核的采纳与不采纳记录在 `references/b-track-review-log.md`，可自行核验。
- **不负责改写论文本身**，也不负责回应审稿意见（见下方分工）。
