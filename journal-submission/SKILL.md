# 选刊与投稿准备 — Journal Selection & Submission Preparation

## 核心理念

**选刊不是「投得中就行」，是让论文落到它会被正确评价的地方。**

高投低是浪费审稿周期、消耗作者信心；低投高是埋没贡献。两种错都要避免。

本 skill 做四件事，顺序不能颠倒：

1. **先分流**——确认学科流派与输入完整度，否则会用错尺子
2. **先定档**——按论文的实际质量评估，而不是按作者的意愿或时间压力
3. **先排除**——在禁用名单之外筛选，而不是先挑好心仪的再去查它有没有问题
4. **再匹配、再准备**——逐本核实等级与匹配度，最后做投稿材料

> **顺序是硬约束。** 先挑期刊再补质量论证，是本末倒置；先选中心仪的再查禁令，查到了也舍不得放弃。

---

## ⚠️ 第 0 关：四层排除（Gate 0，先于一切推荐）

**任何期刊推荐之前，必须先过这一关。** 详细清单与查证流程见 `references/selection-gate.md`。

| 层 | 内容 | 处理 |
|---|---|---|
| **L1 出版社 / 巨型 OA** | MDPI、Frontiers（出版社级）；PLOS ONE、SAGE Open、Scientific Reports、Heliyon（期刊级） | 直接排除 |
| **L2 数据库异动** | **Web of Science「On Hold」**（`mjl.clarivate.com`） | **一票否决**——挂起期内容不予索引，随时可能被 de-list |
| **L3 官方名单** | 中科院《国际期刊预警名单》**最新版** | 命中即排除 |
| **L4 运营红旗** | 掠夺性特征；特刊发文量 ≥ 正刊；发文量三年激增 > 200% | 按计数规则排除（见下） |

### 四条铁律

1. **未查最新版预警名单与 MJL 状态，不得给出任何推荐。**
   预警名单每年 3 月前后更新；MJL 是动态状态，**两者都必须查，不可互相替代**。
2. **命中 L1–L3 即排除，不进入候选、不列入「仅供参考」。**
   L4 按计数：强信号（承诺极短周期／编委造假／APC 汇个人账户／被 Predatory Reports 收录／
   特刊占比警报）1 条即排除；普通信号 2 条及以上排除；单条弱信号需人工确认。
3. **排除要落到期刊身份（ISSN），不能只落品牌名。**
   **Hindawi 即为例证**：Wiley 2023 年 12 月停用该品牌，约 200 种期刊 2024 年中并入
   Wiley 其他系列。名单上写着「排除 Hindawi」，那批期刊已换了招牌。
4. **不得把「机构政策」说成「官方预警」。**
   「禁 MDPI / Frontiers」是机构政策判断，不是官方名单结论——2025 版预警名单只收录 5 本，
   **MDPI 一本都不在**。混为一谈，学生一查就穿帮，之后整份清单都不再可信。

### 官网不可达时的降级路径（不是豁免）

| 步骤 | 做法 |
|---|---|
| 1 | 换网络/浏览器重试；用当期页面而非首页 |
| 2 | 改用高校科研处转载的当期名单（确认当年版本，记录来源与日期） |
| 3 | 报告标注「**非官网核验，置信度较低**」，建议投稿前自行复核 |
| 4 | 转载版也没有 → **不得跳过**：只核验已有候选，不主动推荐新刊，并向用户说明原因 |

**降级不等于豁免。** 不能因为「查不到」就当作「不在名单上」。

## 阶段 0 — 两次分流（决定用哪把尺子）

### 分流 1：学科流派

**六维标准版是为微观行为研究写的。** 拿它去量一篇基于 CSMAR/Compustat 的面板论文会彻底失语——
那类论文不做操纵检验，命门是平行趋势、内生性、聚类标准误。

| 流派 | 典型领域 | 典型方法 |
|---|---|---|
| **A 微观行为** | OB / HRM / 消费者行为 / 营销（行为向） | 实验、问卷、心理测量 |
| **B 档案 / 计量** | 会计、公司金融、应用计量、战略（档案数据向） | 档案数据、DID、IV、RD、事件研究、面板 |
| **B2 资产定价** | 资产定价、因子模型 | 因子构造、Fama-MacBeth、样本外检验 |
| **C 实践 / 现象驱动** | DBA、EMBA、管理实践研究 | 深度案例、一手商业数据、行动研究 |
| **D 质性** | 管理/营销质性研究 | 访谈、扎根理论、案例、民族志 |
| **E 概念 / 综述** | 理论建构、元分析、系统综述 | 推演、二次数据综合 |
| **F 构型 / QCA** | 战略、组织、创业中的集合论研究 | 校准、真值表、一致性与覆盖度 |

**判定方式**：问三件事——① 数据从哪来（自采 / 二手库 / 访谈 / 无数据）？
② 核心论证靠什么（统计推断 / 计量识别 / 深度描述 / 逻辑推演 / 集合关系）？
③ 分析单位是什么（个人 / 团队 / 公司 / 行业 / 资产）？

> **按方法分轨，不按学科分轨。** 战略研究用档案数据走 B，用问卷走 A，用 QCA 走 F。
> **B 不叫「宏观财经」**——会计与公司财务绝大多数是公司层面数据，叫宏观会误导。
> **资产定价必须单列（B2）**：它不问「X 是否导致 Y」，判据与 B 轨完全不同，不要混用。

判错的后果很实际：用微观尺子量 B 类论文，会给出「缺操纵检验」这种**看起来很专业、实则外行**的评语。

### 分流 2：输入完整度（防止模型编造）

| 模式 | 用户给了什么 | 能做什么 |
|---|---|---|
| **A 全稿** | 完整正文（至少含方法、结果） | 完整六维定档 |
| **B 摘要 / 思路** | 一段摘要、一个想法、几句话 | **只能做「理论上限评估」** |

> 模式 B 必须明说：「当前仅基于摘要/思路初筛，结论是**理论上限**，方法缺陷与分析深度无法评估。」
> 然后索取方法与结果部分再做终判。
>
> **严禁**在用户只给两句话时写出「方法严谨性为中、操纵检验合格」——那不是评估，是编造。

## 阶段 1 — 论文质量定档

六维评估（每维「强/中/弱」并附证据），**维度 2、3、4 按流派分流**，
详见 `references/tier-mapping.md`：

| 维度 | A 微观 | B 档案/计量 | C 实践 |
|---|---|---|---|
| 1 理论贡献 | 增量 vs 颠覆 | 同左 | 管理范式颠覆度 / 实践洞察穿透力 |
| 2 方法严谨性 | 操纵检验、预注册、竞争性解释 | **威胁被点名+被检验+有敏感性分析**；识别来源可为外生变异（DID/IV/RD/短窗口事件研究）或结构模型 | 数据壁垒、反事实推演 |
| 3 数据与样本 | 样本量、代表性、多研究 | **数据能否支撑识别所需的变异**；度量效度；前视/生存/回填偏差 | 一手数据稀缺性 |
| 4 分析深度 | 稳健性、竞争模型、边界条件 | 每项检验对应一个替代解释；经济显著性；生成回归量当心 | 对照案例 |
| 5 写作完成度 | 论证链、So what | 同左 | 同左 |
| 6 读者契合 | 与该刊近两年文章对话 | 同左 | 实践刊另有一套 |

> **维度 2 判的是「威胁有没有被处理」，不是「贴了什么标签」。**
> 看到 DID/IV 就给强、看到固定效应/PSM 就给中，是 v2.0.0 的错误，已修正。
> 同一个设计，做得认真与套模板可以差两档。
>
> **判「中」时必须说明是哪一种**：认真做的观测设计（够 3 档），还是套模板（3 档边缘）。

### 从六维到档位

**最弱的一维决定上限，不取平均。** 理论贡献强、方法弱的研究，投 4* 会被 desk reject。

| 档位 | 必要条件 |
|---|---|
| **4\*** | 六维无「弱」；**至少三维「强」**；回答领域核心问题，或显著改变既有认识 |
| **4** | 六维无「弱」；**至少两维「强」** |
| **3** | 六维无「弱」；贡献明确、方法规范 |
| **2** | 允许一维「弱」 |
| **1** | 方法规范即可 |

> **「强」可以来自任何一维**——理论、数据、写作都算，不必非由方法维度提供。
> 真正被「方法只能是中」卡住的是 **4\***（要三维强），不是 4。
> 这一点必须说准，否则会劝退本可以冲 4 的稿子。
>
> 4\* 的旧要求是「贡献具颠覆性」，**已去掉**——顶刊大多数论文属于「重要问题 + 可信证据」，
> 算不上颠覆。要求颠覆性等于把 4\* 判成不可达。

### 三档推荐（互斥）

| 档 | 定位 | 建议数量 |
|---|---|---|
| **冲刺** | 评估档位 **+1** | 1–2 本 |
| **匹配** | 评估档位 **±0** | 2–3 本 |
| **保底** | 评估档位 **−1** | 1 本 |

> 三档必须互斥：一本刊只能落在其中一档。

### ⛔ 时间线红线（必须在出清单之前判断）

设**剩余月数 R**、候选刊**平均审稿周期 T**：

| 条件 | 判断 |
|---|---|
| R ≥ 2T | 可冲：先投冲刺档，被拒后仍能转投匹配档 |
| 1.5T ≤ R < 2T | 只投匹配档，不冲 |
| **R < 1.5T** | **不生成三档清单**，先停下来告知 |

**R < 1.5T 时的话术**：

> 按当前时间线，这篇论文承受不了正常审稿周期。继续做清单只会让你读完一份用不上的方案。
> 现在有三条路：① 改投周期足够短的刊（T ≤ R/1.5）；② 转为工作论文或会议论文，先拿反馈；
> ③ 压缩目标、接受降档。

**理由**：让用户读完整份清单才发现「根本来不及」，是最糟糕的交付体验。
**这一条优先于本阶段的其他输出。**

## 阶段 2 — 候选期刊检索（必须联网）

**所有期刊事实必须联网核实，不得凭记忆。** 影响因子、分区、榜单、周期、APC 每年都在变。

| 项目 | 来源 |
|---|---|
| **ABS/AJG 等级** | `charteredabs.org/academic-journal-guide/`（AJG 2024 为现行版） |
| **FT50 / UTD24** | 各榜单官方页面（本技能不内置名单，必须现查） |
| **ABDC** | ABDC 官方列表（澳洲/亚太用户尤其要看） |
| **SSCI/SCIE 收录 + On-Hold 状态** | `mjl.clarivate.com` |
| JCR 分区 / 影响因子 | JCR（无访问权则标「需自行核实」） |
| 中科院分区 | 分区表官网 |
| **Gate 0 四层** | 见上 |
| APC | 期刊官网 open access 页 |
| 审稿周期 | 见下「查不到怎么办」 |
| 近三年发文量趋势 | 期刊官网 Archive 页逐年统计 |
| 近两年是否发过同主题 | 期刊官网检索、Google Scholar 按刊名过滤 |

> **不得凭记忆报影响因子、分区或榜单归属。** 查不到就写「未能核实」。

### 审稿周期查不到怎么办：用分级区间，不要编小数

很多刊不公开 Time to First Decision，藏在 Journal Insights 动态图或作者社群里。此时：

| 类型 | 经验区间（一审） |
|---|---|
| 快报型（Letters / Rapid Review） | 1–2 个月 |
| 标准商科刊（ABS 3–4 常规刊） | 3–6 个月；含 R&R 全程 1–2 年 |
| 顶级综合刊（AMJ / ASQ / TAR 一类） | 4–8 个月 |

> **这些是行业经验区间，不是该刊的实测值。** 输出时必须标注「经验区间 / 社群共识」，
> **严禁**写成「该刊一审 3.2 个月」这种伪精确数字。

### 检索式的写法

```
site:<期刊域名> "<核心构念>"
"<期刊名>" "<核心构念>" 2024..2026
"<期刊名>" "<方法关键词>"（experiment / DID / SEM / qualitative）
```

三组都查不到同主题文章 → 该刊对该主题的接受度存疑，这是**高风险信号**，应写明而非隐去。

## 阶段 3 — 匹配度评估

1. **Aims & scope 比对**——近两年是否发过同主题、同方法
2. **方法接受度**——这本刊收不收实验/质性/档案数据/概念性论文
3. **篇幅与结构偏好**
4. **审稿周期 vs 截止时间**（用阶段 1 的时间线规则）
5. **APC 与经费**
6. **编委匹配**——有没有你所在领域的编辑
7. **Desk Reject 风险预估**——见下

### Desk Reject 风险预估（必须逐本给）

Desk reject 不产生审稿意见，只消耗几天到两周，但会把整条时间线往后推。

**没有可靠的统一数字。** 常被引用的区间是 50%–90%，但**不要当固定值**——
查该刊公开数据或作者社群，查不到就写「未能核实」。

| 信号 | 风险 |
|---|---|
| 维度 1（贡献）为「中」或以下 | **高** |
| 维度 6（读者契合）为「中」或以下 | **高**——「不适合本刊范围」是头号原因 |
| 维度 1 与 6 都「强」，但方法有弱项 | 中 |
| 六维无「弱」且契合明确 | 低 |

**报告必须写明**：风险等级 + 触发点 + 缓解动作。例如：

> **风险：高。** 触发点：该刊近两年未发过同主题。
> 缓解：cover letter 第 2 段显式对接该刊 2024 年某篇文章的争论，并把 Introduction
> 前两段改写为该刊读者熟悉的框架；否则很可能一周内被退回。

## 阶段 4 — 投稿准备

详见 `references/submission-checklist.md`。

### 4.1 Cover letter

写给**这本刊的编辑**看的，不是通用模板。除常规五段外，商科刊尤其看重
**「本文把哪场既有争论往前推了一步」**——用「争论针刺法」：不只引用该刊文章，
而是点出两位学者之间的分歧，说明本文如何调停。

### 4.2 投稿材料清单

作者信息与顺序、通讯作者、单位与基金、利益冲突、数据可用性、伦理审批、CRediT、
图形摘要、推荐/回避审稿人。

**商科特有**：

- **数据再利用声明**——该数据若曾用于其他已发表文章，必须主动交代，
  并说明本文与先前文章在研究问题、变量、假设上的独立性。不报即可能被认定为
  Salami Slicing（切香肠式发表），属学术不端。
- **建议 Handling / Action Editor**——大型综合刊编委体量大，主动提名 1–2 位
  细分领域契合的副主编，可降低因「找不到合适 AE」而 desk reject 的概率。

### 4.3 格式与匿名化

期刊模板、参考文献格式、图表分辨率、字数压缩、双盲匿名化
（正文、**文件属性**、致谢、自引表述、文件名）。

### 4.4 被拒后的转投策略

三种情形：**desk reject**（重写 cover letter 第 2 段，可立即改投）、
**审稿后拒**（按意见修改，转投时说明改了什么）、**出版社内 cascade**（省时间但通常降档，
且审稿意见可能被带过去）。

> ⚠️ **防「转投内卷」**：同领域同梯队期刊的**审稿人圈子高度重叠**。
> 例如在服务营销领域被 JSR 拒后立刻投 JOSM，极可能撞到同一位外审专家。
> **若上一轮意见指出了硬伤，务必大改后再投**——否则新刊审稿人看到同一篇稿子，
> 会直接 instant reject，而且这次连修改机会都没有。

**一稿多投是红线**：同一时间只能有一家在审。

## 阶段 5 — 交付

## 中文期刊（附注）

中文期刊评级口径不同：**CSSCI（南大核心）／北大核心／
国家自然科学基金委员会管理科学部认定的重要期刊**。

本 skill 不展开中文期刊的完整评级（各校认定差异大），只提示两点：

- 中文期刊同样要查**本单位/本省的预警或黑名单**；
- 中文期刊的审稿与见刊周期通常更长，时间线要留更宽余量。

## 与相邻技能的衔接

> 这里用**纯文本技能名**而不是相对路径链接。技能可能被单独安装、被复制到别的目录，
> 或在多 Agent 环境里被动态加载——相对路径在这种情况下会失效，而名字不会。

| 时点 | 联动哪个技能 | 怎么用 |
|---|---|---|
| 投稿前 | `academic-citation-auditor` | 先核一遍参考文献是否真实。被拒之后才发现假引用，代价高得多 |
| 定档发现贡献讲不清楚 | `discussion-conclusion-writer` | 从它的阶段 2（理论贡献）补起 |
| 定档发现论证链不闭合 | `academic-writing-assistant` | 从它的阶段 5（修改与润色）走一遍六维诊断 |
| 审稿意见回来了 | `response-to-reviewers` | 逐条整理与回应 |
| 需要重跑分析回应质疑 | `quant-data-analysis` / `stats-results-writer` | 前者跑分析，后者写结果 |

**若所在环境未安装上述技能**，把技能名当作「该做什么」的提示即可——不要因为找不到技能就跳过。

## 重要原则（贯穿全程）

1. **先分流，再定档，再选刊。** 尺子用错，后面的推理再严谨也是错的。
2. **输入不完整就明说。** 只有摘要时给「理论上限」，不要编造方法评语。
3. **禁令先于偏好。** 命中 Gate 0 即排除，不给「仅供参考」的例外。
4. **名单必须现查。** 预警名单每年更新，MJL 是动态状态；写死的清单一定会过期。
5. **期刊事实必须联网核实。** 榜单、分区、APC、周期都不得凭记忆。
6. **区分「机构政策」「官方预警」「数据库异动」。** 三者不同，混说会让学生不再相信这份清单。
7. **不替研究者决定投哪里。** 给档位、给候选、给风险，选择权在作者与导师。
8. **不承诺录用。** 只谈匹配度与风险，不谈「好不好中」。
9. **不美化论文。** 定档偏低就明说缺什么。
