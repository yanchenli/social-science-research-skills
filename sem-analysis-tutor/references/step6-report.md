# 第 6 步：生成完整学术报告

## 目标

将所有已验证的统计数据整合为符合顶级商科期刊规范的 APA 格式实证分析报告。

---

## 动作 A：报告生成前的材料核查清单

**在生成报告之前，必须确认以下所有信息已收集完毕。若有缺失，主动向用户索取，绝不凭空补全任何数值。**

| 核查项 | 是否已收集 |
|--------|-----------|
| CMB 检验方法（Harman / VIF）及结果数值 | ☐ |
| 测量模型：所有构念的 Cronbach's $\alpha$、CR、AVE | ☐ |
| 测量模型：所有题项的标准化因子载荷 | ☐ |
| 区分效度：HTMT 矩阵（**首选**；Fornell-Larcker 准则已不推荐作为主要证据，可作补充） | ☐ |
| **CB-SEM 专项**：测量模型 CFA 拟合指标（$\chi^2/df$、CFI、TLI、RMSEA、SRMR） | ☐ |
| **CB-SEM 专项**：结构模型整体拟合指标 | ☐ |
| 结构模型：所有路径的 $\beta$、$SE$（或 $t$）、$p$ 值、95% CI | ☐ |
| 各内生构念的 $R^2$ | ☐ |
| **PLS-SEM 专项**：各路径 $f^2$ 效应量 | ☐ |
| **PLS-SEM 专项**：SRMR 值 | ☐ |
| **PLS-SEM 专项**：各内生构念 $Q^2$ 值（Blindfolding 输出） | ☐ |
| 中介效应（如适用）：间接效应值及 95% Bootstrap CI | ☐ |
| 调节效应（如适用）：交互项系数及简单斜率描述 | ☐ |
| **有调节的中介**（如适用）：交互项系数 + 三个 W 水平下的条件间接效应及 CI | ☐ |
| 完整假设清单：编号 + 路径方向 + 是否支持 | ☐ |

---

## 动作 B：生成报告

确认所有材料就绪后，按以下结构生成报告：

---

### 报告结构

**1. 共同方法偏差检验**

说明：
- 使用的检验方法（Harman 单因子 / 全共线性 VIF）
- 检验结果数值
- 结论（通过 / 存在局限性，并说明已采取的程序控制措施）

**2. 测量模型评估**

分三段报告，CB-SEM 用户额外报告 CFA 整体拟合：

*段落一：信度*
- 所有构念的 Cronbach's $\alpha$ 和 CR 值

*段落二：收敛效度*
- 各构念的因子载荷范围、AVE 值

*段落三：区分效度*
- HTMT 值（或 Fornell-Larcker 准则）

*（CB-SEM 专属）段落四：CFA 整体模型拟合*
- $\chi^2/df$、CFI、TLI、RMSEA、SRMR

**3. 结构模型评估与假设检验**

- 整体模型拟合（CB-SEM）或 $R^2$/SRMR（PLS-SEM）
- 各 $R^2$ 值（内生构念）
- 逐条路径报告：$\beta$、$SE$/$t$、$p$ 值、CI
- 每条假设明确给出 Supported / Not Supported 结论

**4. 中介 / 调节效应（如适用）**

*中介*：
- 间接效应值、95% Bootstrap CI
- 说明中介类型（完全/部分）

*调节*：
- 交互项路径系数
- 调节方向描述（正向/负向调节）
- 简单斜率图文字描述（如有）

**5. 假设检验汇总表**（Markdown 格式）

```
| 假设 | 路径 | $\beta$ | $t$/$z$ | $p$ | 结论 |
|------|------|--------|---------|-----|------|
| H1 | X → Y | .32 | 4.21 | < .001 | ✅ Supported |
| H2 | M → Y | .08 | 1.12 | .263 | ❌ Not Supported |
```

## 报告撰写约束

> **首先确认报告语言**：若用户未说明，主动询问："你的报告需要中文还是英文？"不同语言在写作规范上有差异。

### 中文报告规范

1. **符号规范**：严格使用 LaTeX 统计符号（$\beta$、$\chi^2$、$R^2$、$p$、$t$、$z$、$f^2$、$\alpha$、$\rho_A$）
2. **数值原则**：报告中所有数值必须来自用户提供的软件输出，不得估算、推断或替换
3. **保留位数**：与软件原始输出一致，通常保留 2–3 位小数
4. **写作风格**：客观严谨的学术口吻，使用**第三人称被动语态**（如"本研究发现……"、"结果显示……"）
5. **局限性说明**：未达标的指标必须在局限性部分如实说明，不得回避
6. **不使用模糊表述**：$p = .06$ 等一律报告为不显著，无例外

### 英文报告规范（国际期刊投稿）

1. **符号规范**：同中文，使用 LaTeX 符号，APA 7 格式
2. **数值原则**：同上，数值均来自用户提供输出
3. **保留位数**：通常 2 位小数（APA 7 默认）；$p$ 值精确报告（如 $p = .032$），< .001 时写 $p < .001$
4. **写作风格**：APA 7 允许并**鼓励主动语态**（如 "We examined..." / "Results showed..."），不必强制被动语态
5. **统计符号斜体**：所有统计量符号斜体（$\beta$、$t$、$p$、$F$、$M$、$SD$ 等）——这是 APA 7 硬性规定
6. **局限性与不支持假设**：同中文规范，直接报告 "not supported"，不得模糊化

> 💡 英文报告示例措辞：
> - "The measurement model demonstrated adequate reliability and validity."
> - "Results indicated that H1 was supported ($\beta$ = .32, $t$ = 4.21, $p$ < .001)."
> - "H2 was not supported ($\beta$ = .08, $t$ = 1.12, $p$ = .263)."

若用户需要 `.docx` 格式的报告，用所在环境提供的文档生成能力（如 `python-docx` 库或 `pandoc` 转换；若环境中已有专门的 docx 技能，优先使用它）输出规范格式的 Word 文档，包含：
- 文字结果段落
- APA 格式统计表格
- 假设检验汇总表
