# 异常情况处理策略与局限性说明模板

遇到以下任何异常情形时，**不得强行跳过或轻描淡写**。按对应策略处理，并在最终报告中如实说明。

---

## 数据与检验阶段

| 异常情形 | 处理策略 |
|---------|---------|
| 缺失值 > 15% | 提示用户重新评估数据质量；若继续分析，需在局限性中说明潜在影响 |
| 数据严重非正态（CB-SEM） | 切换至 `estimator = "MLR"`；在方法部分说明使用稳健估计 |
| Harman 单因子解释方差 > 50% | 在局限性部分如实说明；补充程序控制措施描述；建议未来研究使用多源数据 |
| CMB 全共线性 VIF ≥ 3.3 | 同上 |

---

## 测量模型阶段

| 异常情形 | 处理策略 |
|---------|---------|
| CFA 拟合指标差（RMSEA > .10） | ① 检查修正指数（Modification Indices）；② 考虑增加理论合理的误差相关；③ 若仍无法改善，在局限性中说明模型拟合的局限性，提供可接受指标的证据 |
| 因子载荷 < .40 | 建议删除该题项，理由：该题项与构念的关联性不足 |
| AVE < .50，但所有载荷 ≥ .70 | 可引用 Fornell & Larcker (1981) 的论点：在高载荷情况下，AVE 略低于 .50 仍具备一定收敛效度，需在报告中如实报告数值并说明情况 |
| HTMT ≥ .90（两构念间） | ① 检查两个构念的理论区分度；② 考虑合并构念或在理论部分说明二者的概念差异；③ 若研究设计本身导致高相关，在局限性中说明 |
| 删题后构念仅剩 2 道题项 | 提醒用户：2 题项构念在 CB-SEM 中可能导致识别问题；需特别说明量表局限性 |

---

## 结构模型阶段

| 异常情形 | 处理策略 |
|---------|---------|
| 某条假设路径不显著（$p ≥ .05$） | 直接报告为 **Not Supported**；在讨论部分从理论角度解释可能原因（样本特征、情境因素、测量局限等），不得做统计上的模糊处理 |
| 路径方向与假设相反且显著 | 报告为 **Not Supported（反向显著）**；在讨论中着重解释这一意外发现的理论含义 |
| $R^2 < .10$（内生构念） | 提示模型解释力有限；在讨论中说明可能遗漏的前因变量 |
| 结构模型 VIF ≥ 5.0 | 存在多重共线性风险；检查是否有高相关的预测变量，考虑是否需要调整模型设定 |

---

## 中介 / 调节阶段

| 异常情形 | 处理策略 |
|---------|---------|
| 间接效应 95% CI 含零 | 中介效应不显著，直接报告；**不得**表述为"边缘中介"或"趋势上的中介效应" |
| 调节交互项不显著 | 调节假设不支持，直接报告；可在讨论中说明可能的调节变量测量或样本局限性 |
| 中介检验中 $a$ 路径显著但 $b$ 路径不显著 | 间接效应链断裂，整体中介效应不成立；需在报告中逐路径说明 |

---

## 有调节的中介阶段

| 异常情形 | 处理策略 |
|---------|---------|
| 交互项（a3）不显著，但某 W 水平下间接效应显著 | 有调节的中介整体**不支持**；间接效应的跨组变异不能作为调节成立的证据；在结论中分别报告"调节不显著"和"间接效应在某水平下成立"，不得混为一谈 |
| 三个 W 水平下 CI 均不含零 | 间接效应稳定存在，但**不随 W 变化**——这是简单中介效应，而非有调节的中介；应将假设改为简单中介并报告 |
| 三个 W 水平下 CI 均含零 | 间接效应在所有水平下均不显著；整个中介链不成立，需在讨论中解释 |
| 条件间接效应方向在不同 W 水平下发生翻转 | 属于"缓冲/增强调节"的极端情形；在讨论中着重分析理论含义，不得忽视 |
| 样本量 < 200 | Bootstrap CI 宽度增加，稳定性下降；在局限性中注明，建议未来研究扩大样本 |
| Mplus LMS 未输出 CFI/RMSEA | LMS 使用数值积分，**不输出传统 SEM 拟合指标**；这是正常现象，在方法部分说明"使用 LMS 估计法，整体模型拟合无法以 CFI/RMSEA 评估" |

**局限性说明模板（有调节的中介未获完整支持）**：
> "尽管调节效应（$\beta_{XW}$ = .XX，$p$ = .XX）在统计上[显著/不显著]，但三个 W 水平下的条件间接效应置信区间[均/部分]含零，提示有调节的中介效应的统计证据[较弱/未获支持]。这可能与本研究的样本量（N = XX）和 W 变量的变异范围有关，未来研究建议扩大样本量以提升统计检验力。"

## 多组分析阶段

| 异常情形 | 处理策略 |
|---------|---------|
| CB-SEM 度量不变性不成立（$\Delta$CFI ≥ .010）| 进行**部分不变性**检验：逐一释放导致不变性失败的载荷约束，确认至少 2 道题项的载荷跨组等同后报告部分度量不变性；在局限性中说明对跨组比较解读的限制 |
| PLS-SEM MICOM 步骤2不通过 | **不应进行 MGA**；在报告中如实说明测量不变性检验未通过，跨组比较不具备统计基础；在局限性中说明并建议未来研究改善量表的跨组适用性 |
| MGA 路径差异 $p$ 在 .05–.10 | 不显著，直接报告为不支持；不得表述为"边缘显著"或"趋势性差异" |
| 两组样本量差异悬殊（如 1:4 以上）| 统计检验力受影响，较小组的 SE 偏大；在局限性中说明，并建议对较小组进行敏感性分析 |

---

## 样本量局限性

| 情形 | 处理建议 |
|------|---------|
| 样本量 < 100，使用 CB-SEM | 提示统计检验力（Statistical Power）不足；建议切换至 PLS-SEM 或补充样本；在局限性中说明 |
| 样本量 100–200，使用 CB-SEM | 提醒用户结果需谨慎解读；建议在局限性中提及 |
| 样本量 < 30，任何方法 | 强烈建议补充样本后再进行 SEM 分析 |

## 局限性说明模板

以下措辞供参考，使用时需根据具体数值修改：

**CMB 超标**：
> "本研究采用单一来源横截面问卷数据，Harman 单因子检验结果显示单因子解释方差为 XX%，超过 50% 的阈值，提示存在一定程度的共同方法偏差风险。尽管本研究采取了[匿名填写/反向计分题项/分批收集等]措施以降低 CMB 的影响，未来研究仍建议采用多时间点或多来源数据以进一步验证本研究的结论。"

**拟合指标略超标**：
> "测量模型中 RMSEA = .09，略高于 .08 的可接受阈值，但 CFI（= .93）和 SRMR（= .06）均达到可接受标准。整体而言，模型拟合处于可接受范围，结果具有一定参考价值，但仍需谨慎解读。"

**假设未获支持**：
> "H2（X → Y）未获支持（$\beta$ = .08，$p$ = .263），这一结果与原假设预期不符。可能的解释包括：[情境因素说明] / [测量局限说明] / [边界条件说明]。未来研究可……"
