# 第 4 步：结构模型评估与假设检验（内模型）

## 目标

检验研究假设路径是否显著成立。**这是整个 SEM 分析的核心——但只有在测量模型合格后，这里的结果才有意义。**

---

## CB-SEM 路径（lavaan）

### 运行代码

```r
library(lavaan)

# ① 定义完整 SEM 模型（测量模型 + 结构路径）
# 将第3步验证通过的 CFA 测量模型部分直接复制过来
model_sem <- '
  # 测量模型（复制自第3步）
  构念A =~ A1 + A2 + A3
  构念B =~ B1 + B2 + B3
  构念C =~ C1 + C2 + C3

  # 结构路径（根据你的研究假设填写）
  构念B ~ 构念A          # H1: A → B
  构念C ~ 构念A + 构念B  # H2: A → C; H3: B → C
'

# ② 运行结构模型
fit_sem <- sem(model_sem,
               data = data,
               estimator = "MLR")

# ③ 查看结果（含拟合度和标准化路径系数）
summary(fit_sem, fit.measures = TRUE, standardized = TRUE)

# ④ 获取参数估计（含置信区间）
parameterEstimates(fit_sem, standardized = TRUE, level = 0.95)

# ⑤ 计算 R²（各内生构念的解释方差）
inspect(fit_sem, "r2")
```

|------|-----------------|------|--------|--------|--------|
| A → B | | | | | |
| A → C | | | | | |

**模型解释力**
- 各内生构念的 $R^2$

## PLS-SEM 路径（SmartPLS）

### 操作步骤

1. 点击 **Calculate → Bootstrapping**
   - 建议设置：**5000 次重抽样**，双尾检验（Two-tailed）
2. 运行完成后，查看以下报告：
   - **Path Coefficients**（路径系数 $\beta$、$t$ 值、$p$ 值、Bootstrap CI）
   - **$R^2$ Values**（各内生构念）
   - **$f^2$ Values**（效应量）
   - **SRMR**（模型整体拟合参考）

### PLS-SEM 结构模型指标清单

请用户提供以下所有数值：

**路径系数（每条假设路径）**
| 路径 | $\beta$ | $t$ 值 | $p$ 值 | 2.5% CI | 97.5% CI |
|------|--------|--------|--------|---------|---------|
| A → B | | | | | |

**模型解释力与拟合**
| 指标 | 值 | 说明 |
|------|---|------|
| $R^2$（各内生构念） | | 解释方差比例 |
| $f^2$（各路径效应量） | | .02=小；.15=中；.35=大 |
| SRMR | | < .08 可接受 |
| $Q^2$（各内生构念） | | > 0 表示具有预测相关性；通过 Blindfolding 获得 |

> **$Q^2$ 操作**：SmartPLS 中点击 **Calculate → Blindfolding**（omission distance 建议设 7），在 Construct Crossvalidated Redundancy 报告中查看各内生构念的 $Q^2$ 值。

## 假设核对

根据第 0 步记录的假设清单，与用户逐条判断：

| 判断标准 | 结论 |
|---------|------|
| $p < .05$ 且方向与假设一致 | ✅ **Supported** |
| $p < .05$ 但方向与假设相反 | ❌ **Not Supported**（反向显著，需在讨论中解释） |
| $p ≥ .05$ | ❌ **Not Supported** |

> ⚠️ **严格禁止使用**"边缘显著""趋近显著""接近显著"等模糊表述。若 $p = .06$，直接报告为不显著。可在讨论部分提及方向趋势，但统计结论必须清晰。
