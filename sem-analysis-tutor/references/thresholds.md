# 指标判断阈值快速参考

## 显著性标准

| $p$ 值 | 含义 | 标注 |
|--------|------|------|
| $p < .001$ | 极显著 | *** |
| $p < .01$ | 高度显著 | ** |
| $p < .05$ | 显著 | * |
| $p ≥ .05$ | 不显著 | ns |

> ⚠️ **禁止使用**"边缘显著"（marginally significant）、"趋近显著"等模糊表述。

---

## CB-SEM 模型拟合指标

| 指标 | 良好标准 | 可接受标准 | 不可接受 |
|------|---------|----------|---------|
| $\chi^2/df$ | < 2.0 | < 3.0 | ≥ 5.0 |
| CFI | ≥ .95 | ≥ .90 | < .90 |
| TLI | ≥ .95 | ≥ .90 | < .90 |
| RMSEA | < .05 | < .08 | ≥ .10 |
| SRMR | < .05 | < .08 | ≥ .10 |

## 测量模型指标

### CB-SEM（CFA）

| 指标 | 可接受标准 | 良好标准 |
|------|-----------|---------|
| 标准化因子载荷 | ≥ .50 | ≥ .70 |
| Cronbach's $\alpha$ | ≥ .70 | ≥ .80 |
| 组合信度（CR） | ≥ .70 | ≥ .80 |
| AVE | ≥ .50 | ≥ .60 |
| HTMT | < .90 | < .85 |

> **关于区分效度方法**：HTMT 为当前首选。**Fornell-Larcker 准则**已被证明准确性不足（Henseler et al., 2015），不应作为主要证据，仅供补充参考。**HTMT2**（Roemer et al., 2021）为更新版本，SmartPLS 5 已内置，顶刊投稿建议一并报告。

### PLS-SEM（SmartPLS）

| 指标 | 可接受标准 | 良好标准 |
|------|-----------|---------|
| 外部载荷（Outer Loading） | ≥ .60 | ≥ .70 |
| 组合信度（CR / $\rho_c$） | ≥ .70 | ≥ .80 |
| $\rho_A$（rho_A） | ≥ .70 | — |
| AVE | ≥ .50 | ≥ .60 |
| HTMT | < .90 | < .85 |
| $Q^2$（内生构念） | > 0 | 通过 Blindfolding 获得，见"PLS-SEM 整体模型拟合"节 |

### 效应量 $f^2$（Cohen, 1988）

| $f^2$ 值 | 效应大小 |
|---------|---------|
| .02 | 小效应 |
| .15 | 中等效应 |
| .35 | 大效应 |

### $R^2$ 解读（社会科学领域参考）

| $R^2$ 值 | 解读 |
|---------|------|
| < .10 | 弱解释力 |
| .10 – .30 | 中等解释力 |
| > .30 | 较强解释力 |

### VIF（共线性）

| VIF 值 | 判断 |
|--------|------|
| < 3.3 | 无共线性问题（PLS-SEM CMB 检验标准） |
| < 5.0 | 理想（一般结构模型） |
| < 10.0 | 可接受 |
| ≥ 10.0 | 严重多重共线性 |

## PLS-SEM 整体模型拟合与预测相关性

| 指标 | 标准 | 说明 |
|------|------|------|
| SRMR | < .08 可接受；< .05 良好 | PLS-SEM 主要参考拟合指标 |
| $Q^2$（Stone-Geisser） | > 0 | 模型对该内生构念具有预测相关性；通过 Blindfolding 程序获得 |

> 注：PLS-SEM **不使用** CFI/TLI/RMSEA 等基于协方差矩阵的拟合指标。

### $Q^2$ 效应量（$q^2$）参考

| $q^2$ 值 | 预测相关性强度 |
|---------|-------------|
| .02 | 小 |
| .15 | 中 |
| .35 | 大 |

> SmartPLS 操作路径：**Calculate → Blindfolding**（omission distance 通常设为 7），在 **Construct Crossvalidated Redundancy** 报告中查看 $Q^2$ 值。
