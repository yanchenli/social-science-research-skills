# sem-analysis-tutor

> SEM 分析全流程辅导助手 —— 像带教研究生一样，一步一步陪你做完结构方程模型。

**版本**：1.0.0 ｜ **适用**：管理学、市场营销、消费者行为学研究生 ｜ **规模**：SKILL.md + 12 个 references

---

## 它解决什么问题

零基础研究生做 SEM 的典型困境不是「不会点软件」，而是：

- 不知道自己该用 CB-SEM 还是 PLS-SEM，两套指标体系混着看
- 指标不达标（载荷低于 .70、AVE 不足 .50）不知道该怎么办
- 跑出一堆数字，不知道哪些必须报告、哪些可以不报
- 拿不准「这个结果算不算支持我的假设」

这个技能把 SEM 拆成 **step0 → step7** 的固定流程，**每次只推进一步**，
你反馈结果后它诊断，通过了才进下一步。

---

## 核心理念

**像带教研究生一样，一步一步地陪用户完成分析——绝不一次性倾倒所有信息。**

> ⚠️ **数据诚信原则**：报告中所有数值必须来自用户提供的软件输出，
> **不得估算、捏造或替换任何数据**。

### 五条核心交互原则

1. **强制分步制**——每次只推进一个步骤，完成指导后停下来等你反馈结果
2. **双轨区分**——CB-SEM 与 PLS-SEM 的指标体系完全不同，**永远不混用**
3. **零基础友好**——专业术语首次出现时给一句话直觉解释
   （例：「AVE 可以理解为：量表题项平均能解释多少比例的构念方差」）
4. **异常不回避**——指标未达标必须共同讨论修复方案，或在报告中诚实说明局限性，**不得绕过**
5. **不使用模糊表述**——p = .06 直接报告为不显著，**禁止「边缘显著」「趋近显著」**

## 标准操作流（SOP）

```
第 0 步 → 需求评估与方法诊断
第 1 步 → 数据体检（描述统计、缺失值、正态性）
第 2 步 → 共同方法偏差（CMB）检验
第 3 步 → 测量模型评估（外模型 / CFA）
第 4 步 → 结构模型评估与假设检验（内模型）
第 5 步 → 中介 / 调节效应分析（如适用）
第 6 步 → 生成完整学术报告
```

第 0 步**不能跳过**——技能会先了解你的背景（构念数、样本量、软件、期刊目标），
再推荐方法。直接要代码的请求会被它挡回来。

---

## 双轨支持

| | CB-SEM | PLS-SEM |
|---|---|---|
| 软件 | lavaan (R) / AMOS / Mplus | SmartPLS / seminr (R) |
| 指标体系 | CFI、TLI、RMSEA、SRMR 等拟合指标 | 外部载荷、AVE、CR、HTMT、Q² |
| 技能覆盖 | step3/step4 双轨并列，附 FL 降级注释 | 同左，含 Stone-Geisser Q² |

额外覆盖的进阶场景（各有专章）：

- **有调节的中介**（moderated mediation）——CB-SEM + PLS-SEM 全流程
- **潜变量 × 潜变量调节**——Mplus LMS 法，以及 modsem 替代方案
- **多组分析（MGA）**——CB-SEM 测量不变性嵌套检验 + PLS-SEM MICOM/MGA

## 使用示例

```
我要做结构方程模型，模型里有 5 个构念，样本 320 份，
用的是 SmartPLS，想投二区期刊。这是我的数据文件。
```

技能不会直接给你代码，而是先做第 0 步诊断：确认构念是 reflective 还是 formative、
样本量与构念数比例、是否有中介/调节，然后才进入第 1 步数据体检。
每一步结束它会明确告诉你「现在需要把什么结果反馈给我」，然后等你。

## 报告撰写规范

- 使用标准 LaTeX 统计符号：$\beta$、$\chi^2$、$R^2$、$p$、$t$、$z$、$f^2$、$\alpha$、$\rho_A$
- 客观严谨的学术口吻，第三人称被动语态
- 数值保留位数与软件原始输出一致（通常 2–3 位小数）
- 未达标指标在「局限性」部分如实说明，不得回避
- 假设汇总用 Markdown 表格，每条明确标注 ✅ Supported / ❌ Not Supported

---

## 与 stats-results-writer 的分工

**这个技能带你「做」分析**——读数据、判断指标、处理异常、决定下一步。
如果你已经跑完分析、只想把输出转成 APA 段落，用
[`stats-results-writer`](../stats-results-writer/)。

两个一起用的典型顺序：`sem-analysis-tutor` 走完 step0–step5 →
用 `stats-results-writer` 写 Results → 回到 `sem-analysis-tutor` 的 step6 做报告核查。

---

## 边界与注意事项

- **它不会替你把不达标的指标说成达标。** 指标不达标时，它会和你讨论修复方案，
  或指导你如何在局限性部分诚实说明——但不会帮你掩盖。
- **所有数值必须来自你的软件输出。** 技能明确禁止估算、捏造或替换数据。
- **它不做数据造假。** 若数据本身无法支撑假设，技能的方向是
  「如何诚实报告」，而不是「怎么调才能显著」。
