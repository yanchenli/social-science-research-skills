# literature-gap-synthesizer

> 文献系统梳理与研究缺口挖掘 —— 先诊断，后写作。

**版本**：1.0.0 ｜ **适用**：商科 MS/PhD/DBA 学生及教师 ｜ **规模**：SKILL.md + 2 个 references

**中文** | [English](README.en.md)

---

## 它解决什么问题

「这个方向有人做过吗」「这块文献到底缺什么」——这两个问题几乎每个选题阶段都要回答，
但多数人是随手搜几篇、凭印象说「研究较少」。

这个技能把「一堆分散的文献」变成一张能看出**共识在哪、冲突在哪、缺口在哪**的地图，
再把缺口转成一句站得住脚的研究定位。

---

## 核心理念

**先诊断，后写作。**

本技能做的是学术论文最前端、也最容易被跳过的一步。产出直接对接
[`academic-writing-assistant`](../academic-writing-assistant/) 阶段 1 的研究定位工具，
可以无缝续写 Introduction。

> ⚠️ **不编造文献。** 所有文献必须来自真实检索或用户提供的材料。
> 无法核实的一律标 `[待核实]`，定稿前建议过一遍
> [`academic-citation-auditor`](../academic-citation-auditor/) 做真实性核查。

## 工作流程（五阶段）

| 阶段 | 目标 |
|---|---|
| 1. 范围界定与检索 | 把模糊主题收窄成可检索的范围，建立检索策略 |
| 2. 系统梳理与综合矩阵 | 整理成可横向比较的矩阵 |
| 3. 主题聚类与缺口诊断 | 看出结构：共识、冲突、没人碰过的地方 |
| 4. 缺口评估与研究定位 | 从候选缺口里选一个，写成定位陈述 |
| 5. 交付与对接下一步 | 文档 + 交接给下一个技能 |

### 阶段 1：检索式按三个维度拆

不要用一个大而化之的关键词囫囵搜索。按「**构念 × 理论 × 方法/情境**」拆：

```
品牌资产 × 数字化情境：
- 构念层：brand equity, brand asset, customer-based brand equity
- 理论层：signaling theory, self-congruity theory, social identity theory
- 方法/情境层：social media, short video platform, cross-cultural
```

按构念**分批**检索，不要一次塞进所有关键词——分批更容易看出每个子领域各自的研究密度和空白。

### 阶段 2：综合矩阵的八个字段

作者（年份）｜文献类型（含期刊等级）｜理论基础｜核心构念/变量｜研究方法｜
样本与情境｜核心发现（用自己的话转述，不摘抄）｜局限性

篇数 20 以内用 Markdown 表格；更多、且后续要排序筛选时改用 `.xlsx`。

**构念一致性检查**是这一步的重点：同一个词，不同文献是不是在测不同的东西？
同一个理论，不同文献的边界条件是否矛盾？发现不一致要明确标出，不要平滑掉——
这是阶段 3 诊断缺口的重要原料。

### 阶段 3：先分清两种缺口

这组区分来自 Sandberg & Alvesson (2011, *Organization*)：

| 如果你发现的是… | 更接近 |
|---|---|
| 某个变量关系还没人在某情境测过 | gap-spotting（应用型） |
| 现有研究结论互相矛盾、没人解释为什么 | gap-spotting（混淆型） |
| 一个明显相关但完全没人研究的角落 | gap-spotting（忽视型） |
| 领域默认的一个前提假设本身可能是错的 | **problematization** |

两者没有优劣之分，但决定了研究故事的**野心与难度**，也决定后面怎么定位贡献。

## 一条容易被忽略的纳入标准

**排除本科生与硕士学位论文。**

理由写在技能里：未经同行评审、答辩把关较松。检索阶段直接跳过，不纳入综合矩阵，
即便搜到也不作为证据使用。博士学位论文可纳入（经委员会答辩把关，可靠性接近同行评审）。

这条判断在实务上很重要——很多「没人研究过」的印象，其实来自只搜到了低质量来源。

## 使用示例

```
我在做品牌拟人化，想看看这块文献到底缺什么。手头有 18 篇，附清单。
```

技能会搭综合矩阵、做构念一致性检查、聚出共识/冲突/忽视角落，
给出 2–4 个候选缺口并按新颖性、有趣程度、可行性、理论贡献潜力、实践价值评估，
最后写成定位陈述：

```
本研究探讨 [自变量/现象] 对 [因变量/结果] 的影响，
聚焦于 [情境/边界条件]，
以 [理论基础] 为理论视角，
弥补 [现有研究空白] 的不足。
```

这个模板与 `academic-writing-assistant` 阶段 1.2 **完全一致**，可以直接复制过去。

## 边界与注意事项

- **不编造文献。** 无法核实的一律 `[待核实]`，不凭印象补全作者/年份/期刊。
- **不代替判断。** 缺口选哪个、理论故事怎么讲，最终判断权在研究者。
- **不平滑矛盾。** 文献间的冲突、构念操作化的不一致，如实呈现。
- **分阶段交付。** 文献量大时不要一次性生成过长内容，每阶段先给用户看一眼。
- **实践类期刊**（如 HBR、MIT Sloan Management Review）只能用于应用型论文的实践背景与建议，
  不作学术论证主力。

## 与相邻技能的分工

- **文献已理清、只是要写成一段话** → 用 [`academic-writing-assistant`](../academic-writing-assistant/) 阶段 2。
  它有一个轻量的缺口分类步骤。本技能做的是更前面、更重的活。
- **缺口定了，要设计实验或量表** → [`social-science-experiment-designer`](../social-science-experiment-designer/) /
  [`scale-research`](../scale-research/)。
- **怀疑文献本身有假** → [`academic-citation-auditor`](../academic-citation-auditor/)。
- **贡献写不清楚** → [`discussion-conclusion-writer`](../discussion-conclusion-writer/) 阶段 2 会回头对表。
