# 文献系统梳理与研究缺口挖掘 — Literature Synthesis & Gap Analysis

## 核心理念

**先诊断，后写作。** 本skill做的是学术论文最前端、也最容易被跳过的一步：把一堆分散的文献变成一张能看出"共识在哪、冲突在哪、缺口在哪"的地图，再把缺口转成一句站得住脚的研究定位。AI负责检索、整理、交叉比对、诊断缺口类型；研究者负责判断范围边界、评估哪个缺口真正值得做、拍板理论故事怎么讲。

产出的定位陈述直接对接 `academic-writing-assistant` 阶段1的研究定位工具，可以无缝续写Introduction。

> ⚠️ **重要提醒**：本skill整理的所有文献必须来自真实检索结果或用户提供的材料，绝不编造文献。无法通过检索确认的文献一律标注`[待核实]`，建议定稿前过一遍 `academic-citation-auditor` 做真实性核查。

**与相邻skill的分工**：`academic-writing-assistant`的阶段2也有一个轻量的缺口分类步骤，适合"文献已经理清楚、只是要写成一段话"的情况。本skill做的是更前面、更重的活——文献量大、主题模糊、或者需要系统性地论证"为什么这是个真缺口"时用本skill；定位确定之后再交给`academic-writing-assistant`落笔成文。

## 快速入口：你目前在哪个阶段？

| 用户情况 | 进入阶段 |
|---------|---------|
| 只有一个宽泛主题/构念，还没开始找文献 | **阶段1** — 范围界定与检索 |
| 已有一批文献（清单/PDF/笔记），比较乱 | **阶段2** — 系统梳理与综合矩阵 |
| 文献已经理清楚，想知道这堆文献里到底缺什么 | **阶段3** — 主题聚类与缺口诊断 |
| 已经看出几个候选缺口，纠结选哪个/站不站得住脚 | **阶段4** — 缺口评估与研究定位 |
| 定位已经想清楚，需要整理成交付文档 | **阶段5** — 交付与对接下一步 |
| 帮学生proposal把关理论新颖性 | 从**阶段3**或**阶段4**进入，跳过检索 |

## 阶段1 — 范围界定与检索

**目标**：把一个模糊主题收窄成可检索的范围，建立检索策略。

### 1.1 信息收集

| 信息项 | 说明 | 若用户未提供 |
|--------|------|------------|
| 研究主题/核心构念 | 一句话描述 | 必须询问 |
| 用途 | 自己选题 / 论文写作中期查缺口 / 学生proposal把关 | 从上下文推断，不确定则问 |
| 学科领域 | 营销、消费者行为、品牌管理、HRM、OB、战略等 | 从主题推断 |
| 时间窗口 | 近5年/10年/不限 | 默认近10年为主，奠基性文献不受限 |
| 已有文献量 | 用户手头已有多少篇 | 询问；0篇则从检索开始 |
| 检索深度 | 快速摸底（10-15篇） vs 系统综述级（30篇以上） | 默认快速摸底，用户可要求加深 |

### 1.2 检索策略

用"构念 × 理论 × 方法/情境"三个维度拆解检索式，不要用一个大而化之的关键词囫囵搜索：

```
示例（品牌资产 × 数字化情境）：
- 构念层：brand equity, brand asset, customer-based brand equity
- 理论层：signaling theory, self-congruity theory, social identity theory
- 方法/情境层：social media, short video platform, cross-cultural
```

检索时：
- 用所在环境提供的检索能力做论文级检索，注意区分学术数据库结果和一般网页/博客结果，优先Google Scholar、Web of Science、期刊官网等来源
- 每一条文献都要能给出真实来源（作者、年份、期刊、可核实的链接或DOI），不确定的一律标`[待核实]`，绝不凭印象补全文献信息
- 按构念分批检索，不要一次塞进所有关键词——分批更容易看出每个子领域各自的研究密度和空白

### 1.3 纳入/排除标准

明确告诉用户你在用什么标准筛选（可参考PRISMA思路但不必照搬全套流程）：
- 纳入：与核心构念直接相关、发表在同行评审期刊/会议、时间窗口内；博士学位论文可纳入（经委员会答辩把关，可靠性接近同行评审）
- 排除：仅提及构念但非核心议题、灰色文献（除非用户特别要求纳入行业报告）、明显掠夺性期刊、**本科生与硕士生学位论文**（未经同行评审、答辩把关较松，检索阶段直接跳过，不纳入综合矩阵，即便搜到也不作为证据使用）

检索/收集完成后，进入阶段2。

---

## 阶段2 — 系统梳理与综合矩阵

**目标**：把检索到/用户提供的文献，整理成一张可以横向比较的综合矩阵。

### 2.1 综合矩阵字段

| 字段 | 说明 |
|------|------|
| 作者（年份） | Author (Year) |
| 文献类型 | 期刊论文／会议论文／博士学位论文——期刊论文另需标注期刊等级，见下方说明 |
| 理论基础 | 用的什么理论视角 |
| 核心构念/变量 | 自变量、因变量、中介、调节 |
| 研究方法 | 实验／问卷调查／质性访谈／二手数据／元分析 |
| 样本与情境 | 人群、行业、文化/地区、样本量 |
| 核心发现 | 1-2句话概括，用自己的话转述，不直接摘抄原文 |
| 局限性 | 文中明说的，或你判断出的方法/情境局限 |

篇数较少（20篇以内）时直接用markdown表格呈现；篇数较多、用户后续要排序筛选时，建议改用`.xlsx`产出（用所在环境提供的表格生成能力，如 `openpyxl`）。

> 期刊等级标注：期刊论文类条目需对照`references/journal-tiers.md`同时标注层级（顶级／优秀／可信／实践类），清单外期刊按该文件"使用规则"处理，缺乏依据的一律标`[等级待核实]`，不得臆断；实践类期刊（如HBR、MIT Sloan Management Review）只能用于应用型论文的实践背景与建议部分，不作学术论证主力。

### 2.2 构念一致性检查

跨文献比较同一个构念的定义和操作化是否一致——这本身经常就是缺口的来源之一：
- 同一个词，不同文献是不是在测不同的东西？
- 同一个理论，不同文献的边界条件设定是否矛盾？

发现不一致时明确标出来，不要平滑掉，这是阶段3诊断缺口的重要原料。

综合矩阵搭好后，进入阶段3。

---

## 阶段3 — 主题聚类与缺口诊断

**目标**：从矩阵里看出结构——共识在哪、冲突在哪、没人碰过的地方在哪。

### 3.1 主题聚类

任选一种维度（或结合使用）对文献分组：

| 维度 | 适用场景 |
|------|---------|
| 按主题/构念分组 | 综述导向、想看某个构念研究得够不够 |
| 按理论脉络分组 | 想看理论演进、有没有理论断层 |
| 按结论分组（支持/挑战/提出边界条件） | 想看领域内有没有真正的争议 |

### 3.2 共识与冲突地图

对每个聚类，明确回答三个问题：
1. 这些文献一致同意什么？
2. 哪些地方结论互相矛盾，且矛盾还没被解释？
3. 大家都绕开了什么（明明相关，但没人研究）？

### 3.3 缺口类型诊断

先判断这是**gap-spotting**（在现有框架内找漏洞）还是**problematization**（挑战现有框架本身的假设）——这决定了研究故事的野心和难度，二者没有优劣之分，但影响后面怎么定位贡献。这组区分来自Sandberg & Alvesson (2011, *Organization*)，详细框架、三种gap-spotting子类型和例句见`references/gap-taxonomy.md`。这里给一个快速判断表：

| 如果你发现的是… | 更接近 |
|---|---|
| 某个变量关系还没人在某情境测过 | gap-spotting（应用型） |
| 现有研究结论互相矛盾、没人解释为什么 | gap-spotting（混淆型） |
| 一个明显相关但完全没人研究的角落 | gap-spotting（忽视型） |
| 领域默认的一个前提假设本身可能是错的 | problematization |

在gap-spotting范围内，再用内容维度进一步定位缺口类型（理论/方法/情境/人群/机制/证据冲突——定义和中英文例句见references文件）。

**示例（简化版，品牌管理情境）**：
主题：品牌拟人化（brand anthropomorphism）与消费者信任
- 共识：多数研究发现适度拟人化能提升信任和情感依恋
- 冲突：拟人化程度是否存在类似"恐怖谷"的边际递减甚至反转效应，不同研究结论不一致
- 忽视角落：几乎所有研究都在B2C语境下做的，B2B采购情境里的品牌拟人化几乎空白
→ 候选缺口（情境缺口，gap-spotting/忽视型）：B2B品牌拟人化对采购决策信任的影响，是否也存在边际效应的拐点

列出2-4个候选缺口，每个用1-2句话说清楚"现有文献做了什么、没做什么"，进入阶段4。

---

## 阶段4 — 缺口评估与研究定位

**目标**：从候选缺口里选出最值得做的一个，写成一句站得住脚的定位陈述。

### 4.1 缺口评估

| 评估维度 | 关键问题 |
|---------|---------|
| 新颖性 | 真的没人做过，还是只是没搜到？有没有同类工作正在投稿中的风险？ |
| 有趣程度 | 填上这个缺口，会不会改变大家原来的理解，还是只是意料之中的验证？（参考Davis 1971"That's Interesting!"的判断逻辑） |
| 可行性 | 数据/被试/方法是否可得？是否能对接`social-science-experiment-designer`或`scale-research`？ |
| 理论贡献潜力 | 能不能讲出一个完整的因果/理论故事，而不只是"填个空" |
| 实践价值 | 对管理者/从业者是否有可操作的启示 |

不必每个维度都满分，但至少要对新颖性和可行性给出有把握的答案。

### 4.2 研究定位陈述

用这个模板（与`academic-writing-assistant`阶段1.2完全一致，方便直接衔接）：

```
本研究探讨 [自变量/现象] 对 [因变量/结果] 的影响，
聚焦于 [情境/边界条件]，
以 [理论基础] 为理论视角，
弥补 [现有研究空白] 的不足。
```

写完后回头检查：这句话里的"不足"，是不是阶段3诊断出来的那个缺口类型？如果对不上，说明定位还没想清楚，回到阶段3。

---

## 阶段5 — 交付与对接下一步

**目标**：把前面的分析整理成一份可以保存、可以继续用的文档。

### 5.1 交付文档结构

1. 范围与检索策略说明
2. 文献综合矩阵
3. 主题聚类与共识/冲突地图
4. 候选缺口清单与评估
5. 最终研究定位陈述
6. 文献清单（含`[待核实]`标注）

**必须**用所在环境提供的文档生成能力（如 `python-docx` 库或 `pandoc` 转换；若环境中已有专门的 docx 技能，优先使用它）生成`.docx`；矩阵部分篇数多时可另附`.xlsx`（用表格生成能力，如 `openpyxl`）。文档中所有引用信息保留`[待核实: Author, Year]`标注，不要在生成文档时"抹平"这个提示。

### 5.2 下一步

- 文献清单较大、或用户对真实性没把握时，建议运行`academic-citation-auditor`做一次核实
- 定位陈述确定后，直接交给`academic-writing-assistant`（阶段1起步），二者用的是同一套定位模板，可以直接复制过去
- 若缺口涉及需要新设计实验或量表，提示用户可以接着用`social-science-experiment-designer`或`scale-research`

## 重要原则（贯穿全程）

1. **不编造文献**：所有文献必须来自真实检索或用户提供的材料，无法核实的一律标`[待核实]`，不得凭印象补全作者/年份/期刊信息
2. **不代替判断**：缺口选哪个、理论故事怎么讲，AI提供诊断和选项，最终判断权在研究者
3. **不平滑矛盾**：文献间的冲突、构念操作化的不一致，是缺口诊断的原料，如实呈现，不要为了让综述读起来顺而抹平
4. **分阶段交付**：文献量大时不要一次性生成过长内容，每完成一个阶段先给用户看一眼再继续
