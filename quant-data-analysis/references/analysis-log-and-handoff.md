# 分析记录与结果包模板

配合`SKILL.md`阶段5使用。

## 一、分析记录（每次分析都要有）

```
【分析记录】
1. 数据
   - 文件名与版本：
   - 总收集N：        清理后最终N：
   - N变化流水：总收集 → 删除重复(n=) → 按规则1排除(n=) → 按规则2排除(n=) → 最终

2. 预注册与计划
   - 是否预注册：是/否（链接或编号）
   - 分析是否按计划：是/否；偏离之处及原因：
   - 计划之外的分析（一律标注"探索性"）：

3. 排除规则（须写明是否在看结果前确定）
   - 规则1：              确定时间：分析前/分析后
   - 规则2：

4. 缺失与离群值
   - 缺失：变量、比例、处理方式（本次为完整案例分析／其他）
   - 离群值：识别规则（中位数/MAD）、标记人数、处理方式、含/不含两版的结论对比

5. 检验与选择理由
   - DV、因子、协变量：
   - 使用的检验及理由（例如：方差明显不齐→加--robust）：
   - 是否换过检验、为什么换：

6. 敏感性分析
   - 含/不含排除：结论一致／不一致（说明）
   - 含/不含离群值：
   - 经典F vs 稳健/Welch：

7. 运行环境
   - 脚本与参数：（例如 factorial_anova.py --dv y --factors A,B --robust）
   - Python与库版本：
```

## 二、结果包（交给`stats-results-writer`）

写作阶段需要的都在这里，缺哪项就先补：

| 项目 | 内容 |
|---|---|
| 样本 | 总N、最终N、各单元格n、排除情况 |
| 描述统计 | 各单元格均值、标准差（及必要时置信区间） |
| 假设诊断 | 方差齐性诊断、残差分布、采用的稳健处理 |
| 主检验 | F（df1, df2）或t（df）、p、偏η²（及偏ω²）；回归给系数b、SE、t、p、置信区间、ΔR² |
| 事后/简单效应 | 均值差、SE、t、df、p（原始与Holm校正）、置信区间、d/g |
| 操纵检验 | 先于假设检验报告 |
| 敏感性结果 | 结论是否随处理方式变化 |
| 探索性标注 | 哪些分析是预注册之外的 |

交接时对`stats-results-writer`说明：**数字以脚本输出为准，写作中不得改动**；若敏感性分析显示结论不稳，Results里要如实反映，不能写成稳健发现。

## 三、与评审skill的对应

`dissertation-peer-review`会查缺失数据与离群值处理、操纵检验、效应量、研究者自由度（分析选择的透明度）。分析记录里对应的部分：第3–5项（排除、缺失、离群值、检验选择）、结果包里的操纵检验与效应量、第2项的预注册与偏离说明。分析记录写得清楚，评审时这些核查项就有据可查。
