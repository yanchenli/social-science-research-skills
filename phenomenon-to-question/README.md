# phenomenon-to-question

> 从现象到研究问题 —— 研究链条最前端的那一步，也是最少人教的那一步。

## 它解决什么问题

研究生的第一道坎不是做不出结果，是**不知道自己该研究什么**。

他们通常带着一个模糊的观察来：

> 「我觉得现在大家都在买平替，这个能做研究吗？」
> 「我们公司周报公开之后，大家好像都在表演，这算个现象吗？」
> 「平台老改抽成规则，卖家很痛苦，这个值得研究吗？」

而现有工具都假设**你已经有一个构念了**：文献工具问「你的研究主题是什么」，实验设计工具问「你的核心假设是什么」。**没有人负责把「我观察到一件事」变成「一个可以研究的问题」。**

这个技能补的就是这一步。

---

## 核心理念

| 原则 | 含义 |
|---|---|
| **现象先于构念，构念先于假设** | 跳过前两步直接想假设，做出来的是「文献里已有结论的又一次验证」 |
| **压力测试优于快速建构** | 真正的洞察不在于快速解释一个现象，而在于建一个经得起反复追问的结构 |
| **不预设学科** | 同一个现象可能同时属于营销、OB、信息系统、金融。先问「谁在研究它」，不要先贴标签 |
| **不预设方法** | 定量还是定性由问题性质决定，不是由学生偏好或导师偏好决定 |
| **「不值得研究」是合格产出** | 现象不成立、规模太小、无法观察时，如实说出来，比硬凑一个题目负责 |

## 工作流程（五阶段）

| 阶段 | 做什么 | 产出 |
|---|---|---|
| **1 现象锚定** | 把「一个模糊感受」变成「一个有边界的实例」。要求具体化，三问定位：什么变了、相对于什么、谁受影响 | 一段 150 字以内的现象陈述（只写观察，不写解释） |
| **2 前提压力测试** ★ | 六项逐项过：真实性、规模、新颖性、可观察性、反例、机制性 | 三档判定：通过 / 需要收窄 / 不成立 |
| **3 拆解与理论透镜** | 拆成构件（主体、层次、情境、时间、候选 DV/IV）；用三步法找理论 | 2–3 个透镜，每个说清能解释什么、解释不了什么、**预测什么可观察的差异** |
| **4 候选问题** | 生成 2–3 个候选研究问题，判断定量还是定性 | 每个附：需要什么数据、方法倾向、贡献、主要风险 |
| **5 可行性预筛与交接** | 数据、时间、伦理、能力、风险五项过筛 | 一页「研究问题简报」+ 明确的下一步 |

> **阶段 2 是整个技能最不能跳过的一步**，也是最容易被跳过的一步。学生最常犯的错是抓着一个媒体热词不放，而六项测试会把它逼到「有数据吗、有反例吗、能测量吗」上。

## 跨领域是怎么做到的

这个技能不绑定营销。三处设计：

**① 理论部分不给学科清单，给找理论的方法。**
「定位学科 → 找同义词 → 选透镜」三步，配一张 8 种现象内核 × 6 个学科的**同义词对照表**。同一件事在不同领域叫法完全不同——「跟着别人做」在营销叫从众、在 OB 叫社会影响、在金融叫羊群行为、在战略叫制度同构。**不找同义词，学生会在一个领域的文献里打转，错过另外三个领域已经做过的工作。**

**② 六项压力测试，每一项配四个领域的例子。**
真实性一项：营销要客单价与搜索指数，OB 要离职率与工时记录，会计要应计分布与阈值断点，运营要进口来源国集中度。

**③ 八类机制家族（跨领域通用）**：认知 / 动机与自我 / 社会影响 / 信息与不确定性 / 激励与契约 / 结构与制度 / 时间与过程 / 情感与体验。学生说「不知道有哪些理论」时，先定位家族再选具体理论，比从理论名硬找快得多。

## 用法示例

```
我观察到公司推行周报公开之后，员工开始在周报里互相引用彼此的工作内容，
而且周报写得比实际做得多。这个现象值得研究吗？能做成什么样的问题？
```

技能会先要求具体化（哪家公司、什么时间、什么层级的员工），再逐项做压力测试（有数据吗？是单一公司还是普遍？是老现象换名字吗？），然后拆构件、给 2–3 个理论透镜（印象管理、信息不对称、实践理论），最后给 2–3 个候选问题与可行性判断。

## 边界与注意事项

- **不负责文献检索与缺口诊断。** 那是 `literature-gap-synthesizer` 的活。本技能只到「有一个值得研究的问题」为止。
- **不负责假设审查与实验设计。** 那是 `social-science-experiment-designer` 的活。本技能给出候选问题，不给出可检验的假设。
- **不编造文献、理论、学者。** 只提确信存在的条目；不确定时明说，并给出核实路径。
- **不替学生决定研究什么。** 给候选、给依据、给风险，选择权在学生。
- **不保证现象成立。** 六项测试里任何一项「不通过」，本技能会直说这个方向做不了、需要什么条件才能做。

## 与相邻技能的分工

| 情形 | 用哪个 |
|---|---|
| 有一个**现象**，不知道能不能做研究 | **本技能** |
| 有一个**宽泛主题**，要查文献、找缺口 | [`literature-gap-synthesizer`](../literature-gap-synthesizer/) |
| 有**明确假设**，要设计实验、接受审查 | [`social-science-experiment-designer`](../social-science-experiment-designer/) |
| 现象复杂、要看当事人怎么理解 | [`qualitative-research-methods`](../qualitative-research-methods/) |
| 要读一批论文、把变量整理成表 | [`paper-variable-extraction`](../paper-variable-extraction/) |
| 要合成一批实证研究 | [`systematic-review`](../systematic-review/) |
| 要选刊、投稿 | [`journal-submission`](../journal-submission/) |

> **与 `literature-gap-synthesizer` 的区分**：起点不同。从**现象**出发 → 本技能；从**主题/构念**出发 → 那个技能。
