# 研究问题简报 / Research Question Brief

> 一页纸。用途不是交作业，是**三个月后回来时还能说清当初为什么选这个问题**。
>
> 填写原则：写不出来的格子就空着并注明"待补"，**不要为了填满而编**。

## 示例 A · 营销（定量为主）

```markdown
# 研究问题简报

**领域**：营销 / 消费者行为

## 1. 现象陈述
2023 年起，一部分消费者在社交平台主动发布"平替"清单，明确标注自己买的不是原版；
评论区出现互相验证真伪、交换购买渠道的协作行为。同期同品类原版的搜索热度下降。

## 2. 前提压力测试

| 检验 | 结论 | 依据 / 待补证据 |
|---|---|---|
| 真实性 | 通过 | 平台话题量、平替关键词搜索指数可查；已确认 3 个具体账号的内容形态 |
| 规模 | 待补 | 目前只有话题量，缺品类分布与实际购买转化 |
| 新颖性 | 通过（需限定） | 老现象（性价比消费）的新形态：公开标注 + 协作验真 |
| 可观察性 | 通过 | 内容可抓取，发布者可访谈，受众反应可实验 |
| 反例 | 有且能区分 | 反例：也有大量"假装买平替实则买原版"的炫耀型内容，需在编码时区分 |
| 机制性 | 可陈述 | 猜测：公开标注是向"懂行受众"发信号；可推出"受众构成影响发布意愿" |

**总判定**：进入下一阶段（规模一项需补数据）

## 3. 构件拆解
- 行为主体：发布者（消费者）、受众（同社群成员）
- 分析层次：个体 + 社群
- 情境：图文社交平台，服饰与美妆品类
- 时间结构：横断面为主，内容发布时间可做短窗口
- 要解释的（候选 DV）：公开标注意愿、标注的具体形式（明示/暗示）
- 用来解释的（候选 IV）：受众构成（懂行比例）、品类价格透明度

## 4. 理论透镜

| 透镜 | 能解释什么 | 解释不了什么 | 预测什么可观察的差异 |
|---|---|---|---|
| 信号理论 | 为什么要公开标注 | 为什么是协作验真而非各自发布 | 受众中懂行者比例高时，标注更具体、更愿意公开 |
| 身份认同 | 为什么变成群体身份 | 为什么集中在某些品类 | 身份被质疑时标注行为增强 |
| 制度同构 | 为什么短期内跨平台扩散 | 个体差异 | 同侪采用率越高，个体采用概率越高，且与价格敏感度无关 |

**推荐**：信号理论为主、身份认同为辅。理由：现象的核心异常是"主动暴露自己买了便宜的"，
这在纯经济理性下说不通，信号解释最直接。

## 5. 候选研究问题

### 问题 A
- **问句**：消费者公开标注"我买的是平替"，是在向谁传递什么信号？
- **类型**：② 为什么
- **需要的数据**：平台内容（约 2,000 条）+ 发布者访谈（20–25 人）+ 受众实验（约 300 人）
- **方法倾向**：混合——访谈确定信号对象，实验检验受众反应
- **贡献**：信号理论假设信号成本可观察；"平替"的信号成本恰恰不可观察，构成边界修正
- **主要风险**：访谈对象难触达；"平替"定义跨品类不一致

### 问题 B
- **问句**：品类价格透明度如何影响消费者采用"平替"标注的意愿？
- **类型**：③ 何时 / 对谁
- **需要的数据**：平台内容 + 品类价格数据（现成）+ 一个 2×2 实验
- **方法倾向**：定量
- **贡献**：把"平替"现象定位到可测量的品类特征上，给实践者一个可操作判断
- **主要风险**：贡献偏中等，需要更强的机制论证

## 6. 可行性预筛

| 项 | 判定 | 说明 |
|---|---|---|
| 数据 | 黄 | 内容可抓；访谈需 1–2 个月；实验需被试费约 4,500 元 |
| 时间 | 黄 | 8 个月窗口，A 偏紧，B 宽松 |
| 伦理 | 绿 | 访谈需知情同意与化名，低风险 |
| 能力 | 绿 | 实验与内容编码均已掌握 |
| 风险 | 黄 | A 的访谈若触达不到，退化为纯内容分析（贡献下降但仍可完成） |

## 7. 推荐与交接
**推荐**：先做 B，把 A 作为后续研究。
**下一步**：查文献确认"平替"是否已有对应研究 → `literature-gap-synthesizer`

## 8. 未解决的问题
- "平替"与"山寨""仿品"的边界尚未厘清
- 平台内容抓取的合规性需确认
```

## 示例 B · 组织行为（质性为主）

```markdown
# 研究问题简报

**领域**：组织行为 / 管理控制

## 1. 现象陈述
某互联网公司 2022 年推行"全员周报公开"后，员工开始在周报里互相引用彼此的工作内容，
并出现"周报写得比实际做得多"的现象；同期跨部门协作请求的响应时间缩短。

## 2. 前提压力测试

| 检验 | 结论 | 依据 / 待补证据 |
|---|---|---|
| 真实性 | 通过 | 已获得该公司 2022–2024 的周报文本（脱敏），可做内容分析 |
| 规模 | 偏小（改设计） | 单一公司，不做总体估计，改做机制揭示 |
| 新颖性 | 通过 | 周报制度不新，但"公开"带来的表演性行为是新的 |
| 可观察性 | 通过 | 周报文本可编码；员工可访谈 |
| 反例 | 有且能区分 | 反例：部分团队没有出现表演性写作，差异可能在管理者使用周报的方式 |
| 机制性 | 可陈述 | 猜测：公开使周报从"汇报"变成"表演"，受众（同事与上级）的可比性驱动了修饰 |

**总判定**：进入下一阶段（规模偏小，改为质性设计）

## 3. 构件拆解
- 行为主体：员工、直接上级、跨部门同事
- 分析层次：个体 + 团队
- 情境：单一互联网公司，2022 年制度变更前后
- 时间结构：过程（制度变更前 → 后 → 稳定期）
- 要解释的（候选 DV）：周报的表演性程度（自我引用、成果夸大、可见性修饰）
- 用来解释的（候选 IV）：受众可见范围、上级对周报的使用方式

## 4. 理论透镜

| 透镜 | 能解释什么 | 解释不了什么 | 预测什么可观察的差异 |
|---|---|---|---|
| 印象管理 | 为什么修饰周报内容 | 为什么协作响应反而变快 | 受众越广，修饰越强；受众中上级权重越高，修饰越针对上级 |
| 信息不对称 | 为什么周报成为信号 | 修饰的具体形式 | 工作可观察性越低，周报的信息含量越依赖自我陈述 |
| 实践理论 | 周报公开如何改变"写周报"这件事本身 | 个体差异 | 制度变更后，周报的体裁与用词会出现系统性变化 |

**推荐**：印象管理为主、实践理论为辅。理由：核心异常是"表演"，而制度效果（协作变快）
需要实践理论来解释惯例的重构。

## 5. 候选研究问题

### 问题 A
- **问句**：周报公开后，员工如何在"汇报工作"与"表演工作"之间做取舍？
- **类型**：④ 如何形成
- **需要的数据**：周报文本（约 12,000 份）+ 访谈（25–30 人，跨层级）+ 制度变更前后的对比
- **方法倾向**：定性——过程与意义建构
- **贡献**：把"透明化"的管理收益与表演成本放在同一个框架里，修正"透明即好"的假设
- **主要风险**：单一公司，外部效度受限；访谈中员工可能不愿承认表演

### 问题 B
- **问句**：上级如何使用周报，是否决定了公开制度产生协作收益还是表演成本？
- **类型**：③ 何时 / 对谁
- **需要的数据**：周报文本 + 团队层面访谈 + 上级使用方式编码
- **方法倾向**：定性为主，团队间比较
- **贡献**：给出制度效果的边界条件，可操作
- **主要风险**：团队数量有限（约 8 个），比较的说服力受限

## 6. 可行性预筛

| 项 | 判定 | 说明 |
|---|---|---|
| 数据 | 绿 | 周报文本已获得；访谈需公司配合，已初步同意 |
| 时间 | 绿 | 10 个月窗口，质性分析可并行 |
| 伦理 | 黄 | 涉及员工评价，需严格化名与脱敏；需说明不会反馈给管理层 |
| 能力 | 绿 | 编码与访谈已做过 |
| 风险 | 绿 | 即使访谈受阻，纯文本分析仍可完成 |

## 7. 推荐与交接
**推荐**：问题 A。
**下一步**：查"透明化""绩效可见性""印象管理"三条文献线 → `literature-gap-synthesizer`；
确认编码方案 → `qualitative-research-methods`

## 8. 未解决的问题
- 周报文本的脱敏是否会破坏表演性线索（引用关系、措辞）
- 制度变更同时伴随组织架构调整，混杂因素需处理
```

## 填写要点

| 要点 | 说明 |
|---|---|
| **现象陈述不写解释** | 一旦出现"因为""由于""导致"，就已经越界 |
| **压力测试要写依据** | 只写"通过"没有价值，要写凭什么通过 |
| **透镜必须给预测** | 说不出可观察差异的透镜，删掉 |
| **贡献要指名对话对象** | "对哪个文献说话"，不是"有理论贡献" |
| **风险要写最坏情况** | 不是"可能做不完"，是"如果 X 失败，退化为 Y" |
| **未解决问题不要藏** | 这一步没解决的就是下游要解决的，写出来交接更顺 |

## 三个常见错误

1. **把简报写成论文摘要**——摘要是结论，简报是决策依据。没有结论是正常的。
2. **压力测试全写"通过"**——六项全绿通常意味着测得太松。至少有一两项应该是"待补"。
3. **候选问题只写一个**——一个问题是命令。给 2–3 个，让学生自己选。
