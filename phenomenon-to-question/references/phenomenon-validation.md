# 前提压力测试 / Premise Stress Test

> 这一步的唯一目的：在投入三个月之前，确认这个现象**真实、有规模、够新、可观察、有反例可辩、有机制可猜**。
>
> 六项全过才进下一步。任何一项不过，如实说出来——**"这个现象不成立"是一个合格的结论**，
> 比硬凑一个题目负责得多。

---

## 一、六项检验

### 1. 真实性 / Is it real?

| 问什么 | 通过标准 | 不通过怎么办 |
|---|---|---|
| 有数据支撑吗？ | 有可引用的统计、平台数据、行业报告、或你自己的系统观察记录 | 没有 → 先去找数据；找不到就降级为「待验证的观察」，**不要当成前提** |
| 是你亲眼见的，还是听说的？ | 能指认具体时间、地点、人群、行为 | 只是"感觉" → 要求补三个具体实例 |
| 有没有可能是媒体的框架效应？ | 能说清媒体报道与实际行为的差别 | 分不清 → 先做描述性数据，别急着解释 |

**跨领域示例**

- 营销：说"消费者转向理性消费"，需要客单价、平替搜索量、退货率这类数据，不是几篇"消费降级"的报道。
- OB：说"年轻人不愿加班"，需要离职率、工时记录、或至少是同岗位跨代际对比，不是社交媒体吐槽。
- 会计：说"企业普遍盈余管理"，需要应计项目分布、阈值附近的断点检验，不是几个案例。
- 运营：说"供应链在去全球化"，需要进口来源国集中度、库存周转、订单交付周期的变化。

> **判据**：如果拿不出任何一个可复现的数字或可指认的实例，这项不过。

### 2. 规模 / Does it matter?

| 问什么 | 通过标准 | 不通过怎么办 |
|---|---|---|
| 影响多少人 / 多少钱 / 多少组织？ | 能给出量级（不必精确） | 规模极小 → 改做案例研究，或承认它是"边界现象" |
| 是一个细分市场的特例，还是跨群体的模式？ | 能说清边界在哪 | 说不清 → 收窄现象，明确"只在 X 条件下" |
| 如果这个现象消失了，谁会受损？ | 能指认利益相关方 | 指不出 → 可能只是观察者自己的兴趣 |

> **规模小不等于不值得研究**，但要改变研究设计：从"估计总体效应"改成"揭示机制"。
> 一个只有 30 人的极端群体，用质性方法可能比用问卷更有价值。

### 3. 新颖性 / Is it new?

| 问什么 | 通过标准 | 不通过怎么办 |
|---|---|---|
| 是新现象，还是老现象换了名字？ | 能说清"新"在哪里：新情境、新主体、新机制、还是只是新词汇 | 只是换名 → 转为「边界条件变了，原结论还成立吗」 |
| 上一个版本的研究结论是什么？ | 能说出既有结论 | 说不出 → **先去查文献**，不要在这里继续 |
| 新在情境还是新在机制？ | 能区分 | 只新在情境 → 贡献较弱，需要更强的机制论证 |

**老现象换新名的典型**（跨领域都有）：

- "私域流量" vs 关系营销；"种草" vs 口碑传播；"内卷" vs 过度竞争
- "算法管理" vs 科学管理；"平台用工" vs 非标准雇佣
- "数字化转型" vs 信息化；"ESG" vs 企业社会责任

> 换名本身不否定研究价值，但**必须说清"除了名字，什么变了"**。说不清就是旧瓶新酒。

### 4. 可观察性 / Can it be observed?

| 问什么 | 通过标准 | 不通过怎么办 |
|---|---|---|
| 核心概念能测量吗？ | 能说出至少一种测量方式（问卷、行为记录、档案、访谈编码） | 不能测 → 改研究问题，或改做质性 |
| 测量的是构念本身，还是它的代理？ | 能说清代理的效度风险 | 代理太远 → 换测量或换问题 |
| 数据存在吗，还是要自己去造？ | 明确"现成 / 需收集 / 需实验生成" | 需自造且成本高 → 进可行性预筛时重点评估 |

> **"不可观察"不等于"不能研究"**，但意味着要做质性或解释性研究，
> 而不是假装能用问卷测出来。硬测的结果是"测了一个和现象无关的东西"。

### 5. 反例 / What would falsify it?

| 问什么 | 通过标准 | 不通过怎么办 |
|---|---|---|
| 有没有相反的观察？ | 能举出至少一个 | 举不出 → 可能是观察者选择性注意 |
| 什么情况下这个现象**不会**出现？ | 能说出边界 | 说不出 → 现象可能只是"任何情况下都成立"的同义反复 |
| 如果换个解释，同样的观察还能成立吗？ | 能说出竞争解释并区分 | 区分不了 → 研究问题需要重新设计 |

**这一步是魔鬼代言人的主战场。** 主动问：

> 「如果这其实是平台推荐算法造成的信息茧房，而不是真实的观念变化，你的观察还能成立吗？有什么能区分这两种解释？」

能回答这个问题，研究问题就站住了；答不上来，说明观察里混杂了两个机制，需要拆。

### 6. 机制性 / Is there a causal guess?

| 问什么 | 通过标准 | 不通过怎么办 |
|---|---|---|
| 能不能说出一句"因为……所以……"？ | 能说出一个可证伪的因果猜测 | 说不出 → 停在描述阶段，**先别做假设** |
| 这个机制能推出什么可观察的差异？ | 能说出至少一个可检验的推论 | 说不出 → 这个机制只是叙事，不是理论 |
| 机制与现象之间隔着几步？ | 能数清中介链条 | 链条太长 → 收窄到相邻两步 |

> **机制性不过，最常见的处理是"降级"**：把"为什么"改成"是什么、有多少"，
> 先做描述性研究，等有了稳定的经验规律再问为什么。这不是退步。

## 二、四类常见伪命题

| 类型 | 特征 | 典型话术 | 处理 |
|---|---|---|---|
| **媒体叙事型** | 依据是报道、热词、"大家都在说" | "现在年轻人都躺平了" | 要求数据；没有就降级为待验证观察 |
| **概念换名型** | 老现象贴新标签 | "私域流量改变了营销" | 要求说清"除了名字什么变了" |
| **不可观察型** | 核心概念只能推测 | "消费者的潜意识被算法塑造" | 改问题或改方法，不要硬测 |
| **循环论证型** | 解释里已经包含了结论 | "因为消费者理性，所以选择性价比" | 要求给出独立于结论的证据 |

**循环论证最隐蔽**，检查方法：把解释句和现象句并排写，如果解释只是把现象换个说法，就是循环。

## 三、现象陈述的写法

**格式**：一段话，不超过 150 字，只写观察，不写解释。

| 要素 | 要求 |
|---|---|
| 时间 | 什么时候开始 |
| 主体 | 谁在做 |
| 行为 | 做了什么（可观察的动作，不是心理状态） |
| 参照 | 与什么相比反常 |
| 边界 | 在什么范围内成立 |

**合格示例（营销）**
> 2023 年起，一部分消费者在社交平台主动发布"平替"清单，标注自己买的不是原版；评论区出现互相验证真伪的协作行为。同期同品类原版的搜索热度下降。

**合格示例（OB）**
> 某互联网公司 2022 年推行"全员周报公开"后，员工开始在周报里互相引用彼此的工作内容，并出现"周报写得比实际做得多"的现象；同期跨部门协作请求的响应时间缩短。

**不合格示例**
> 「消费者因为经济下行而转向理性消费。」
> —— 后半句是解释，且"经济下行"与"理性消费"的关系正是要研究的东西，不能当前提。

> **检验方法**：把陈述给一个不了解你研究的人看，问他"你从这个描述里能看出原因吗？"
> 如果他能，说明你把解释混进去了。

## 四、判定记录

压力测试结束后，逐项记录结论，进简报：

| 检验 | 结论 | 依据 / 待补证据 |
|---|---|---|
| 真实性 | 通过 / 待验证 / 不通过 | |
| 规模 | 通过 / 偏小（改设计） / 不通过 | |
| 新颖性 | 通过 / 换名（改角度） / 不通过 | |
| 可观察性 | 通过 / 需改方法 / 不通过 | |
| 反例 | 有反例且能区分 / 有反例未区分 / 无反例（警惕） | |
| 机制性 | 可陈述 / 只能描述（降级） / 不通过 | |

**六项里有任何一项"不通过"，不要进入阶段 3。** 回到阶段 1 重新锚定，或如实告诉学生这个方向做不了、需要什么条件才能做。
