# scale-research

> 量表研究工作流 —— 从模糊的研究现象到可直接施测的中文问卷。

**版本**：1.0.0 ｜ **适用**：管理学、营销学、人力资源 MS/PhD ｜ **规模**：SKILL.md + 3 个 references

**中文** | [English](README.en.md)

---

## 它解决什么问题

量表研究有四个阶段，每个阶段都有典型的翻车方式：

| 阶段 | 典型翻车 |
|---|---|
| 澄清构念 | 测的根本不是自己想测的东西（构念混淆） |
| 搜寻量表 | 找到的是二手转引，α 值是从别的论文抄来的 |
| 翻译量表 | 直译导致「翻译腔」，被试看不懂或理解偏差 |
| 情境改编 | 改得太多，已经不是在测原来的构念了 |

这个技能把四个阶段串成一条工作流，并且在**每个阶段之间插入人工检查点**——
它不会替你跳过需要你自己判断的环节。

---

## 核心理念（技能启动时会主动提醒你）

1. **AI 提议选项；研究者做决定。** 构念选择、量表取舍、题项措辞的最终判断由你来做。
2. **三角验证。** AI 给出的每一条文献信息（作者、年份、期刊）必须先在真实数据库核实，
   才能引用。
3. **你的数据、你的统计。** 论文里的信效度数字必须来自**你自己的样本**，
   不能引用 AI 给出的数字。

---

## 什么时候用它

- 只有个模糊现象，不知道对应什么学术构念
- 知道构念名，需要找量表
- 已有候选量表，需要比较优劣
- 有英文量表，需要中文版
- 已有中文版，需要改编到新情境（如从「门店」改到「直播间」）

---

## 工作流程（四个阶段 + 四个人工检查点）

| 阶段 | 内容 | 模板 |
|---|---|---|
| **1. 构念澄清** | 把口语描述转成可检索的学术构念：构念映射、易混构念辨析、检索关键词、推荐与理由 | 1-A 构念识别、1-B 构念精确化 |
| **2. 量表搜寻与评估** | 找 3–5 个候选量表，按引用量、中文情境验证、已有中文版优先排序 | 2-A 经典量表搜寻、2-B 多量表比较 |
| **3. 翻译与语义验证** | 不是逐字翻译，是语义对等；含反向计分标记与译者注 | 3-A 专业初译、3-B 回译分析 |
| **4. 情境改编与定稿** | 最小必要修改；改动处用【】标出，标注改动类型 | 4-A 改编必要性评估、4-B 执行改编、4-C 模拟专家内容效度审查 |

### 四个人工检查点（技能会强制你停下来）

- **Checkpoint A**（进阶段 2 前）：关键词在 WOS/CNKI/Google Scholar 能搜到；
  读 2–3 篇近期综述；记录研究情境；与导师口头确认构念选择
- **Checkpoint B**（进阶段 3 前）：找到**原始开发文献**（不只是引用它的文章）；
  下载并找到附录里的完整题项；搜「量表名 + China / Chinese sample」找本土验证证据；
  **检查版权**（MBTI、Gallup Q12 等商业量表需授权）
- **Checkpoint C**（进阶段 4 前）：**由「人」做独立回译**——这是期刊评审的核查点；
  修改所有 ⚠ 和 ❌ 项；认知访谈（3–5 名目标被试逐题朗读）；记录翻译过程
- **Checkpoint D**（最终关）：导师签字；2–3 名领域专家评定内容效度；
  预试 N ≥ 30（推荐 N ≥ 100）并跑 EFA；保存完整改编日志

## 一个特别实用的部分：幻觉热点清单

技能明确列出了量表文献的**幻觉热点**：

> 作者姓名拼写错误、年份差 1–3 年（把原始论文与验证研究混在一起）、
> α 值写成「typical」而不是来自具体研究。

**核实方法**：Google Scholar → 「作者姓氏 + 年份 + 构念关键词」。搜不到 = 幻觉。

这一条对现在用 AI 找文献的学生尤其重要——AI 编造量表文献的比例相当高。

## 使用示例

```
我要测「品牌依恋」，研究对象是中国一线城市的年轻消费者，
需要中文版量表，问卷总题项控制在 60 题以内。
```

技能会先做构念澄清（区分品牌依恋与品牌情感、品牌忠诚等易混构念），
给出候选量表对照表，然后进入翻译阶段——并在 Checkpoint C 明确要求你
**找真人做回译**，不能用 AI 回译充当质量证明。

## 常见陷阱（技能内置的对照表）

| 陷阱 | 症状 | 正确做法 |
|---|---|---|
| AI 幻觉 | 作者/年份/期刊在数据库查不到 | 引用前在 WOS 或 Google Scholar 逐条核实 |
| 轻信 AI 给的 α | 把 AI 给的 α 抄进论文 | 所有报告统计量必须来自你自己的数据 |
| 跳过人工回译 | 拿 AI 回译当质量证明 | 必须人工回译；评审会查 |
| 过度改编 | 删维度、反向计分方向改错、无预试 | 超出词汇替换就要预试 + EFA + 方法部分说明 |
| 侵犯版权 | 未经授权使用 MBTI、Gallup Q12 | 查版权；商业量表需书面授权 |
| 跳过导师 | 全流程走完没跟导师沟通 | 构念选择与改编定稿两个节点必须确认 |

---

## 边界与注意事项

- **不要用 AI 回译代替人工回译。** 技能反复强调这一点，因为这是评审的实际核查点。
- **不要引用技能给出的 α / AVE / CR。** 这些只是参考值，论文里必须用你自己的数据。
- **改编有安全边界。** 技能用「安全改编 / 高风险改编」分类帮你判断，
  超出词汇替换的改动需要额外验证步骤与方法部分披露。
