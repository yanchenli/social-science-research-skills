# Scale Adaptation Reference Guide

## Adaptation Safety Boundary

### ✅ Safe Adaptations (low methodological risk)

| Change type | Example |
|---|---|
| Context-word substitution | "顾客" → "粉丝" / "门店" → "直播间" |
| Role-label update | "supervisor" → "直属领导" |
| Active/passive voice (meaning unchanged) | Passive restructured to active |
| Culturally opaque expression → equivalent | "poker face" → "表现出与内心不符的情绪" |

These changes should be transparently documented in the Methods section but
do not require additional psychometric validation beyond the standard pre-test.

### ⚠ High-Risk Adaptations (require extra validation)

| Change type | Risk |
|---|---|
| Deleting an entire dimension or many items | Damages content validity; may require reporting as a shortened scale |
| Reversing an item's direction (positive → negative framing) | Changes what is being measured, breaks comparison with original |
| Adding concepts not in the original construct definition | Scale now measures something different |
| Converting behavioural items to attitudinal ones (or vice versa) | Shifts level of analysis |

**If you make high-risk adaptations**, you must:
1. Justify theoretically in the Methods section why the change is necessary
   and does not alter construct meaning
2. Run a pre-test with EFA to verify the factor structure is preserved
3. Consider whether the adapted version should be treated as a new scale
   requiring full development validation

## Pre-Test Requirements by Adaptation Extent

| Adaptation scope | Minimum pre-test N | Analysis |
|---|---|---|
| Word substitution only | 30 | Descriptive stats + α check |
| Sentence restructuring | 50 | α + item-total correlations |
| Deleted / added items | 100 | EFA + α per dimension |
| Multiple dimensions changed | 200+ | Full EFA + CFA recommended |

## Methods Section Wording — Adaptation

Template for reporting adaptation:

> 本研究所用量表原版针对[原情境]开发。鉴于本研究对象为[目标情境]，
> 参照[引用方法论依据，如：Schaffer & Riordan, 2003]的跨情境量表改编
> 建议，对[X]道题项的情境措辞进行了调整（如将"顾客"替换为"用户"），
> 其余题项保持原有表述不变。改编后量表经[N]名[研究对象描述]进行预测试，
> 探索性因子分析结果显示因子结构与原量表一致（详见附录），各维度
> Cronbach's α 均在可接受范围（α = [X] — [X]）。

Replace bracketed items with your own data.

## Content Validity Index (CVI) — Simple Expert Rating Protocol

If you want expert content validity evidence (recommended for high-risk adaptations):

1. Recruit 3–5 domain experts (faculty, advanced PhD students in the field)
2. For each adapted item, ask them to rate relevance to the construct:
   1 = Not relevant | 2 = Somewhat relevant | 3 = Quite relevant | 4 = Highly relevant
3. Calculate Item-CVI (I-CVI) = proportion of experts rating 3 or 4
4. Target: I-CVI ≥ 0.78 for each item (Lynn, 1986 standard)
5. Revise or remove items below threshold before pre-test

## Common Adaptation Errors

| Error | Consequence | Prevention |
|---|---|---|
| Adapting items "because I don't like them" | Introduces researcher bias; breaks comparison with original | Only adapt for documented contextual mismatch |
| Adapting without documenting changes | Cannot replicate; reviewer rejection | Maintain a change log from day one |
| Skipping pre-test after adaptation | Unknown whether factor structure survived | Pre-test is non-negotiable for any structural change |
| Calling heavily adapted scale by original name | Misleads readers about what was actually measured | If > 30% items changed, consider renaming and citing original as basis |
