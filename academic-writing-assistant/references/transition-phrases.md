# 段落过渡与连接词库（中英文）

---

## 英文过渡词库

### Within Paragraph (段内连接)
| 功能 | 词组 |
|------|------|
| 补充 | Furthermore, Moreover, In addition, Additionally, Also |
| 对比 | However, In contrast, On the other hand, Conversely, Yet |
| 因果 | Therefore, Thus, Consequently, As a result, Hence |
| 举例 | For example, For instance, Specifically, In particular |
| 让步 | Although, While, Despite, Even though, Notwithstanding |
| 强调 | Indeed, Notably, Importantly, Crucially, Significantly |

### Between Paragraphs (段间过渡)
```
- "Having established [X], we now turn to [Y]..."
- "The preceding discussion suggests [summary]. Against this backdrop..."
- "Building on this foundation, the next section examines..."
- "Taken together, these studies highlight [point]. However, [gap]..."
- "The above review points to [conclusion], which leads us to propose..."
```

### Between Sections (节间过渡)
```
- "In sum, [X] represents [summary statement]. In the following section, we examine..."
- "Having reviewed the literature on [X], we next develop our theoretical framework."
- "The theoretical and empirical evidence reviewed above supports the argument that [X]. We now consider [Y]."
- "Collectively, the studies reviewed in this section establish [finding], which forms the basis for Hypothesis [N]."
```

### Introducing Hypotheses
```
- "Based on the above reasoning, we hypothesize that..."
- "Taken together, this logic suggests..."
- "Integrating [Theory A] with [empirical evidence], we propose..."
- "Accordingly, we offer the following hypothesis:"
- "This leads to our first/second/third hypothesis:"
```

## 中文过渡词库

### 段内连接
| 功能 | 词组 |
|------|------|
| 补充递进 | 此外，进一步地，与此同时，更重要的是，不仅如此 |
| 转折对比 | 然而，但是，相比之下，与此不同，值得注意的是 |
| 因果 | 因此，由此可见，由此推断，据此，这表明 |
| 举例说明 | 例如，以……为例，具体而言，如 |
| 让步 | 尽管如此，虽然……但是……，即便……也…… |
| 强调 | 尤为重要的是，值得强调的是，特别地，关键在于 |

### 段间过渡
```
- "在厘清[X]概念基础上，本研究进一步探讨……"
- "综合以上分析可以发现，[总结要点]。在此基础上……"
- "上述文献综述为本研究的理论推导提供了重要基础，接下来……"
- "综上所述，[总结]。然而，[转折/缺口]……"
- "以上研究揭示了[结论]，这为本研究提出[假设/问题]提供了依据。"
```

### 节间过渡
```
- "综上所述，[X]是影响[Y]的重要因素。以下将重点探讨[Z]在此过程中的作用。"
- "在梳理[X]文献的基础上，以下转向对[Y]的理论分析。"
- "上述对[X]的回顾表明，[核心结论]。下一节将在此基础上，系统推导本研究的理论假设。"
- "综合上述[几个方面]的研究可以看出，[整合性结论]，这为本研究的假设推导奠定了基础。"
```

### 引出假设
```
- "据此，本研究提出假设……"
- "综合以上理论逻辑，本研究假设……"
- "基于上述分析，我们预期……"
- "综合上述推导，提出如下假设："
- "由此，本研究的第一/二/三个假设如下："
```

## 结构性标记词

### Literature Review节内结构词
| 功能 | 英文 | 中文 |
|------|------|------|
| 开始综述 | "The literature on X has examined..." | "围绕X，现有研究主要从……" |
| 早期研究 | "Early work by [Author] established..." | "早期研究以[Author]为代表，……" |
| 近期发展 | "More recently, scholars have..." | "近年来，研究者开始关注……" |
| 现有共识 | "There is broad consensus that..." | "学界普遍认为……" |
| 现有争议 | "Scholars disagree on..." | "对于……，学界尚存争议" |
| 综合评价 | "In sum, research on X suggests..." | "综上，围绕X的研究表明……" |
