# academic-writing-assistant

> 学术论文写作助手 —— 引导撰写 Introduction 与 Literature Review。

**版本**：1.0.0 ｜ **适用**：商科 MS/PhD 学生及教师 ｜ **规模**：SKILL.md + 4 个 references

---

## ⚠️ 先说清楚：这是写作脚手架，不是代写

这是本技能包中**唯一直接产出论文正文**的技能，因此也最容易被误用，需要先说边界。

**它做什么**：帮你把「论证链条」写清楚——研究缺口怎么论证、假设怎么从前提出发
一步步推导出来、文献怎么按主题整合而不是逐篇罗列、段落之间怎么过渡。

**它不做什么**：不替你判断研究缺口是否真的存在、贡献是否够新。**原创性判断
必须由你和导师做**，技能没有能力评估这一点。

**它内置的护栏**：所有文献引用一律以 `[待核实: Author, Year]` 标红输出并在文末
附核验清单；缺少的统计数据一律以 `[请填入真实数据]` 占位，**不编造任何数字**。

> **请自行确认所在院校对学位论文使用 AI 工具的规定。** 各校政策正在收紧，
> 且差异很大；期刊对 AI 辅助写作的披露要求也不一致。是否使用、如何使用、
> 是否披露，由你与导师决定。

---

## 它解决什么问题

Introduction 和 Literature Review 是最难下笔的两章，因为难的不是语言，是**逻辑**：

- 研究缺口怎么写才不是硬凑？"没人研究过"本身就是不合格的论证。
- 假设怎么推导？直接从理论跳到 H1，审稿人一眼就看出"假设从天而降"。
- 文献综述怎么不做成"摘要堆砌"？每段一篇文献、逐篇介绍，是学生最常见的问题。
- 段落之间怎么衔接？章节之间怎么过渡？
- 中文和英文期刊的写法差别在哪？字数要求差多少？

这个技能把这套**结构性知识**整理成了可执行的六个阶段 + 句式库。

---

## 核心理念

**AI 辅助写作，研究者主导内容。**

AI 负责**结构、逻辑、语言和格式**；研究者负责**确认论点方向、审核引用准确性、
提供研究情境**。

> ⚠️ **重要提醒**：AI 生成的所有文献引用信息（作者、年份、期刊）必须在真实数据库
> （Google Scholar、Web of Science 等）中核实后方可使用。技能会用红色标注
> `[待核实: Author, Year]` 提示你——**这个标注不是装饰，是必须执行的动作**。

## 工作流程（六阶段）

技能先判断你在哪个阶段，再从对应入口进入：

| 你的情况 | 进入阶段 |
|---|---|
| 只有研究主题/想法，尚未开始 | **阶段1** — 写作前规划 |
| 有文献清单/笔记，不知如何组织 | **阶段2** — 文献梳理与框架 |
| 有框架，开始动笔写 Introduction | **阶段3** — Introduction 写作 |
| 有框架，开始动笔写 Literature Review | **阶段4** — Literature Review 写作 |
| 有草稿，需要润色/改写/扩展 | **阶段5** — 修改与润色 |
| 有完整内容，需要输出为 Word | **阶段6** — 文档生成 |

### 阶段1 — 写作前规划

先确认研究主题、研究问题、目标期刊类型、学科领域、写作语言、文献数量、字数要求，
再用「研究定位一句话框架」厘清定位：

```
本研究探讨 [自变量/现象] 对 [因变量/结果] 的影响，
聚焦于 [情境/边界条件]，
以 [理论基础] 为理论视角，
弥补 [现有研究空白] 的不足。
```

### 阶段2 — 文献梳理与框架搭建

提供三种文献分组维度（按主题 / 按时间脉络 / 按研究结论），以及**五类研究缺口的
识别与句式**：

| 缺口类型 | 示例表达 |
|---|---|
| 理论缺口 | `Prior research has not theorized...` |
| 情境缺口 | `Little attention has been paid to X in the context of Y...` |
| 机制缺口 | `The underlying mechanism remains unclear...` |
| 边界缺口 | `When and for whom X affects Y is largely unexplored...` |
| 方法缺口 | `Previous studies relying on... may have overstated...` |

### 阶段3 — Introduction 写作

按**漏斗模型**展开，并给出每一层的写作要点与英文句式：

```
1. 宏观背景钩子（1-2句）    ← 现象重要性/实践价值
2. 现有研究综述（2-4句）    ← 文献已知什么
3. 研究缺口（1-2句）        ← 但是/然而/不足
4. 本研究目的与贡献（2-3句） ← 本研究做什么/贡献
5. 论文结构预告（可选）
```

缺口段是**最关键**的一层，技能强调避免过度否定前人研究，用
"尽管已有贡献，但……"的句式，而不是"前人研究都不行"。

### 阶段4 — Literature Review 写作

给出每个子节的五段式结构（定义句 → 历史脉络 → 核心发现综述 → 争议与局限 →
过渡句），并用对照表点明**批判性综述 vs 描述性综述**的区别：

| 描述性（避免） | 批判性（推荐） |
|---|---|
| "Smith (2020) found that X affects Y." | "Smith (2020) demonstrated X→Y, but used a student sample, limiting generalizability." |
| 逐篇列举文献 | 按主题整合多篇文献 |
| 只说"做了什么" | 说明"贡献是什么"和"局限在哪" |

还包含**假设推导的逻辑链模板**：前提1（理论支撑）→ 前提2（文献支撑）→ 因此 H1。

### 阶段5 — 修改与润色

收到草稿先跑一份六维诊断清单（结构完整性 / 缺口论证 / 假设逻辑 / 文献整合度 /
语言学术性 / 过渡连接），再针对四类常见问题给出修复策略——其中"假设从天而降"
和"摘要堆砌"是最典型的两种。

### 阶段6 — 文档生成

输出 `.docx`，内置样式规范（Times New Roman 12pt / 宋体小四，双倍行距或 1.5 倍，
A4 四边距 2.54 cm）、文档结构、以及特殊标注规范（引用标红、数据占位符高亮）。

## 使用示例

```
研究主题：直播电商中主播的语言具体性对消费者购买意愿的影响
研究问题：语言具体性通过什么机制影响购买意愿？边界条件是什么？
理论基础：解释水平理论（CLT）
研究情境：中国直播电商平台
写作语言：英文
目标：期刊论文
参考文献：目前有 32 篇
帮我写 Introduction 和 Literature Review，Introduction 约 800 词。
```

技能会先确认定位、输出带层级标题的综述框架供你确认，然后按漏斗结构写
Introduction、按五段式结构写各子节。**所有引用都会标成
`[待核实: Author, Year]`**，文末附一份核验清单；缺数据的地方留
`[请填入真实数据]` 占位，不会编一个数字填上。

写完后建议接着用
[`academic-citation-auditor`](../academic-citation-auditor/) 逐条核实那些标红的引用。

## 边界与注意事项

- **不编造统计数据。** 背景钩子里需要真实数据时，技能会留占位符等你填，
  不会生成一个看起来合理的数字。
- **不生成未经核实的引用。** 所有引用一律标红待核实——这是硬约束，不是建议。
- **不使用第一人称。** 学术语气，客观严谨。
- **不评估原创性。** 「这个缺口是否成立」「这个贡献是否够新」超出它的能力范围，
  必须由你和导师判断。
- **写作规范因期刊而异。** 技能给出的是通用学术规范；具体期刊的格式要求
  （字数上限、结构要求、引用格式）请以投稿指南为准。
- **学位论文 vs 期刊论文**：字数与详尽程度差别很大（期刊 Introduction 约
  400–800 词；学位论文常 1500–3000 字），技能会按你指定的类型调整。

## 与 stats-results-writer 的分工

两者都产出论文正文，但**写的章节不同、规范不同，不要混用**：

| 技能 | 写的章节 | 依据 |
|---|---|---|
| `academic-writing-assistant` | Introduction、Literature Review | 文献逻辑与理论推导 |
| [`stats-results-writer`](../stats-results-writer/) | Results | 你自己的软件输出 |
