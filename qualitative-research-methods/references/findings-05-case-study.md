# 案例研究的Findings写法

配合`SKILL.md`阶段5使用，先读`findings-01-general.md`。以Eisenhardt式的"从案例建构理论"为主线（Eisenhardt, 1989；Eisenhardt & Graebner, 2007）；若用户用的是Yin式案例研究（更偏描述与解释、模式匹配），结构相近，但通常不以"浮现命题"为目标，先确认。

## 报告标准

Findings（有些期刊把案例背景放在Methods）通常要有：

1. **案例概览**：每个案例的关键特征，最好用一张表，方便跨案例对照
2. **案例内分析（within-case）**：每个案例的关键事件、过程、转折，常配时间线或事件表；叙述要为构念服务，不是流水账
3. **跨案例比较（cross-case）**：在案例间找模式与差异，常用"构念×案例"的对比表
4. **浮现的构念与命题**（Eisenhardt式）：每个命题配证据
5. **证据表**：把每个命题或构念的支持性证据（引语、事件）按案例列出，表格用法可参考Cloutier & Ravasi (2021)
6. **替代解释与边界**：哪些案例不支持、为什么，理论适用的范围

## 写作要点

- **复制逻辑**：把案例看作一连串可相互印证的"实验"，说明每个命题被哪几个案例支持、哪几个不支持——这是分析性推广，不是统计推广。避免写成"大多数案例"式的伪量化
- **结构一致**：各案例的叙述采用相同的框架（背景—关键事件—结果），才能做跨案例比较
- **叙述要有分析**：每一段案例描述后都要点明它对应哪个构念、支持哪个命题
- **证据与主张对得上**：命题说的，证据表里要有
- **匿名化**：企业名称、人物、可识别的细节按知情同意与匿名化方案处理，同时让读者仍然能理解情境（厚描述与匿名化的平衡）

## 结构模板

1. **概览**：案例总数与选择逻辑（一句话回指Methods）、案例概览表、整体发现的预告
2. **案例内分析**：逐案例简述（可精简成一段加时间线）
3. **跨案例比较**：模式一、模式二……，每个模式配对比表与关键引语
4. **命题与证据**：逐条命题＋证据表
5. **整合模型**：图示并讲解构念之间的关系，然后过渡到Discussion（与文献对话；Eisenhardt强调"与文献对话"是理论建构的重要一步）

## 中英文模板

- **案例内分析**
  - EN: In [Case A], [key event] led [actors] to [action], which produced [outcome] (see Table [X] for the event timeline). This case illustrates [construct] because [reason].
  - 中: 在[案例A]中，[关键事件]促使[行动者][采取行动]，产生了[结果]（事件时间线见表[X]）。该案例体现了[构念]，因为[理由]。
- **跨案例模式**
  - EN: Comparing across cases, we observed that [pattern] appeared in [n] of the [N] cases ([Cases A, C, D]), whereas [Cases B, E] followed a different path, characterized by [difference].
  - 中: 跨案例比较发现，[模式]出现在[N]个案例中的[n]个（案例A、C、D），而案例B、E走了另一条路径，其特征是[差异]。
- **提出命题并指向证据**
  - EN: Proposition 1: [statement]. This proposition is supported by evidence from [Cases A, C, D] (Table [Y]); [Case B] does not follow the pattern, which we discuss below.
  - 中: 命题1：[表述]。该命题得到[案例A、C、D]证据的支持（表[Y]）；[案例B]不符合这一模式，下文另行讨论。
- **说明替代解释**
  - EN: An alternative explanation is that [alternative]. However, [evidence] suggests otherwise, because [reason].
  - 中: 一种替代解释是[替代解释]。但[证据]表明并非如此，因为[理由]。

## 常见坑

- 案例叙述是流水账，与构念脱节
- 各案例结构不一致，无法比较
- 命题没有对应的证据表，或证据只来自一个案例却宣称跨案例成立
- 忽略或回避不支持命题的案例
- 用统计口吻描述案例（"大多数案例""70%的案例"）
- 匿名化不足，或为了匿名化把情境细节删到看不出发生了什么
