# 主题分析的质量判据与报告 — TA Quality

配合 `SKILL.md` 阶段 4–5 使用。方法本体（取向选择、六阶段、编码、主题发展）见 `thematic-analysis.md`。

---

## 1. 两套语言，不要混用

质性研究里同时流通两套质量语言，它们管的不是同一件事：

| | 通用层 | 方法层 |
|---|---|---|
| 代表 | Lincoln & Guba (1985) 四要素 | Braun & Clarke 的判据（15 点清单、20 问、一致性矩阵） |
| 回答 | 这项研究可不可信 | 这项研究**用它自己声称的方法**做得对不对 |
| 适用范围 | 跨范式通行，是评审与学生共用的语言 | 只在某一取向内成立 |
| 局限 | **不判方法内一致性**——用它审反身性主题分析，会放过"声称反身性却报 kappa" | 换一种取向就不适用，不能当普适标准 |

**正确用法**：两层都用。四要素交代"这项研究整体可信吗"，方法层判据交代"它按自己选的路走对了吗"。**只用四要素会漏掉不一致，只用 B&C 判据会看不懂评审意见。**

### 1.1 判据有时点：审旧文献要按当时的规范

还有第三个维度：**判据本身在变**。用今天的判据去审 2019 年之前的论文，会把当时的标准判成缺陷——这类误报比漏报更伤，因为它会让使用者不再信任判据。

| 判据 | 什么时候才成立 |
|---|---|
| 必须说明是四种取向中的哪一种 | 类型学 2019 命名 reflexive、2021 三分法、2022 四取向才系统化。更早的论文写"thematic analysis（Braun & Clarke, 2006）"就是当时的规范 |
| 必须有反身性陈述 | "reflexive TA" 这个名字 2019 才有；此前论文普遍不单列反身性一节 |
| 必须用六阶段的名称 | 六阶段是 2006 提出、2021 改述的**描述工具**，不是合规清单。作者完全可以写"四步"或自定流程——判据是"说清实际做了什么"（20 问第 11 条），不是"有没有六个阶段" |

**一个读数陷阱**：摘要里的主题短名往往是话题词（"choice, privacy, attractiveness"），而 Results 里的主题名是命题句（"what you do with pubic hair is up to you (within limits)"）。**判话题摘要要看 Results 里主题怎么展开，不能看摘要**——摘要有字数限制，只能给短名。

**做法**：审旧文献先看发表年份，再决定拿哪一版判据；判"不一致"之前，先确认当年是否有这条要求。

### 1.2 写作要求 ≠ 审稿判据

技能里有些话是对**写**的人说的，有些是对**审**的人说的。混用会误伤：对作者来说是"最好写上"，对审稿人来说可能是"不写也不算错"。

| 要求 | 对作者 | 对审稿人 |
|---|---|---|
| 交代归纳／演绎、语义／潜在 | 建议逐项点名，一句话即可，成本很低 | **能推断出来就不算漏**。例如"读完资料后系统编码、再聚类成主题"已能推出归纳取向，不必因没写 "inductive" 就报缺陷 |
| 写明四种取向中的哪一种 | 必须写 | 必须写（2019 年之后） |
| 有反身性陈述 | 必须写 | 必须写（2019 年之后） |

**判据：能推断就不算漏，推断不出来才算漏。** 这条也适用于审稿之外的场景——给学生的修改建议可以说"补一句更好"，但不该说"你没写所以不合格"。

## 2. 一致性矩阵（核心）

行是常见做法，列是四种取向。**这是本文件最该被查的一张表。**

✓ 相容　△ 需改造后可用　✗ 不相容（用了就构成方法学不一致）

| 做法 | 编码信度 | 码本 | 反身性 | 主题编码 |
|---|---|---|---|---|
| 编码者间信度（kappa 等） | ✓ | △ | **✗** | △ |
| 预先建码本／编码框架 | ✓ | ✓ | **✗** | △ |
| 成员检验（请参与者核验解读"对不对"） | ✓ | △ | **✗** | △ |
| 三角验证（作为准确性核验） | ✓ | △ | **✗** | △ |
| 饱和（作为样本量理由） | ✓ | △ | **✗** | ✓ |
| member reflections（请参与者反思、补充） | △ | ✓ | **✓** | ✓ |
| critical friend（同行作批判性对话者） | ✓ | ✓ | ✓ | ✓ |
| 反身性日志 | ✓ | ✓ | ✓ | ✓ |
| 留痕／审计轨迹 | ✓ | ✓ | ✓ | ✓ |
| 厚描述 | ✓ | ✓ | ✓ | ✓ |
| 多编码者讨论（求深度而非求一致） | △ | ✓ | ✓ | ✓ |
| 报告编码条数作为效度指标 | **✗** | **✗** | **✗** | **✗** |

**△ 不是"勉强可以用"，是"必须改一处才用"。** 十处 △ 各自要改什么：

| 做法 | 取向 | 改什么 |
|---|---|---|
| 编码者间信度 | 码本 | 把一致性系数当作**码本校准**的手段（用来发现定义歧义），不当作质量指标报告 |
| 编码者间信度 | 主题编码 | 同上；且只在编码阶段用，主题发展仍由研究者解释 |
| 预先建码本／编码框架 | 主题编码 | 码本只作起点，允许编码过程中新增、合并、改名；不要求"编码不超出码本" |
| 成员检验 | 码本 | 只核事实性内容（术语、事件、时间），不核"解读对不对" |
| 成员检验 | 主题编码 | 同码本；若要核解读，改用 member reflections |
| 三角验证 | 码本 | 作资料来源的丰富性说明，不作准确性核验 |
| 三角验证 | 主题编码 | 同上 |
| 饱和 | 码本 | 只在"资料收集的广度"层面说，不说"主题不再出现" |
| member reflections | 编码信度 | 只作补充材料，不进入质量论证 |
| 多编码者讨论 | 编码信度 | 讨论用于**校准码本**，不能替代独立编码与一致性计算 |

**几条要展开说**：

- **成员检验 ≠ member reflections**。前者问"我理解得对吗"（预设有一个正确答案），后者请参与者对分析作反思、补充、指出盲点（不判对错）。反身性取向下只能用后者。
- **三角验证**在反身性取向里不是不能用，而是**不能当准确性核验**。多数据源互证是设计层面的丰富性，不是"验证解读正确"。
- **"报告编码条数"一律避免**。BQQRG 明确把"把每个主题下的编码数量当效度指标"列为应避免的做法——它把分析深度换成了一个可数的东西。
- **编码信度取向里，反身性日志仍然是好的**，只是它不承担质量论证的主要责任。

## 3. 十五点清单（Braun & Clarke, 2006, Table 2）

这是最老也最通用的一张，适合自查，也适合给学生当交付前检查。

**本节与下一节的 20 问，都是按"已完成的期刊论文"写的。** 用来审开题报告、研究计划或论文初稿时，要换时态：「作者是否交代了 X」→「计划如何交代 X」；「分析是否扎实」→「这个设计能不能支撑起扎实的分析」。换时态不是放宽标准——开题阶段问的是「照这个计划做出来会不会成立」，不是「已经做出来的东西好不好」。

### 转录

| # | 判据 |
|---|---|
| 1 | 转录详细程度适合分析目的；转录稿已对照录音核对过 |

### 编码

| # | 判据 |
|---|---|
| 2 | 每一份资料在编码中都得到同等关注 |
| 3 | 主题不是从几个生动例子里生成的（轶事式），编码过程彻底、包容、全面 |
| 4 | 每个主题的相关片段都已归类齐全 |
| 5 | 主题之间互相核对过，也回到原始资料核对过 |

### 分析

| # | 判据 |
|---|---|
| 7 | 资料被**分析**（解释、赋予意义）过，不只是复述或描述 |
| 8 | 分析与资料相符——片段确实支撑了分析主张 |
| 9 | 分析讲出了一个有说服力、有组织的关于资料与主题的故事 |
| 10 | 分析叙述与示例片段之间比例恰当 |

### 整体

| # | 判据 |
|---|---|
| 11 | 六个阶段都有足够时间，没有赶工或草草带过 |

### 书面报告

| # | 判据 |
|---|---|
| 12 | 清楚交代了对主题分析的假设与具体取向 |
| 13 | 声称做的与实际呈现的一致（方法与结果是同一套） |
| 14 | 报告使用的语言与概念，与分析的认识论立场一致 |
| 15 | 研究者被呈现为研究过程中的主动角色；主题不是"自己涌现"的 |

**第 13 与 14 条是抓不一致的主力**，也最常被忽略：它们不查内容对不对，只查"你说的和你做的是不是一回事"。

## 4. 二十问（Braun & Clarke, 2021, Table 1）

原意是给编辑与审稿人用的，同样适合审学生论文、以及自查。

### A. 方法与方法论交代是否充分

1. 是否解释了为什么用主题分析（哪怕只有一句）？
2. 是否明确说明并论证了用的是**哪一种**主题分析？
3. 所选取向与研究问题／目的是否一致？
4. 研究的理论与概念基础与所选取向是否匹配（概念一致性）？
5. 资料收集方法与所选取向是否匹配？
6. 所选取向是否在全文一贯执行？
7. 是否存在对主题分析的错误假设？常见的有：把主题分析当成一种统一方法；把不相容的取向拼在一起而不说明；把话题摘要当共享意义；假定扎根理论的概念（饱和、持续比较、逐行编码）可直接套用；假定主题分析必然实在论或无理论；假定主题分析只能做描述因而必须再加别的程序
8. 附加的程序或方法是否必要？会不会把主题分析本身做得更好就够了？
9. 理论立场（本体论、认识论、理论框架）是否交代清楚？（**归纳不等于没有理论**）
10. 研究者是否努力"own their perspectives"——个人与社会立场？

### B. 分析是否扎实

11. 分析程序是否写的是**实际做了什么**，而不是通用程序？
12. 是否存在概念与程序的混乱？（声称反身性，却用码本、多编码者共识、信度系数；或主题成了分析的输入而非产出，流程变成"先定主题再编码"）
13. 作者是否表现出对其声称取向的完整理解？
14. 报告里主题在哪、是什么，是否清楚？是否需要主题清单、叙述性概览、主题表或主题图？
15. 报告的主题是不是话题摘要，而不是围绕中心组织概念的意义模式？若是：是否符合研究目的？在反身性取向下是否说明并论证了这一改动？是否直接拿访谈问题当主题？是否该换一种取向？
16. 是否把非主题性的背景信息当成了主题？（例如第一个"主题"其实是样本描述）
17. 应用研究里，主题是否有导向可行动结论的潜力？
18. 是否存在概念冲突？（声称建构主义，却在担心编码的可靠性；或声称建构主义，却把受访者的话当作经验的透明反映）
19. 分析是否薄弱？常见表现：主题太多或太少；层级太多；编码与主题混淆；片段与分析主张不匹配；片段太少或太多；主题之间重叠
20. 是否对"不可推广"作了有问题的表述，或把推广默认理解为统计概率意义上的推广？

## 5. 十个常见问题（Braun & Clarke, 2021）

按"最常出现"排序，第一条是其余多条的根源。

| # | 问题 | 识别信号 | 改法 |
|---|---|---|---|
| 1 | 把主题分析当成一种方法 | 写"标准主题分析流程"，不说是哪一种 | 先定位取向（`thematic-analysis.md` 第 1 节） |
| 2 | 引而不读 | 只引 2006，用的却是 2021 之后才澄清的概念 | 读该取向的近期文献，按实际用的版本引 |
| 3 | 不相容的拼装 | 声称反身性 + 报 kappa + 用码本 | 查一致性矩阵（本文件第 2 节） |
| 4 | 假定主题分析无理论 | 只写"归纳"，不交代本体论／认识论 | 补一段理论定位；归纳也要有理论 |
| 5 | 假定只能实在论／经验主义 | 无法处理建构主义的分析 | 明确经验主义还是批判取向 |
| 6 | 假定只能描述 | 分析停在"受访者说了什么" | 补解释层；描述不是终点 |
| 7 | 混淆编码与主题 | 十几个一两个词的"主题" | 合并到中心组织概念下 |

| 9 | 主题"涌现" | "主题从资料中浮现" | 改成"我们生成／建构了" |
| 10 | 不加批判地接受方法学家的说法 | 把任何一条判据当铁律 | 判据要看是否与自己的取向相容 |

## 6. 报告标准：三份文件与一个陷阱

| 文件 | 是什么 | 什么时候用 |
|---|---|---|
| **15 点清单**（2006） | 自查用，最通用 | 任何取向都能用，第 12–15 条尤其 |
| **20 问**（2021） | 评审用，也适合自查 | 投稿前、审学生论文时 |
| **BQQRG**（2025） | Big Q 报告指南，按论文章节组织（写作风格、术语、标题、摘要、引言、方法、分析、讨论） | 声称 Big Q 取向时 |
| **RTARG**（2024） | 反身性主题分析专用报告指南 | 明确用反身性取向时 |

**陷阱：COREQ 这类通用质性清单**。它把"成员检验""三角验证""饱和"当普适条目，用在反身性主题分析上会**引入**不一致。填之前先看每一条是否与自己的取向相容。

### 6.1 一个术语选择：Analysis 还是 Findings

BQQRG 明确偏好 **Analysis**：

> Findings infers the researcher 'found,' 'discovered' or 'identified' pre-existing entities, and Results is strongly associated with the outputs of statistical analysis.

理由是 "Findings" 预设了"被发现的东西已经在那里"，与反身性立场冲突。

**但在商科与学位论文里，Findings 是通行章节名**，改成 Analysis 反而不符合学校格式。处理办法：

- 学位论文／管理学期刊 → 用 Findings，但**正文里不要写"主题浮现""被发现"**
- 心理学期刊／明确的反身性取向投稿 → 可考虑 Analysis
- 无论用哪个词，**章节名不构成不一致，措辞才构成**

## 7. 抽样与饱和

### 7.1 四种"饱和"不是一回事

| 名称 | 出处 | 含义 |
|---|---|---|
| 理论饱和 theoretical saturation | Glaser & Strauss (1967) | 扎根理论专用，绑定理论抽样与收集—分析交替进行 |
| 数据饱和 data saturation | 后被泛化 | 不再有新信息出现 |
| 编码饱和 code saturation | Hennink et al. (2016) | 不再有新编码出现 |
| 主题饱和 theme saturation | Guest et al. (2006) | 不再有新主题出现 |

**只有第一种有明确的方法论归属**，其余三种是从它派生、被泛化使用的。

### 7.2 为什么反身性主题分析不用饱和

Braun & Clarke (2021) 的结论是 **"it depends, of course, but often no"**，对反身性取向尤其：

> when it comes to reflexive TA, data saturation is not a particularly useful, or indeed theoretically coherent, concept.

理由有三：

1. 饱和预设"主题在资料里等着被发现"，与分析立场冲突
2. 反身性取向认为分析没有固定终点——换一个视角重读，仍可能有新理解
3. 饱和在操作上常是**事后**给一个已经定下的样本量找理由

**编码信度与码本取向用饱和是可以的**，但要写清是哪一种、怎么判断的。

### 7.3 不用饱和，用什么

**信息力**（Malterud, Siersma & Guassora, 2016）：样本里与研究目的相关的信息越多，需要的参与者越少。五个维度：研究目的、样本针对性、是否使用已有理论、对话质量、分析策略。

**十个维度**（Braun & Clarke, 2021），在必须事先定样本量时逐条想：

1. 研究问题的广度与聚焦程度
2. 资料收集的方法与形式
3. 目标人群的身份多样性／样本想要的多样性
4. 资料里可能出现的经验或视角差异
5. 对参与者提出的要求（负担越重，越难招募）
6. 每份资料／每位参与者可能产生的资料深度
7. 所在学科与机构的惯例期望
8. 项目的范围与目的
9. 项目的现实约束（时间、经费）
10. 分析的取向与目的

**做法**：先给一个**区间**（下限／上限），边收边判，最终由"资料对回答研究问题是否足够充分"决定，而不是由某个数字决定。

**如实写**：如果样本量其实是受现实约束决定的（能接触到谁、有多少时间），就写这个。把它包装成"达到饱和"，是在延续一个本身就站不住的说法。

## 8. Methods 的可抄段落

第 20 问第 11 条要求写**实际做了什么**，不是通用程序。以下模板留了空，按实际填。

### 8.1 反身性主题分析

> 中：本研究采用反身性主题分析（Braun & Clarke, 2006, 2021），在［经验主义／批判］取向、以［归纳／理论引导］为主的方式下，围绕［研究问题］生成主题。分析按六个阶段推进：反复阅读并撰写熟悉笔记；对全部资料作系统编码（以［语义／潜在］层面为主）；将编码聚类为候选主题并识别各自的中心组织概念；在已编码片段与整个资料集两个层面复核主题；为每个主题撰写定义并命名；最后撰写分析。编码由［谁］完成，过程中保留反身性日志，记录［举例：编码调整、主题合并的理由］。主题是我们对资料的解读性建构，而非等待被发现的现成模式。

> EN: We used reflexive thematic analysis (Braun & Clarke, 2006, 2021), working within a[n] [experiential/critical] orientation and predominantly [inductive/theoretically informed] engagement with the data. ## 9. 交付前自查（十项）

给学生用的一页版：

1. 写明是哪一种主题分析，并给了理由
2. 理论立场交代了（哪怕一段）
3. 归纳／演绎、语义／潜在、经验主义／批判 三项各有交代
4. 主题有定义，且定义能独立读懂
5. 每个主题有一个中心组织概念，不是话题名
6. 引语来自多位受访者，且引语与主张匹配
7. 有反例或变异交代
8. 质量做法与取向相容（查第 2 节矩阵）
9. 没有"涌现""被发现""编码准确"这类措辞
10. 若用了 AI，披露了三件事
