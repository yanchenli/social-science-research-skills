# 主题分析参考手册 — Thematic Analysis

配合 `SKILL.md` 阶段 3–4 使用。质量判据与报告标准另见 `ta-quality.md`。

---

## 1. 先定位：TA 是一个方法家族，不是一种方法

Braun & Clarke (2023) 的原话是 **"TA is a family of methods, not a singular method—there is no 'standardised TA'"**。四种取向的差别不在步骤，而在三个假设：主题是什么、质量靠什么、研究者在分析里扮演什么角色。**混着用就是方法学不一致**，而这是评审最常抓的点。

### 1.1 一条根本的轴：small q ↔ Big Q

| | small q（小 q） | Big Q（大 Q） |
|---|---|---|
| 框架 | （后）实证主义 | 非实证主义 |
| 研究者主体性 | 需要控制的偏差 | 研究的资源 |
| 编码的目标 | 准确、可复现 | 有解释力、有深度 |
| 知识观 | 存在独立于研究者的真实 | 意义是情境化的、部分的、暂时的 |

四种取向分布在这条轴上：编码信度在最左，码本在中间，反身性在最右，主题编码在中间偏左。

### 1.2 四种取向

| 取向 | 主题是什么 | 质量靠什么 | 常见于 |
|---|---|---|---|
| **编码信度** coding reliability | 分析早期就确定，常直接来自访谈问题；本质是话题摘要 | 多编码者独立编码 + 一致性系数（kappa 等） | 心理学、健康研究、部分管理期刊 |
| **码本 / 框架** codebook | 话题摘要，但编码带解释性；码本随分析迭代 | 码本的系统性、团队协作的一致性 | 应用研究、多人分片编码、有交付期限 |
| **反身性** reflexive | 围绕**中心组织概念**的共享意义模式，是"关于资料的一个故事" | 反身性、分析深度、连贯性、透明度；**明确不用编码者间信度** | 心理学主流、批判取向研究 |
| **主题编码** thematic coding | 用扎根理论编码程序发展出的主题 | 编码程序的系统性 | 沿用扎根理论习惯、未明确区分两者的研究 |

**主题编码这一种容易被忽略**：它指用开放/主轴/选择性编码这类扎根理论程序来产出主题。如果用户说自己做的是"三级编码的主题分析"，他其实在第四种取向里，Methods 应当这么写，而不是声称反身性。

### 1.3 怎么选：四个问题

按顺序问，前面的答案优先：

| 问题 | 若答"是" | 若答"否" |
|---|---|---|
| 1. 你要的是"这类人说了哪些关于 X 的内容"，还是"这些说法背后的意义模式"？ | 前者 → 编码信度或码本 | 后者 → 反身性 |
| 2. 研究问题里是不是有"哪些因素／障碍／类型"这类**清单式**表述，而且清单本身就是答案？ | 是 → 编码信度或码本（话题摘要是正当产出） | 只是入口 → 反身性 |
| 3. 期刊、学校或导师是否要求编码者间信度／多编码者？ | 是 → 编码信度（并如实交代） | 反身性可行 |
| 4. 团队是否多人分片编码、或含未受训练的合作者？ | 是 → 码本 | 一两人全程 → 反身性 |

**若已经有初步分析产出，加看一条**：现有"主题"有没有中心组织概念，还是只是类别的名字（例如"两类触发线索""三类调节因素"）。这一步比前四问更能抓出"声称反身性、实际在做归类"的情形——研究问题可以是意义取向，而手上的产出已经滑成话题摘要。判断方法见 5.6 的三条测试。

### 1.4 按研究问题形状推荐

| 研究问题 | 推荐 | 理由 |
|---|---|---|
| 消费者在退货过程中遇到哪些障碍 | 编码信度 / 码本 | 清单本身就是答案，话题摘要正当 |
| 消费者如何理解"这笔钱花得值" | 反身性 | 要的是意义模式，不是清单 |
| 在既有框架下，A/B/C 三类话语各占多少 | 码本 | 预设维度 + 系统归类 |
| 这个行业里"专业"是怎么被做出来的 | 反身性 | 需要一个中心组织概念来统摄 |
| 六人团队分片编码，含企业合作者 | 码本 | 需要码本协调分工 |
| 学位论文，导师要求报告 kappa | 编码信度 | 但 Methods 必须如实写，不能同时声称反身性 |

**推荐时必须同时说清代价**：选了反身性就不能报 kappa、不能用码本、不能声称"编码准确"；选了编码信度就不要再写"主题是研究者生成的共享意义"。**换取向要改的不是一段话，是整个 Methods 与质量判据。**

> 推荐不等于规定。研究者的立场与研究问题是最终依据；技能只负责把选择的后果讲清楚。

## 2. 三个取向选择（互相独立，都要交代）

| 选择 | 两端 | 与理论框架的匹配 |
|---|---|---|
| **归纳 ↔ 演绎** | 归纳从资料出发；演绎用既有理论作透镜 | 归纳更贴经验主义；演绎更贴批判取向 |
| **语义 ↔ 潜在** | 语义编表面明说的意思；潜在编隐含的假设、前提、未言明之意 | 语义更贴经验主义；潜在需要更深的理论介入 |
| **经验主义 ↔ 批判** | 经验主义关注当事人怎么体验；批判关注意义如何被社会性地建构 | — |

**三条注意**：

1. **"纯归纳"不存在**。研究者不是白纸；归纳只是一种"以资料为起点"的姿态，不等于没有理论。
2. **演绎不是检验假设**。反身性取向里的演绎是"用理论作看资料的透镜"，不是拿资料去证实或推翻一个命题——那是编码信度取向里的用法。
3. **三者可以混，但要说明主次**。常见写法是"以归纳为主、在编码后期引入 XX 理论作透镜"。

## 3. 六阶段（现行表述）

Braun & Clarke (2021) 的现行表述与 2006 年那版有实质差别：**"searching for themes" 已改为 "generating initial themes"**——"搜索"预设主题已存在于资料中，与反身性立场冲突。

| 阶段 | 做什么 | 产出 | 判据 | 常见错法 |
|---|---|---|---|---|
| **1 熟悉资料并写熟悉笔记** | 反复读全部资料；边读边写观察（不是摘要）；听录音看视频；把笔记综合成对整体的判断 | 熟悉笔记（单份 + 全资料集） | 能说出这份资料里"什么让人意外"；笔记里是问题而不只是内容 | 只读一遍；把"看过"当熟悉；把第一印象直接当主题 |
| **2 系统编码** | 给与研究问题相关的片段贴标签；覆盖全部资料；同一片段可多码；无关的不码 | 编码清单 + 归类后的片段 | `take away the data` 测试；能看出编码在演进 | 只编"有趣"的部分；编码只是复述；碎片化到上千个码 |
| **3 生成初始主题** | 聚类、合并、拆开编码；找中心组织概念；画主题图初稿 | 候选主题 + 初版主题图 | 每个候选主题有一个中心概念；模式跨整个资料集 | 把编码改个名就叫主题；主题数量过多；按访谈提纲分组 |
| **4 发展与复核主题** | Level 1 对着已编码片段查；Level 2 回到整个资料集查；调整、合并、拆分、丢弃 | 修订后的主题集 + 主题图 | 内部同质、外部异质；每个主题能回答研究问题 | 只做 Level 1；发现不吻合就改资料不改主题；主题大量重叠 |
| **5 提炼、定义、命名** | 给每个主题写"摘要式定义"；据此判断薄厚；命名 | 主题定义 + 最终名称 | 定义能独立读懂；名称是对资料的主张 | 单词命名；"XX 的影响"；名字很花但抓不住内容 |
| **6 撰写报告** | 选引语、写分析叙述、与文献接上 | 分析章节 | 引语是分析对象而非仅举例；叙述回答 RQ | 引语堆砌；只描述不解释 |

六个阶段是**递归**的，不是流水线。常见的是回到阶段 2 补编码、回到阶段 3 重划主题边界。**这不是返工，是分析在推进。**

## 4. 编码

### 4.1 编码与主题不是一回事

Braun & Clarke (2021) 的比喻：**编码捕捉（通常只有）一个面；主题像多面晶体**，捕捉多个观察与多个面。

| | 编码 code | 主题 theme |
|---|---|---|
| 维度 | 单一面向 | 多面 |
| 数量 | 多（几十到上百） | 少（通常 3–6 个） |
| 角色 | 分析工具、建筑材料 | 分析产出、"关于资料的一个故事" |

**判断信号**：如果一份分析里"主题"有十几个、而且大多是一两个词，那些多半是编码。这是最常见的诊断，也是最容易改的——把它们合并到一个中心概念下。

### 4.2 `take away the data` 测试

好的编码标签，**拿走资料本身也读得懂**。Terry et al. (2017) 举的例子：`hates the idea of pregnancy` 合格；`pregnancy` 不合格。

不合格的标签在阶段 3 会立刻出问题：你没法判断它该归到哪个主题下，因为它没有携带意义。

### 4.3 不必逐行编码

主题分析**不要求**编码每一行资料——那是扎根理论的做法。与 RQ 无关的段落可以不编码，同一段落可以编多个码。硬要逐行，结果是碎片化，反而妨碍看到模式。

### 4.4 编码会演进，没有固定终点

编码标签可以扩张、收缩、合并、拆分。这种"有机"演进正是反身性取向的特点，也是**码本与反身性不相容**的原因：码本会把编码在分析早期固定下来，之后只做归类，不做再解释。

**但演进要留痕**：改了什么、为什么改，记下来。没有痕迹的"有机"，在评审看来就是随意。

### 4.5 什么算好编码

| 好 | 差 |
|---|---|
| 深：带解释，不只是复述 | 薄：只是把原话缩短 |
| 一致：同一类现象用同一套标签 | 不一致：同类现象三种叫法 |
| 彻底：覆盖全部相关资料 | 片面：只挑支持自己看法的段落 |

工具层面：NVivo/Atlas.ti 不是必需的。表格、Word 批注、卡片、纸笔都能做到同等质量。**编码是过程，不是软件。**

## 5. 主题发展

### 5.1 中心组织概念（central organising concept）

一个主题必须能被一句话说清"它到底在讲什么"，这句话就是中心组织概念。它决定某个编码该不该进这个主题。

中心概念不是"资料里藏着的本质"，而是**研究者对这批编码的理解**。所以两个研究者对同一批资料会生成不同的主题——这不是缺陷，是反身性取向的预期结果。

### 5.2 候选主题可以丢

阶段 3 产出的是**候选主题**，不是主题。候选的意思是"可以整批丢掉重来"。第一版主题图几乎从来不是最终版。

### 5.3 主题图

把候选主题画成图：主题之间的关系（并列、包含、因果、张力）、子主题、边界。

- 画图是为了**看见关系**，不是为了放进论文
- 期刊论文通常不放主题图（除非方法学文章）；**学位论文建议放附录**
- 图里要能看出"哪个是主、哪个是子"，以及两个主题在哪里交界

### 5.4 两级复核

| 层级 | 对着什么查 | 查什么 |
|---|---|---|
| **Level 1** | 已编码、已归类的片段 | 这个主题下的片段是否真的围绕同一个中心概念？有没有明显不合的？ |
| **Level 2** | **整个资料集** | 回到原始资料重读：主题有没有漏掉重要内容？有没有被分析带偏？ |

只做 Level 1 是最常见的省略。Level 2 的作用是防止"分析越走越远，离资料本来的样子越来越远"。

**双判据**（Patton, 1990）：**内部同质**（同一主题内的资料意义一致）+ **外部异质**（主题之间有清晰可辨的差别）。两个都要，只满足一个不够。

### 5.5 主题数量的判断

没有标准数字，但有两条经验：

- **太少**（2 个）：通常意味着把不同层次的东西压在一起，该拆
- **太多**（8 个以上）：通常意味着停在编码层面，该合并到中心概念下

判断依据不是数量，是**每个主题能不能独立成章**：有话可说、有证据、有边界。

### 5.6 话题摘要的三个识别测试

Braun & Clarke (2023) 给的判据，按顺序用：

1. **能不能在分析之前就想出来，而且预判之后就说不出更多了？** 只是能预判（"在线学习对我有效／无效"）不算；预判之后只剩一句"有人喜欢有人不喜欢"，才算
2. **是不是紧贴访谈提纲里的问题？** 是 → 很可能是话题摘要
3. **命名是不是"Experiences of…"／"Barriers to…"／"Influences on…"／单个名词／功能性短语？** 功能性命名（"X for Y"、"X to Y"，如 "Music to Come Out To"、"Queer Music for Community"）同样只是命名功能、不是主张 → 很可能是话题摘要（也可能只是名字没取好）

三条中两条成立，就要回头重做阶段 3。

**第 3 条判的是命名，不是分析本身**，两者要分开说：名字是功能性的、但定义句给出了中心概念 → 只需改名；定义句也只说"本节探讨 X 的作用" → 那才是分析停在话题层面。**看第一句比看名字准**：陈述主张的是主题，说明"这一节要谈什么"的是话题。

> 话题摘要**不是错误**，是**与取向不匹配**。如果研究问题本来就要清单，选编码信度或码本取向，话题摘要就是正当产出。问题只出在"声称反身性却交出一堆话题摘要"。

**方向性主题名的例外**：以判断命名的主题（"X worked for me"／"didn't work for me"）名字本身可预判，但它是**主张**不是话题。判断看两件事：① 有没有给出**机制或条件**；② 与相邻主题的差别是不是**只在评价方向**。两端机制不同（一端"障碍被移除"、另一端"支持被移除"）→ 正当的主题对；只有方向、没有机制 → 话题摘要。

## 6. 定义与命名

### 6.1 主题定义＝给主题写一段摘要

做法：用 3–5 句话写清这个主题的中心概念、它涵盖哪些面向、它的边界在哪。Terry et al. (2017) 的说法是"像给每个主题写一段 abstract"。

这段定义有三个用处：

1. **检验薄厚**。写不出三句，说明主题太薄，该并进别的主题或丢掉
2. **检验边界**。写得越长越散，说明主题太厚或没抓住中心概念，该拆
3. **写作时的骨架**。定义稍加展开就是 Findings 里那一节的开头

### 6.2 命名

| 做法 | 例 |
|---|---|
| 用资料里的话（能抓住核心时） | "Not a maternal bone in my body" |
| 用中心概念作名称 | "A precarious identity" |
| 用"X as Y"的结构点出解释 | "Price as an identity signal" |

**避免**：单个名词（"价格"）、"XX 的影响／因素／体验"、只有作者懂的内部梗。

名字可以有趣，但**有趣而抓不住内容的名字，不如朴素而准确的名字**。

### 6.3 子主题

子主题共享主主题的中心概念，只是其中一个面向。判断：拿掉它，主主题是否还成立？成立 → 是子主题；不成立 → 它可能是独立主题。

## 7. 反身性

### 7.1 三层

| 层次 | 内容 |
|---|---|
| **个人反身性** | 我的身份、经历、立场如何影响我看什么、怎么看 |
| **功能反身性** | 我的设计选择（抽样、提纲、分析取向）如何塑造了能得到的结论 |
| **学科反身性** | 我所在学科的惯例与预设，如何限定了什么算"好研究" |

### 7.2 反身性日志

从第一天记起：为什么这样编码、为什么改、哪个判断让自己不舒服、哪个发现出乎意料。日志是 Dependability（留痕）的载体，也是写作时最有用的一手材料。

### 7.3 两条禁忌

1. **不要用 "bias" 这个词**。反身性取向里不存在"无偏差的知识"，谈 bias 等于承认有一个可以抵达的客观版本——这是 small q 的语言，混进来就是不一致。
2. **不要写成身份清单**。"我是女性、来自二线城市、有五年从业经验"——这是 positionality 的罗列，不是反身性。反身性要接上**它如何影响了这次分析的具体判断**。

## 8. 与 Gioia 方法论的关系

商科学生最可能同时遇到这两种。它们不是同一层的东西。

| | 反身性主题分析 | Gioia 方法论 |
|---|---|---|
| 结构 | 主题 + 中心组织概念 | 一阶概念 → 二阶主题 → 整合维度 |
| 推进方式 | 有机编码，反复回到资料 | 溯因（abductive），在资料与理论间来回 |
| 编码的固定程度 | 不固定，持续演进 | 相对结构化，接近码本 |
| 主要产出 | 意义模式的故事 | 一个可检验的理论模型 |

**关键区别**：一阶/二阶是**抽象层级**，中心组织概念是**意义的核心**。把"二阶主题"当"主题"用，得到的往往是话题摘要——因为它回答的是"这个编码更抽象的叫法是什么"，而不是"这些说法共同在讲什么"。

**混用要交代**：如果确实要用 Gioia 的数据结构来呈现反身性分析的主题（商科里常见），Methods 里要说明两者的关系——数据结构图是**呈现工具**，主题生成过程仍是反身性的。不能一边说"主题是研究者生成的"，一边把一阶概念当作资料里客观存在的东西。

**怎么选**：研究目标是**建构可检验的理论模型** → Gioia；研究目标是**理解意义如何被组织** → 反身性主题分析。两者都能回答"这个现象是怎么回事"，但产出的东西不一样。

### 8.1 与"讲一个完整故事"（选择性编码）的张力

商科导师常要求把主题串成"起因—发展—结局"的故事线，并把它对应到选择性编码（selective coding）。这有方法学后果，需要提前说清：

- **选择性编码是扎根理论三级编码的第三级**，不是反身性主题分析的程序。用它的产出，Methods 应当写成主题编码或扎根理论取向，而不是反身性。
- **"起因—发展—结局"的模板会自然产出因果模型**。学生照着做，得到的往往是与开题时的概念框架重合的一条链——不是从资料长出来的。
- **一个可用的判据**：如果最终的"故事"与开题报告里的模型一一对应，那多半是演绎式速记（Pratt, 2009），不是分析。

**两种解法，选一个**：① 改取向声明，承认用了扎根理论程序；② 把故事模板换成主题发展——每个主题写定义、划边界、配引语，主题之间说明关系但不强加因果。两者都行，混着不行。

## 9. AI 辅助主题分析

这个技能本身就是 AI 在帮研究者做主题分析，所以这一节是自我约束。

### 9.1 AI 可以做什么

| 环节 | 可以做 | 边界 |
|---|---|---|
| 熟悉资料 | 提问、指出反复出现的说法、提示可能忽略的段落 | 不替代通读；AI 的"印象"不能当熟悉笔记 |
| 编码 | 生成编码初稿、给同一片段提多个候选标签 | **每一条都必须由研究者确认、改写或删除** |
| 主题发展 | 把编码聚类成候选主题、指出哪些编码可能不属于同一中心概念 | 聚类是建议，中心概念由研究者定 |
| 复核 | 检查主题是否只是话题摘要（用 5.6 的三个测试）、引语与主题是否匹配 | 不判断"解读对不对" |
| 写作 | 起草叙述、检查 tell–show–tell 结构 | 引语不得改写、不得生成 |

### 9.2 AI 不能做什么

1. **不能替研究者判断意义**。主题是研究者与资料互动的产物；AI 给的是模式识别结果，不是解释。
2. **不能生成或润色引语**。这是本技能最硬的一条红线，见 `SKILL.md` 重要原则第 4 条。
3. **不能用来"验证"编码的准确性**。让 AI 重编一遍再看一致性，是把 small q 的逻辑搬进反身性分析——两者不相容。若研究本身就是编码信度取向，AI 也不能充当"第二编码者"：一致性系数的前提是**独立的人类判断**，不是同一个模型的两次输出。

### 9.3 怎么披露

Methods 里写清三件事：**哪一步用了、用来做什么、研究者如何复核**。

> 例：熟悉与编码阶段使用了大语言模型辅助生成编码初稿；全部编码由研究者逐条复核、改写或删除，最终编码表与主题结构由研究者确定。模型输出未用于验证编码一致性。

**不能只写"使用 ChatGPT 辅助分析"**——这句话没有信息量，评审无法判断影响。

### 9.4 一个反面教材

文献里有一篇用 ChatGPT 做主题分析的工作论文，用 "researcher bias""replicability""validation" 这套语言论证 AI 辅助的可靠性。这套话术属于 small q 取向；如果研究声称反身性，照抄它会直接造成 Methods 内部不一致。

**判断标准很简单**：你写的每一句关于 AI 的话，是否与你选的取向用同一套语言。

## 10. 中英术语对照

中文文献里同一概念常有几种译法，学生读中文材料入门、再引英文文献，最容易两套说法混着写。**选一套用到底**，首次出现时给英文。

| 英文 | 本技能用 | 其他常见译法 | 说明 |
|---|---|---|---|
| thematic analysis | 主题分析 | 主题分析法 | 不必加"法" |
| reflexive thematic analysis | 反身性主题分析 | **反思性主题分析** | reflexivity 在中文里"反身性"（社会学传统）与"反思性"（心理学、教育学）都通行，指同一概念；**全文统一一个**即可 |
| code | 编码 | 代码 | "代码"易与编程混淆，建议用"编码" |
| theme | 主题 | 主题类属、主题范畴 | 与"类属／category"不同：主题围绕中心概念，类属只是归类 |
| sub-theme | 子主题 | 次主题 | |
| central organising concept | 中心组织概念 | 核心组织概念、中心概念 | |
| coding reliability | 编码信度 | 编码者信度、编码可靠性 | |
| codebook | 码本 | 编码簿、编码手册、编码框架 | |
| thematic coding | 主题编码 | 主题编码法 | 用扎根理论程序产出主题，别与"编码"混 |
| semantic / latent | 语义 / 潜在 | 表层 / 深层 | |
| inductive / deductive | 归纳 / 演绎 | | |
| member checking | 成员检验 | 参与者检核、参与者验证 | 与 member reflections 不是一回事 |
| member reflections | 成员反思 | 参与者反思 | 不判对错 |
| saturation | 饱和 | 资料饱和、饱和点 | 扎根理论概念，慎用于反身性取向 |
| trustworthiness | 可信性 | 可信赖性 | Lincoln & Guba 四要素的上位词 |
| audit trail | 留痕 | 审计轨迹、稽核轨迹 | |
| thick description | 厚描述 | 厚实描述、深描 | |

**翻译的两条规矩**：一是术语一旦选定就全文统一，中途换词读者会以为是两个概念；二是"反身性／反思性"这类并存译法，首次出现时给出英文原词，避免评审按另一套译法理解。
