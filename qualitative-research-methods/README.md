# qualitative-research-methods

> 质性研究方法 —— 严谨不是统计显著性，是可信性。

**版本**：1.2.0 ｜ **适用**：商科 MS/PhD/DBA 学生及教师 ｜ **规模**：SKILL.md + 11 个 references

**中文** | [English](README.en.md)

---

## 它解决什么问题

量化路线有一整套工具，质性路线常常只能靠「导师说怎么改」。这个技能补上整条链：

方法选择 → 抽样与工具设计 → 编码与分析 → 严谨性核查 → Findings 撰写。

它是这套技能里**唯一不依赖统计**的一条路径，也是唯一把「引语」当作核心证据的路径。

**它写给谁**：商科的研究生，以及**更熟悉定量方法的导师**。所以方法选择那一节不按质性行话组织，
按「先看结论要什么形状 → 再看数据能不能撑 → 再看方法能不能产出」的顺序走——
跟「先想清因变量是什么」是同一个思路。

---

## 核心理念

**质性研究的「严谨」不是统计显著性，是可信性（trustworthiness）。**

质性研究里设计、收集、分析常常交织进行——尤其扎根理论的「理论抽样」，分析结果会反过来指导
下一步该找谁访谈。所以技能里的阶段划分是一张**入口地图**，不代表必须严格按顺序走一遍。

> ⚠️ **引语之于质性，相当于数字之于量化。**
> 编码、分析、Findings 撰写都必须基于用户提供的真实转录稿/田野笔记：
> **不得凭空生成「看起来像」的访谈内容，也不得把用户的引语「润色」成更漂亮的版本。**

AI 负责结构化——推荐方法、搭工具、建编码框架草案、核对严谨性标准、起草和诊断 Findings；
真正的解读判断、编码取舍、理论建构，是研究者的活。
**质性分析里的主观介入本身就是方法的一部分，不是要被消除的噪音。**

## 工作流程（五阶段）

| 阶段 | 内容 | 关键产出 |
|---|---|---|
| 1. 方法与传统选择 | 三步决策；九种方法的比较；扎根理论三派的分辨 | 方法 + 版本的选择及理由 |
| 2. 抽样与资料收集设计 | 目的性/极端案例/理论/滚雪球抽样；访谈提纲、焦点小组、观察记录 | 抽样方案 + 工具 |
| 3. 编码与分析 | 主题分析（四种取向）、扎根理论编码、Gioia 数据结构、交叉案例分析 | 编码框架 + 主题结构 |
| 4. 严谨性核查 | Lincoln & Guba 四要素 + 按取向调整；进入 Findings 前的留痕清单 | 可信性说明 |
| 5. Findings 撰写 | 按传统分册的写作规范；引语使用；双语引语翻译 | Findings 正文 |

### 阶段 1：怎么选方法

**第一步，该不该做质性。** 问题是「如何／为什么／什么意义」，还是「多少／是否／哪个因素影响更大」。
硬判据：**若预期结论是一组系数或一个排名，质性帮不上。**

**第二步，看数据形态。** 这一层往往比研究问题本身更能定方法——研究问题写得漂亮但只有 8 份访谈，
就已经排除了民族志和案例研究。

**第三步，在候选之间比较。**

| 方法 | 一句话回答的问题 | 商科常见度 |
|---|---|---|
| 主题分析 TA | 这批资料里，人们围绕某个议题共享的意义模式是什么 | 高 |
| 案例研究 | 某个过程/机制在特定情境下如何展开 | 高 |
| 扎根理论 GT | 这个现象还没有理论，能否从资料里长出一个 | 中 |
| Gioia 方法论 | 如何把归纳过程呈现成审稿人熟悉的数据结构 | 高（管理学） |
| 质性内容分析 | 各类内容各占多少、有哪些类别 | 中 |
| 话语分析 | 语言如何建构现实、身份与权力关系 | 低 |
| IPA／现象学 | 极少数人的这段经历对他本人是什么感觉 | 低 |
| 民族志 | 一个群体的文化与非正式规则如何运作 | 中 |
| 叙事研究 | 人们如何用讲故事建构身份与意义 | 中 |

**推荐必须给四样**：理由、代价、替代方案、还缺什么信息。只说一个方法名的推荐，等于没推荐。

**给不熟悉质性方法的导师，三个问题就够**：你的结论最后长什么样？你手上的数据能支撑那个形状吗？
这个方法在学界被承认能产出那个形状吗？三问都过，方法选择基本站得住。

详见 `references/method-selection.md`。

## 主题分析：四种取向，先选一种

主题分析是一个**方法家族**，不是一种方法。四种取向的差别不在步骤，在「主题是什么」「质量靠什么」：

| 取向 | 主题是什么 | 质量靠什么 |
|---|---|---|
| 编码信度 | 分析早期就确定，本质是话题摘要 | 多编码者独立编码 + 一致性系数 |
| 码本／框架 | 话题摘要，但编码带解释性 | 码本的系统性与团队协作 |
| **反身性** | 围绕**中心组织概念**的共享意义模式 | 反身性、深度、连贯性；**不用编码者间信度** |
| 主题编码 | 用扎根理论程序发展出的主题 | 编码程序的系统性 |

**混着用就是方法学不一致**，而这是评审最常抓的点。典型错误：声称反身性取向，同时报告 kappa；
或声称反身性取向，却用「成员检验」去核验解读的准确性。

技能带一张**一致性矩阵**（12 种做法 × 4 种取向），标明哪些相容、哪些要改造、哪些不相容：

| 做法 | 反身性取向下 |
|---|---|
| 成员检验（核验解读「对不对」） | ✗ 不相容 → 改用 member reflections |
| 三角验证（作准确性核验） | ✗ 不相容 → 可作设计层面的丰富性 |
| 饱和（作样本量理由） | ✗ 不相容 → 用「资料是否足够充分」+ 信息力 |
| 编码者间信度 / 码本 | ✗ 不相容 |
| 反身性日志 / 留痕 / 厚描述 | ✓ 相容 |

另有三条**话题摘要识别测试**（能不能预判且预判后说不出更多、是否紧贴访谈提纲、命名是否话题式），
以及质量判据三层：15 点清单、20 问评审工具、十个常见问题。

详见 `references/thematic-analysis.md` 与 `references/ta-quality.md`。

## 阶段 4：可信性四要素

credibility、transferability、dependability、confirmability。

技能会逐项核对是否**有实质性交代**，而不是只挂了术语。同时提示**按取向调整**：
反身性取向下的 credibility 用 member reflections 而非成员检验，confirmability 用
「owning one's perspective」而非「反身性陈述」，并避免「bias」一词——那个词预设存在无偏差的知识。

**四要素是跨范式的通用语言，但它不判方法内一致性。** 两套要并用。

这是本技能最有价值的设计之一——质性论文的 Findings 没有统一模板，
不同传统的写法差别很大：

| 参考文件 | 适用 |
|---|---|

## 使用示例

```
我有 14 份访谈转录稿，做的是中层管理者对数字化转型的理解。
用的是 Gioia 方法论，编码表已经做了两轮，帮我写 Findings，英文。
```

技能会先确认传统与版本是否与编码步骤一致、抽样与饱和是否有交代，
再读 `findings-03-gioia.md` 的写作规范，逐项诊断现有编码表（二阶主题是否真的比一阶概念更抽象，
还是只换了说法），最后按 Gioia 的叙述结构起草 Findings。

```
我的问题是消费者怎么理解某类营销内容，手上大概能约到 20 份访谈，该用什么方法？
```

技能会走三步：先判该不该做质性，再看 20 份访谈能支撑什么、排除什么，最后在候选之间比较，
给出推荐 + 理由 + 代价 + 替代方案。

**引语缺失时不会编。** 会写成骨架并用 `[引语待补：P?，支持××]` 占位。

## 边界与注意事项

- **不替研究者编码或下解释判断。** 可以提编码框架草案、标注可能的主题、起草并诊断 Findings，
  但主题成立与否、解读方向，最终判断权在研究者。
- **不编造引语。** 见上文核心提醒。
- **不把「饱和」当通用判据。** 理论饱和是扎根理论的概念，对反身性主题分析不成立
  （Braun & Clarke 2021 的结论是「often no」）。样本量按「资料对回答研究问题是否足够充分」判断，
  需要给数字时用区间 + 边收边判。
- **不假装能做 NVivo。** 没有质性分析软件也完全可以做——用表格/文档手动编码，
  技能可以在你提供的文本上直接标注、归类、生成编码框架初稿。
- **AI 不替代解释，也不用于验证。** AI 可以生成编码初稿、聚类候选主题、检查主题是否只是话题摘要，
  但每条编码须由研究者确认或改写；不得生成或润色引语；不得用「再编一遍看一致性」来验证编码。
  披露写清哪一步、做什么、如何复核。
