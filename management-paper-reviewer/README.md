# management-paper-reviewer

> 管理类论文深度同行评审 —— 红队攻击、蓝队辩护、事实核查，三道关才出结论。

**版本**：1.0.0 ｜ **适用**：营销学 / 消费者行为 / HRM / OB / 战略管理 ｜ **规模**：SKILL.md（单文件）

**中文** | [English](README.en.md)

## 它解决什么问题

语言模型默认的「审稿」是模式匹配式的：概括内容，再给几条温和建议。这种输出看起来像审稿意见，实际上漏掉了真正会导致拒稿的问题。

这个技能用对抗性角色强制深度批判，然后**再用两道验证关把批判里捏造的部分剔掉**。

---

## 两条设计原则

**一、激进优先。**

默认状态下模型倾向于表面评价。必须通过角色扮演与对抗性指令，强制它去找其他 reviewer 可能遗漏的真实问题。

**二、验证过滤。**

激进提示会让模型为了取悦「批评者」身份而**虚构问题**。所以激进阶段之后必须设验证链，区分真实问题与捏造问题。

> 这两条是一体的。**只用第一条会得到一堆听起来犀利、实际站不住的批评；
> 只用第二条则什么也发现不了。**

## 流水线（五个阶段）

```
阶段 0  元数据提取
阶段 1  红队攻击（五个专项攻击者，独立运行）
阶段 2  汇总与蓝队辩护 → 裁决
阶段 3  事实核查与引用审计
阶段 4  最终评审写作
阶段 5  （可选）作者修改建议
```

### 阶段 1：五个攻击者

| 攻击者 | 专攻 |
|---|---|
| 理论破坏者 | 理论选取的正当性、构念定义、贡献真实性、假设推导的逻辑一致性 |
| 方法屠夫 | 按研究类型分支：问卷/量表、实验、二手数据、质性 |
| 统计审计员 | 报告数据内部一致性、测量模型、结构模型、效应量、稳健性 |
| 文献侦探 | 综述完整性、引用准确性、贡献新颖性、「沉默的证据」 |
| 实践意义质疑者 | 管理含义可操作性、情境边界、反向因果 |

攻击者的全局指令里有一条值得注意：**IGNORE PRESTIGE** ——忽略期刊排名、作者声望、机构背景和排版精美程度。先发表不证明正确。

> 若阶段 0 判定为纯质性研究，统计审计员**跳过**——质性论文没有可审计的统计量，
> 数据真实性的核查由方法屠夫的「数据-发现可追溯性」一项承担。

### 阶段 2：蓝队

论文作者的辩护律师，为每一条红队发现提出最强反驳，按四个角度组织：
防御理由（论文是否已在脚注/附录回应）、领域惯例（是否是本领域普遍局限）、
误读可能、辩护结论（Red Team Correct / Blue Team Correct / Debatable）。

### 阶段 3：事实核查

> **全局原则：所有关于论文具体内容的声明，在未经文本核实前均视为错误。**

捏造或无法在文本中找到依据的发现标 `[可疑]`，涉及外部文献的标 `[引用存疑]`，最终一并剔除或降级。

## 严重程度分级

| 级别 | 含义 |
|---|---|
| **致命** | 根本性问题，无法通过修改解决，数据可能需要重新收集 |
| **重大** | 可修复，但需实质性修改，可能影响核心结论 |
| **中等** | 需要修改，但不影响核心结论 |
| **轻微** | 细节性问题 |

---

## 领域特定检查清单

技能内置了五个领域的专项检查项，例如：

- **HRM**：数据有嵌套结构（员工-团队-组织）时是否用了 HLM/MLM？声称因果是否有纵向数据？
- **OB**：团队层面聚合是否满足 rwg / ICC 要求？领导行为测量是否区分了行为本身与下属感知？
- **战略**：战略选择往往内生于组织特征，内生性是否被认真处理？是战略导致绩效，还是绩效影响战略？
- **消费者行为**：跨文化比较是否检验了测量不变性？线上实验推论到现实购买行为的外部效度是否论证？

## 使用示例

```
帮我审这篇论文（附 PDF）。目标是 JCR，想知道能不能过。
```

技能会先提取元数据（研究领域、类型、核心问题、自称的 2–4 个贡献），
再让五个攻击者独立输出，汇总去重后交蓝队逐条辩护，最后只保留通过事实核查的问题。

**输出会明确回答**：作为 AE 会做什么决定（接受 / 小修 / 大修 / 拒稿），以及原因。

## 边界与注意事项

- **阶段 1 的激进是刻意的角色设计，不代表最终判断。** 不要拿红队原始输出当审稿意见——
  必须走完阶段 2、3。
- **不捏造外部证据。** 不得声称某篇未引用文献有特定内容；只能说「应引用 X 类研究」。
- **对量化声明保持审慎。** 疑似统计问题时，只基于内部一致性提出（如「表 2 样本量与方法部分不一致」），
  不靠视觉印象断言方程有误。
- **区分领域惯例与真实问题。** 社会科学普遍使用自我报告量表，这不等于每篇都有缺陷。

## 与相邻技能的分工

- 收到审稿意见、要写回应 → 用 [`response-to-reviewers`](../response-to-reviewers/)。两者一体两面。
- 要核验引用是否真实存在 → 用 [`academic-citation-auditor`](../academic-citation-auditor/)。
  本技能的引用核查只基于论文自身的参考文献列表。
- 评的是**学位论文**而非期刊论文 → 用另一套盲审流程（该技能不公开）。
- 评的是**基金申请书** → 用 [`grant-proposal-reviewer`](../grant-proposal-reviewer/)。
  评计划与评已完成的研究，标准不同。
