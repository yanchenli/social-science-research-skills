# 报告规范：PRISMA + MARS 双清单

> 两套标准管两件事，不能互相替代：
> **PRISMA 2020** 管「综述是怎么做出来的」；**MARS**（APA）管「元分析结果怎么报」。

---

## 一、PRISMA 2020 管什么

- 27 个条目的清单，覆盖标题、摘要、引言、方法、结果、讨论、其他信息
- 四阶段流程图（Identification / Screening / Included），数字必须能对上
- 关键：**检索式可复现、筛选过程可追溯、排除理由有计数**

详细条目与流程图算术见 `search-and-prisma.md`。

---

## 二、MARS 管什么

**Meta-Analysis Reporting Standards**（APA；初版 2008，Appelbaum et al. 2018 修订版为
7 个部分、27 个条目）。它比 PRISMA 更聚焦于**元分析特有的报告内容**：

| 部分 | 必须报什么 |
|---|---|
| 标题与摘要 | 明确是元分析；报告纳入研究数与主要结论 |
| 引言 | 研究问题、为何需要定量合成 |
| 方法 | 检索与纳入（可与 PRISMA 共用）、**效应量指标的选择理由**、**模型（FE/RE）与 τ² 估计方法**、调节变量假设 |
| 结果 | 每项研究的效应量与权重、森林图、合并估计与 CI、异质性、发表偏倚、稳健性 |
| 讨论 | 异质性的解释、局限（含发表偏倚与语言限制） |

> **最容易漏的两项**：① 为什么选这个效应量指标（r / d / OR）；
> ② 为什么用 RE 而不用 FE。这两条在方法部分必须写，不能只在结果里体现。

---

## 三、中英双语报告的结构

### 中文版（主报告）

```
1. 摘要（结构化：背景 / 目的 / 方法 / 结果 / 结论）
2. 引言
   2.1 研究问题与为何需要合成
   2.2 与既有综述的区别
3. 方法
   3.1 检索策略（数据库、检索式、日期）
   3.2 纳入与排除标准
   3.3 筛选过程与一致性
   3.4 数据提取
   3.5 效应量指标与换算
   3.6 合成模型与 τ² 估计
   3.7 异质性与发表偏倚的处理
   3.8 偏倚风险评估
4. 结果
   4.1 检索与筛选（PRISMA 流程图）
   4.2 纳入研究特征表
   4.3 合并效应量
   4.4 异质性
   4.5 发表偏倚
   4.6 稳健性与亚组分析
5. 讨论
   5.1 主要发现
   5.2 异质性的解释
   5.3 局限
   5.4 对未来研究的启示
6. 参考文献
7. 附录
   A. 完整检索式（逐库）
   B. 排除研究清单及理由
   C. 数据提取表
```

### 英文版（摘要 + 图表标题 + PRISMA 模板）

英文版不要求全文重写，但以下三项**必须有英文**：

1. **结构化摘要**（Background / Objectives / Methods / Results / Conclusions）
2. **所有图表标题与注释**（Figure 1. PRISMA 2020 flow diagram…）
3. **PRISMA 流程图**用英文标注（Identification / Screening / Included）

> 若目标是 SSCI，建议全文英文；若面向国内期刊与学位论文，中文正文 + 英文摘要即可。
> **不要中英混排在同一段**——这是学位论文最常见的格式问题。

## 四、森林图与表格的最小要求

| 元素 | 要求 |
|---|---|
| 每项研究 | 名称、效应量、95% CI、**权重（%）** |
| 合并估计 | 菱形或点 + CI，标明模型（RE, REML） |
| 异质性 | I²、τ²、预测区间（至少 I² 与 τ²） |
| 坐标轴 | 标明效应量类型与方向（「正值 = 有利于假设」） |
| 注释 | 说明用的是哪个模型、τ² 如何估 |

> **权重列不能省。** 没有权重，读者无法判断哪项研究在驱动结果——
> 而这恰恰是审稿人最想知道的。

## 五、交付前自查

- [ ] PRISMA 流程图五个等式全部对得上
- [ ] 方法部分写明了「为何选这个效应量指标」
- [ ] 方法部分写明了「为何用 RE」与「τ² 用哪个估计量」
- [ ] 合并结果报在**原始尺度**上（r 而非 z；OR 而非 log OR）
- [ ] 报了 τ² 与预测区间，不只报 I²
- [ ] 发表偏倚的解释写成「小样本效应」而非断言「存在发表偏倚」
- [ ] 稳健性至少做了留一法与剔除高风险
- [ ] 亚组/元回归若做了，说明了 k 与功效限制
- [ ] 附录有完整检索式与检索日期
- [ ] 偏倚评估工具说明了适用性局限
- [ ] 中英不混排
