# 系统文献综述与元分析 — Systematic Review & Meta-Analysis

## 核心理念

**系统综述与叙述性综述的分界线，不在「读了多少文献」，而在「检索与筛选是否可复现」。**

元分析再精致，如果检索式写不出来、排除理由没有计数、流程图数字加不起来，
它就不是系统综述，只是一篇带统计的综述文章。

本技能按七步走，**前四步决定这篇综述是否成立，后三步决定结论是否可信**：

| 步 | 做什么 | 失败的后果 |
|---|---|---|
| 0 | 三次分流：综述类型 / 输入完整度 / **统计范式** | 用错范式，方法部分直接被质疑 |
| 1 | 研究问题结构化 | 检索式无从构建 |
| 2 | 检索策略 | 不可复现 |
| 3 | 筛选与 PRISMA | 数字对不上，一眼被看穿 |
| 4 | 编码与偏倚风险 | 结论无法解释 |
| 5 | 效应量提取与换算 | 合并了不同的东西 |
| 6 | 合成、异质性、发表偏倚 | 结论过度自信 |
| 7 | 报告（PRISMA + MARS） | 投稿被拒或要求重做 |

## 阶段 0 — 三次分流

### 分流 1：这是哪一种综述

| 类型 | 做什么 | 要不要元分析 |
|---|---|---|
| **系统综述（systematic review）** | 按预设方案检索、筛选、评估，可含也可不含定量合成 | 可选 |
| **元分析（meta-analysis）** | 在系统综述基础上做效应量合成 | 是 |
| **范围综述（scoping review）** | 摸清某领域有什么、边界在哪，**不评估质量、不做合成** | 否 |
| **叙述性综述** | 按主题组织论证 | 否（不属于本技能） |

**先判断能不能做元分析**，三条硬条件缺一不可：

1. **可比性**：纳入研究测的是**同一个构念、同一个方向**的效应；
2. **k 数**：至少 5 项（k < 5 只能描述，异质性与发表偏倚都估不准）；
3. **可提取**：能拿到效应量与样本量，或能换算。

> 三条有一条不满足，**不要硬做元分析**。改为系统综述 + 叙述性总结，
> 并在方法部分说明「为何未做定量合成」——这比勉强合出一个数更专业。

### 分流 2：输入完整度

| 模式 | 用户给了什么 | 能做什么 |
|---|---|---|
| **A 全流程** | 从零开始，或已有检索结果 | 完整七步 |
| **B 只有一批文献** | 一份文献清单，检索过程不明 | **只能做「合成可行性评估」**，不能称为系统综述 |
| **C 已有初稿** | 写好了综述，要按规范整改 | 从阶段 3 的流程图与阶段 6 的合成开始补 |

> **模式 B 必须明说**：没有可复现的检索与筛选过程，成果**不能叫 systematic review**。
> 可以先做合成，但要如实标注为「基于既有文献清单的元分析」。

### 分流 3：统计范式（商科内部分歧最大的一处）

商科有**两个互不兼容的传统**。选错，方法部分会被直接质疑。

| | **Hunter-Schmidt（心理测量）** | **Hedges-Olkin（反方差随机效应）** |
|---|---|---|
| 核心动作 | 校正测量误差：ρ = r / √(r_xx·r_yy) | 不校正，合成观测效应量 |
| 加权 | 按样本量 N | 按 1/方差 |
| 主要区间 | **可信区间（credibility interval）** | 置信区间 + 预测区间 |
| 异质性 | σ_ρ²、% 方差由 artifact 解释 | τ²、I²、Q |
| 主导领域 | **OB / HRM / 工业组织心理** | **战略 / 金融 / 会计 / 经济** |
| 脚本 | `scripts/hs_meta.py` | `scripts/meta.py` |

> **营销与消费者行为两边都用**：心理测量传统偏多，但 Hedges-Olkin 也常见。
> 判断依据是**目标期刊近三年元分析文章的惯例**，不是个人偏好。

**R 生态的对应工具**（审稿人常会直接索要 R 代码，脚本结果与 R 交叉核对更稳）：

| 用途 | R 包 | 说明 |
|---|---|---|
| Hunter-Schmidt | `psychmeta` | CRAN 包，专门实现心理测量元分析（Dahlke & Wiernik, 2019）；`metafor` 也有 Hunter-Schmidt 的做法说明 |
| Hedges-Olkin 随机效应 | `metafor::rma()` | 与本技能 `meta.py` 的 REML 路线可直接对照 |
| 多层 / 非独立性 | `metafor::rma.mv()` | 三层模型 |
| 稳健方差估计 | `robumeta::robu()` | RVE |

> `hs_meta.py` 与 `meta.py` 是**给你自己先跑一遍、看清每个中间量**用的；
> 定稿前建议用 R 复算一次，两边数字对上了再写进论文。

## 阶段 1 — 研究问题结构化

用 **PICOS** 拆解（商科改造版）：

| 要素 | 商科对应 | 例 |
|---|---|---|
| P | 研究对象 | 消费者 / 员工 / 企业 / 国家 |
| I / E | 自变量或处理 | 品牌拟人化 / 培训项目 / 政策冲击 |
| C | 比较基准 | 对照组、低水平组（无则说明） |
| O | 因变量 | 品牌信任 / 绩效 / 创新 |
| S | 研究设计 | 实验 / 问卷 / 档案 / 质性 |

**这一步的产出直接决定检索式**。PICOS 写不清楚，检索式一定写不出来。

---

## 阶段 2 — 检索策略

见 `references/search-and-prisma.md`。四条底线：

1. **至少两个独立数据库**（WoS + Scopus 起步，按主题加 EBSCO Business Source、ProQuest ABI/INFORM）
2. **完整检索式写进附录**，含字段限定、截词符、检索日期
3. **记录每个库的命中数**——这是 PRISMA 第一格数字的来源
4. **说明灰色文献**：SSRN / NBER / RePEc / PQDT 至少交代是否检索

> 只查一个库，无法回答「漏了什么」；不写检索日期，别人无法复现。

### 注册：PROSPERO 不收商科综述

**PROSPERO 只登记「与健康结局相关」的系统综述。** 商科主题投过去会被拒——不是质量问题，是范围问题。

商科该去 **OSF**（首选）、**AsPredicted**，或主题落在其范围内时用 **Campbell Collaboration**。
注册的意义不是走流程，而是**把纳入排除标准在检索之前锁死**。

## 阶段 3 — 筛选与 PRISMA 流程图

### 筛选

- 标题摘要 → 全文，两阶段
- **双人独立 + 报告 Cohen's κ**（κ < 0.40 说明标准不清，需重训）
- 单人筛选必须写进局限

### 流程图：用脚本强制核对

```
python scripts/prisma_flow.py --identified-db 1240 --identified-other 35 \
    --duplicates 260 --screened-excluded 812 --not-retrieved 11 \
    --assessed-excluded 168 --included-meta 20 \
    --exclusion-reasons '{"非实证研究":45,"自变量或因变量不匹配":60,"效应量无法提取":63}'
```

脚本推导每一格、校验四个等式，并**强制要求全文排除原因的合计等于排除总数**。
任一条不成立即报错退出。

> **PRISMA 2020 要求报告全文排除的每一项原因及其频次**，不是一个总数。
> 审稿人真的会加——这是最容易被一眼看出的硬伤。

## 阶段 4 — 编码与偏倚风险评估

见 `references/quality-assessment.md`。两件事要分开：

| 评什么 | 工具 |
|---|---|
| **综述本身**做得怎么样 | AMSTAR 2（16 条，7 个关键领域）或 ROBIS |
| **纳入研究**靠不靠得住 | RoB 2（实验）/ ROBINS-I（观察性、档案数据）/ **商科定制 7 维清单** |

### 两个必须说清的点

**一、AMSTAR 2 与 ROBIS 是为医疗卫生干预设计的。** 逐条标注「是否适用」，
不适用写「不适用」而非「未达标」；**不给总分**（AMSTAR 2 明确反对算总分）。

**二、商科的核心偏倚不是盲法缺失，而是**：内生性/识别策略、共同方法偏差、
构念效度（CR/AVE/HTMT）、样本代表性、选择性报告。参考文件里有一份 7 维清单。

> 偏倚风险要落到**方向**：「存在 CMB 风险，**可能高估**效应」比「高风险」有用得多。
> 测量误差则相反，通常**低估**（衰减偏误）。

## 阶段 5 — 效应量提取与换算

见 `references/effect-sizes.md`。五类：

| 类型 | 合成用 | 关键坑 |
|---|---|---|
| r | Fisher's z | 报结果时**必须反变换回 r**（脚本已自动输出两套尺度） |
| d | Hedges' g | **d 与 g 不是一回事**，原文已报 g 时用 `--d-is-g` |
| OR | ln(OR) | **不能算术平均**；不能与 d 直接混用 |
| t | 偏相关 r_p = t/√(t²+df) | 只解决量纲，不解决控制变量差异 |
| 路径系数 | β | **只可合并同一模型设定**，否则合的是同名不同物 |

> 最高频的错误是 d/g 混淆：它会让结果系统性偏移，方向一致，你看不出来。

### 非独立性：商科最容易被低估的错误

**一篇论文几乎从不只提供一个效应量**（Study 1/2a/2b；ROA/ROE/Tobin's Q；不同滞后期）。
把它们当独立行塞进脚本，会**低估标准误、抬高假阳性**——而结果看起来更显著，所以没人怀疑。

处理：文内聚合（脚本可直接做）→ 三层模型 → RVE。
后两者用 R：`metafor::rma.mv()` / `robumeta::robu()`。
**`meta.py` 假定独立，同一 study 名出现多次时会警告，但不会替你修正。**

## 阶段 6 — 合成、异质性与发表偏倚

```
python scripts/meta.py --file studies.csv --type r --out result.json      # Hedges-Olkin
python scripts/hs_meta.py --file studies.csv                              # Hunter-Schmidt
```

### `meta.py` 给什么

固定效应、随机效应（DL / REML / Paule-Mandel）、Q / I² / τ² / H²、
Hartung-Knapp 区间、预测区间、Egger、PET-PEESE（**含推荐用哪个的决策结论**）。
**同时输出运算尺度（z / lnOR）与原始尺度（r / OR）**——后者才能直接写进论文。

### 三条报告原则

1. **主分析报随机效应（RE）**，τ² 用 REML；FE 作为敏感性分析。
   **不要看 I² 再决定用哪个模型**——模型由「研究是否来自同一总体」决定。
2. **报 τ² 与预测区间，不只报 I²。** 预测区间回答「这个结论在新情境下还成立吗」。
3. **Egger 显著 ≠ 存在发表偏倚。** 写「检测到小样本效应」，并列出替代解释
   （真实异质、小样本研究质量更低、测量误差与精度相关）。

### 为什么本技能不做 trim-and-fill

它假定漏斗图对称，会把**异质性**误当成偏倚；补出来的是插补值，容易被读成
「真实存在但未发表的研究」。改用 Egger + PET-PEESE，并在报告里说明理由。

### 稳健性做三个有用的

留一法、剔除高偏倚风险、换 τ² 估计量或效应量指标。
**元回归在 k < 10 时基本没有功效**，样本不够就明说「未做」。

## 阶段 7 — 报告

见 `references/reporting.md`。两套标准并用：

- **PRISMA 2020**（27 条 + 流程图）管「综述是怎么做出来的」
- **MARS**（APA，Appelbaum et al. 2018 修订版，7 部分 27 条）管「元分析结果怎么报」

### 最容易被漏的两项

1. **为什么选这个效应量指标**（r / d / OR）——写进方法，不能只在结果里体现
2. **为什么用 RE 而不用 FE**——同上

### 中英双语

中文正文 + 英文结构化摘要、英文图表标题、英文 PRISMA 流程图。
**不要中英混排在同一段**——这是学位论文最常见的格式问题。

## 重要原则（贯穿全程）

1. **先判断能不能做元分析，再动手。** 可比性、k 数、可提取性，缺一不可。
2. **先选范式，再选模型。** Hunter-Schmidt 与 Hedges-Olkin 不可混用。
3. **没有可复现的检索，就不叫系统综述。** 只有一份文献清单时，如实标注。
4. **流程图数字必须加得起来，排除原因必须分类计数。** 用脚本核对，不靠肉眼。
5. **效应量不能混着合。** d 与 g、OR 与 d、不同模型的路径系数，都不是同一尺度。
6. **报结果要回到原始尺度。** z 与 lnOR 是运算尺度，不是论文里能用的数。
7. **模型由理论决定，不由 I² 决定。**
8. **报 τ² 与预测区间。** 只报 I² 是当前文献里最常见的偷懒写法。
9. **Egger 显著不等于发表偏倚。** 写成「小样本效应」，并给出替代解释。
10. **同一论文的多个效应量不是独立观测。** 不处理就会低估标准误。
11. **偏倚风险要落到方向。** 「可能高估」比「高风险」有用。
12. **不硬凑、不美化。** k 不够就说未做；异质性高、证据弱就照实写。
