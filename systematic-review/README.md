# systematic-review

> 系统综述与元分析 —— 把「读了几篇文献的感想」变成可复现的证据合成。

**版本**：1.1.0 ｜ **适用**：商科 MS / PhD / DBA 学生及教师 ｜ **规模**：SKILL.md + 5 份参考文件 + 3 个脚本

**中文** | [English](README.en.md)

---

## 它解决什么问题

大多数研究生写的第一篇「综述」，实质是**把几篇摘要串起来**：有主题、有引用、没有可复现的检索与筛选过程。

这种稿子有三个具体问题：

1. **审稿人问「你怎么找到这些文献的」，答不上来**——没有检索式、没有数据库、没有排除标准。
2. **结论不可核验**——读者无法重做一遍看是否得到同样的文献集。
3. **定量合成做错**——效应量不换算就平均，或者把 r 和 d 混在一起合。

这个技能把系统综述拆成七步可核验的流程，并在每一步给出判据与工具。

---

## 核心理念

**先能复现，再谈结论。**

| 原则 | 含义 |
|---|---|
| **检索与筛选必须可重做** | 检索式、数据库、时间范围、排除原因与篇数，逐项留痕 |
| **范式先于统计** | 商科有两个互不兼容的元分析传统，选错方法部分会被直接质疑 |
| **效应量必须换算到同一尺度** | r、d、OR、z 之间不能直接平均 |
| **不报没有依据的数** | 异质性与发表偏倚都估不准时（k < 5），不做元分析，改做叙述性总结并说明理由 |

### 商科最关键的一处分流

| | **Hunter-Schmidt（心理测量）** | **Hedges-Olkin（反方差随机效应）** |
|---|---|---|
| 核心动作 | 校正测量误差：ρ = r / √(r_xx·r_yy) | 不校正，合成观测效应量 |
| 加权 | 按样本量 N | 按 1/方差 |
| 主要区间 | 可信区间（credibility interval） | 置信区间 + 预测区间 |
| 主导领域 | OB / HRM / 工业组织心理 | 战略 / 金融 / 会计 / 经济 |

> 营销与消费者行为**两边都用**。判断依据是**目标期刊近三年元分析文章的惯例**，不是个人偏好。

## 工作流程

| 阶段 | 内容 |
|---|---|
| 0 | **三次分流**：综述类型 / 输入完整度 / 统计范式 |
| 1 | 研究问题结构化（PICOC 或等价框架） |
| 2 | 检索策略（数据库、检索式、灰色文献、纳入排除标准） |
| 3 | 筛选与 PRISMA 2020 流程图（含排除原因与篇数） |
| 4 | 编码与偏倚风险评估（AMSTAR 2 / ROBIS / 商科定制七维清单） |
| 5 | 效应量提取与换算 |
| 6 | 合成、异质性与发表偏倚 |
| 7 | 报告（PRISMA 2020 清单、可复现附件） |

### 三个脚本

| 脚本 | 做什么 |
|---|---|
| `scripts/meta.py` | 五类效应量（r / d / OR / t / 路径系数）的换算与合成；REML / DL / Paule-Mandel；HK 校正；Egger 与 PET-PEESE 决策链 |
| `scripts/hs_meta.py` | Hunter-Schmidt 心理测量元分析：信度校正、N 加权、可信区间、方差分解 |
| `scripts/prisma_flow.py` | PRISMA 流程图：各阶段人数、排除原因合计校验（不符即报错） |

三个脚本都只依赖 Python 标准库，无需安装任何包。

## 用法示例

```
我在做「品牌社群参与对购买意愿的影响」的元分析，已经检索到 42 篇。
帮我看看这个 k 数能不能做，效应量怎么统一，以及要不要做发表偏倚检验。
```

技能会先判范式（营销领域两边都有，需看目标刊惯例），检查效应量是否可换算到同一尺度，
给出 k = 42 下的异质性与发表偏倚可行性判断，并说明哪些检验在该 k 数下没有意义。

---

## 边界与注意事项

- **k < 5 不做元分析。** 异质性与发表偏倚都估不准，改做系统综述 + 叙述性总结，并说明理由。
- **PROSPERO 只收健康结局。** 商科综述的预注册走 OSF 或 AsPredicted——这不是流程缺陷，是注册库的收录范围。
- **刻意不做 trim-and-fill。** 该方法在异质性存在时校正方向不可靠，容易给出虚假的「已校正」结论；
  技能改用 PET-PEESE 决策链并要求报告未校正结果。
- **不做 MASEM。** 需要结构方程与元分析结合时，转专门的工具（如 R 的 `metaSEM`）。
- **脚本给的是中间量，不是定稿数字。** 定稿前建议用 R（`metafor` / `psychmeta`）复算一次，两边对上再写进论文。
