# 伦理、数据治理与数据管理计划（所有分支共用）

配合`SKILL.md`阶段4使用。一手问卷、访谈、二手数据都涉及个人信息、使用权、存储与分享，不只是二手数据的问题。

## 总原则

- **识别风险，记录证据，不下法律或伦理结论。** 本skill不能替研究者或伦理委员会作出合规判断
- 凡是涉及个人信息、跨境流动、平台规则、数据使用条款的事项，都要明确标注"需人工或专业核验"，写入规格里的`governance.items_needing_human_verification`
- 能不收集的字段就不收集（数据最小化）
- 伦理申请材料里写的数据处理方式，必须与实际操作一致

## 检查表

对应工作簿的"Ethics & DMP"表。每项记录：当前答案、是否已人工核验、负责人。

| 主题 | 要回答的问题 |
|---|---|
| 伦理与法律 | 是否需要伦理审批、知情同意、豁免审查或其他合规核验？涉及哪些适用规则？ |
| 数据最小化 | 是否确实需要每个字段？哪些可以不收集、删除或分开保存？ |
| 隐私与安全 | 如何匿名化或去标识化？数据如何加密？访问权限如何分配？ |
| 保存与删除 | 原始数据、处理后数据、身份对应表分别保存多久？由谁管理？ |
| 数据使用权 | 数据是否允许研究使用、保存、分享或用于后续发表？（二手数据看使用条款） |
| 数据共享 | 能否开放原始数据、衍生数据、代码，还是只提供汇总统计？是否需要数据使用协议？ |
| 跨境问题 | 是否涉及跨境存储、访问、传输或其他跨境处理？是否需要专项审查？ |
| 责任分工 | 谁负责获取、处理、审查、授权、备份与最终归档？ |

## 各数据路径的特别提醒

**一手量化**：问卷平台、招募平台是第三方，参与者数据经过它们；报酬发放可能需要个人信息；同意书要写清楚。

**一手质性**：录音是最敏感的数据；自动转录或翻译服务会让录音与文字经过第三方；受访者的职位、公司、地点组合起来可能识别身份。

**二手数据**：使用条款可能禁止再分发或限制用途；脱敏数据仍可能被再识别；爬取可能违反平台条款；公开可见不等于可以随意使用。

**使用连接器时**：把参与者数据或访谈录音交给第三方服务（包括问卷、转录类连接器）之前，先确认伦理批准和知情同意是否涵盖这种处理，以及所在机构的数据保护规定。不要因为连接器方便就绕过这一步。

## 跨境与区域性问题

研究者所在地、参与者所在地、数据存放地、第三方服务器所在地可能分属不同法域。**这里只提示要问这个问题，不判断适用哪些规则**，写入人工核验清单，由所在机构的伦理或数据保护部门确认。

## 输出

- 工作簿"Ethics & DMP"表
- 规格中的`governance`：`ethics_approval_status`、`personal_data`、`items_needing_human_verification`、`storage_and_retention`
- 若`personal_data`是`identifiable`或`unknown`而伦理状态是`pending`或`unknown`，`validate_spec.py`会发出警告
