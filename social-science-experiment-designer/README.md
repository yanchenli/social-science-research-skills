# social-science-experiment-designer

> 社会科学实验设计专家助手 —— 从研究想法到六个标准交付文件的多实验研究方案。

**版本**：4.0.0 ｜ **适用**：商科研究生、社会科学研究者 ｜ **规模**：SKILL.md + 5 个 references

**中文** | [English](README.en.md)

---

## 它解决什么问题

多实验研究（multi-study paper）的设计门槛很高：实验之间要相互印证而非重复，
每个实验要承担明确的论证功能，还要提前预判审稿人会从哪里攻击。
新手最常见的失败不是「实验做错了」，而是「三个实验其实在证明同一件事」。

这个技能扮演两个角色，优先级明确：

- **首要：守门员（Gatekeeper）**——在任何建议提出之前，先完成批判性审查
- **次要：创意伙伴（Creative Partner）**——审查通过后，提出带条件的具体建议

每个材料建议都必须按 **推荐方案 → 方法论依据 → 潜在混淆变量 → 控制方案 → 替代方案**
的格式输出。**不允许直接给建议而不附批判性分析**——这是它和普通「帮我设计个实验」
的根本区别。

---

## 什么时候用它

- 有研究想法，还没收数据，需要设计完整的多实验方案
- 已完成 Study 1，需要设计后续实验（会自动检查跨实验一致性）
- 已有全部数据，需要生成预注册文档与 IRB 申请草案
- 假设被导师/审稿人质疑，需要结构化地检验假设体系

**入口自动识别三种场景**：从零开始 → 完整七步；已有部分数据 → 从第 3 步进入；
已有完整数据 → 直接生成交付文件包。

## 工作流程（七步）

| 步骤 | 做什么 | 关键机制 |
|---|---|---|
| 1 | 介绍、背景了解与场景识别 | 探测用户水平（0–1 / 2–5 / 5+ 篇），据此调整解释深度；按目标期刊层级调整实验数量建议 |
| 2 | **假设陈述与批判性审查** | 六维度审查：理论机制、替代解释、新颖性、边界条件、**构念边界**、**可证伪性标准**。全部覆盖后才推进 |
| 3 | 研究蓝图规划 | 填「实验功能分配表」；资源不足时触发假设优先级评估（必须检验/条件检验/留给未来） |
| 4 | 逐实验设计与材料构思 | 操纵设计（5 种范式按优先级评估）、测量设计、问卷流程排序、Pilot 建议；**每个实验后执行 6 项跨实验一致性检查** |
| 5 | 批判性设计审查 | 内部效度 / 构念效度 / 统计结论效度三张威胁清单 |
| 6 | 功效分析与样本量规划 | 每个实验独立分析，不得共用数字；效果量来源按「同范式文献 → 元分析 → Cohen 惯例」三级优先 |
| 7 | 生成完整研究方案包 | 六个交付文件，分研究执行层 / 论文写作层 / 研究规范层 |

### 回溯迭代（这是它的设计核心）

流程**不是单向传送带**。四个明确标注的回溯触发点：

- 材料设计时发现某假设难以操作化 → 回溯修订假设
- 功效分析发现资源不足以支撑蓝图 → 回溯调整实验规划
- 一致性检查发现跨实验根本性不一致 → 回溯蓝图层面解决
- 统计分析规划发现设计无法识别目标效应 → 回溯调整设计

### 伦理自动触发

以下情况出现时**立即**触发伦理讨论，不得延迟：涉及弱势群体、强烈负面情绪操纵、
目的隐瞒、完全欺骗性成分、真实金钱支出或敏感个人信息、歧视/自伤/违法意图等敏感构念。

## 六个交付文件

| 层 | 文件 |
|---|---|
| 研究执行层 | ① 实验设计文档　② 标准作业程序（SOP） |
| 论文写作层 | ③ 跨实验论证地图　④ 方法部分写作提纲 |
| 研究规范层 | ⑤ 预注册文档　⑥ IRB 申请草案 |

生成文件一时还会建议加入「**结果不支持假设时的处理预案**」：
先检查操纵是否成功 → 功效事后分析 → 说明该情况作为探索性发现处理，不更改预注册的主要假设。

## 使用示例

```
我有个研究想法：在线评论的语言风格（具体 vs 抽象）会影响消费者对
产品的信任，进而影响购买意愿，这个效应可能受产品类型调节。
我想投 JCR，预算有限，被试主要从 Credamo 招募。
```

技能会先问你的实验经验（决定解释深度），然后从第 2 步的六维度审查开始——
包括逼问「什么样的结果算支持你的假设」「最可能被审稿人挑战的是哪个替代解释」。

## 边界与注意事项

- **它不创造不存在的研究或数据**，也不编造文献。引用的文献只在可于
  Google Scholar 搜到的情况下给出 APA 引用，不确定时会明确告知你自行核实。
- **实验设计总是在效度之间、理想与资源之间权衡**，技能会让这一点始终可见，
  而不是假装存在「完美设计」。
- **最终设计责任在研究者本人**，所有建议应结合机构要求与导师意见评估。
