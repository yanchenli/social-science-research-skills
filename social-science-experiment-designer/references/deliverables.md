# 六个交付文件完整内容规范

本文件供第 7 步「生成完整研究方案包」使用。

---

## 交付文件总览

| 文件 | 名称 | 功能层 | 主要用途 |
|-----|-----|-------|---------|
| 文件一 | 详细实验设计文档 | 研究执行层 | 实际开展实验的主要依据 |
| 文件二 | 实验操作指南 / SOP | 研究执行层 | 实验执行者的操作手册 |
| 文件三 | 跨实验论证地图 | 论文写作层 | 解释多实验设计逻辑的写作工具 |
| 文件四 | 方法部分写作提纲 | 论文写作层 | 可直接填充的论文方法框架 |
| 文件五 | 预注册文档 | 研究规范层 | 提交 OSF/AsPredicted 的标准文档 |
| 文件六 | 伦理审查申请草案 | 研究规范层 | 提交 IRB 的参考草案 |

---

## 文件一：详细实验设计文档（研究执行层）

### 必须包含的内容：

**1. 研究假设**
- 清晰陈述所有核心假设（H1, H2, H3...）
- 说明各实验分别检验哪些假设

**2. 多实验研究架构概览**
- 完整的实验功能分配表（含操纵方式变化、样本来源、回应的审稿人质疑）

**3. 各实验变量定义与操作化**
- 自变量（IV）：理论定义 + 各实验的具体操纵方式（注明异同）
- 因变量（DV）：理论定义 + 量表来源文献 + 完整题项
- 中介变量（Mediator）：理论定义 + 测量量表（测量中介实验）或操纵方式（操纵中介实验）
- 调节变量（Moderator，如有）：理论定义 + 操纵方式

**4. 各实验设计类型**
- 明确说明：被试间/被试内/因子设计，条件数量，随机分配方案

**5. 被试招募计划**
- 各实验的目标群体描述
- 计划样本量（附功效分析依据：效果量来源文献 + 计算参数）
- 招募平台与渠道
- 跨实验样本策略说明

**6. 实验材料**
- 完整的操纵材料文本（指导语、故事材料、广告文案等）
- 图片/视频材料的描述和版权说明
- 材料格式建议（仅文字 / 图片+文字 / 视频等）

**7. 完整问卷**
按以下顺序组织，不得遗漏：
```
① 知情同意书
② 人口统计学变量
③ 基线控制变量（如有）
④ 随机分配 → 操纵材料呈现
⑤ 操纵检查（紧接操纵材料之后）
⑥ 中介变量测量（如适用）
⑦ 混淆变量检查（如：一般性情绪、内疚感等）
⑧ 注意力检查（1 题，明确指定答案）
⑨ 因变量 A：行为测量任务
⑩ 因变量 B：量表测量
⑪ 开放题（如需构念效度核查）
⑫ 人口统计学（如放在后面）
⑬ 事后告知书
```

**8. 参考文献（APA 格式）**
- 仅引用真实存在的文献，可在 Google Scholar 检索到

## 文件二：实验操作指南 / SOP（研究执行层）

### 必须包含的内容：

**1. 总体注意事项**
- 三个实验的建议执行顺序及原因
- 跨实验被试重复参与控制方案（在各平台的具体操作方法）
- 数据收集时间建议（如：避免节假日前后）

**2. 各实验分章节说明**（每个实验一节）
- **实验前准备**：问卷平台搭建步骤、随机分配设置、预测试（pilot test）流程
- **发布设置**：招募平台的具体参数（样本量、时间预估、报酬金额、纳入标准筛选器）
- **数据收集监控**：进度追踪频率、异常情况处理
- **数据清洗标准**：逐条列出排除标准及其执行方式（哪些排除、哪些仅记录不排除）

**3. 数据分析执行清单**
- 可勾选的分析步骤清单（含文件命名规范）

**4. 数据管理规范**
- 文件存储位置和命名规则
- 数据备份要求
- 数据保留期限

## 文件三：跨实验论证地图（论文写作层）

### 必须包含的内容：

**1. 各实验核心信息对照表**
- 设计特征、样本来源、操纵方式、关键预期发现

**2. 效度威胁与实验对应关系表**
- 每一行对应一个效度威胁或审稿人质疑
- 说明由哪个实验应对、通过何种方式应对

**3. 常见审稿人质疑预设答复模板**（逐条列出）
- 针对本研究最可能遇到的 4-6 个审稿人质疑
- 每条质疑附一段可直接使用的答复段落模板

**4. 概念性复制矩阵**
- 跨实验在操纵方式、样本来源、因变量测量上的策略性变化
- 每种变化的方法论意义说明

**5. 论文写作段落模板**
提供一个「研究概述段落」的可修改模板，解释多实验设计的内在逻辑必然性：
```
示例格式：
「我们通过 [N] 个实验来检验研究假设。Study 1 [功能]。然而，[指出 Study 1 的局限]。
因此，Study 2 [功能]。Study 2 同时 [额外价值]。Study 3 [功能]，并通过 [设计变化]
实现了 [方法论价值]。三个实验共同构建了从 [起点] 到 [终点] 的完整论证链。」
```

## 文件四：方法部分写作提纲（论文写作层）

### 必须包含的内容：

**1. 研究概述段落**（可直接修改使用的填空式模板）

**2. 各实验方法部分框架**
按学术论文格式，为每个实验提供以下各节的写作框架：

```
## Study [N]
### Participants（被试）
[N] participants (M_age = [X], SD = [X]; [X]% female) were recruited from [平台/机构]
via [招募方式] and randomly assigned to [条件描述].
[X] participants were excluded because [排除原因], resulting in a final sample of [N].

### Design（设计）
Study [N] employed a [设计类型] design with [自变量] as the independent variable(s).

### Materials and Procedure（材料与程序）
[操纵材料描述]
[操纵后，被试完成……]
[量表描述]

### Measures（测量）
**[构念名]**. We measured [构念] using [量表来源] ([N] items, e.g., "[示例题目]";
α = .[X]).
**Manipulation Check**. [操纵检查描述]

### Results（结果）
**Manipulation Check**. [操纵检查结果，格式：M_条件A = X.XX, SD = X.XX vs. M_条件B = X.XX,
SD = X.XX, t([df]) = X.XX, p = .XXX, d = X.XX]
**Main Effect（H[X]）**. [主效应描述，格式：F(1, N) = X.XX, p = .XXX, ηp² = .XX]
**[中介分析/调节分析]**. [分析描述]
```

**3. 跨实验衔接句模板**
```
Study 1 established [发现]. However, [指出需要进一步解决的问题].
Study 2 addresses this by [Study 2 的设计策略]...
```

**4. 格式注意事项**
- JCR/JMR 通常要求双盲审查：方法部分不得包含机构名称等可识别信息
- APA 第 7 版报告格式要求（p 值报告、效果量报告标准）
- 字数建议：单实验方法部分通常 300-500 词

## 文件五：预注册文档（研究规范层）

### 格式说明
可直接复制到 OSF（https://osf.io）或 AsPredicted（https://aspredicted.org）。

### 必须包含的内容：

**1. 研究问题**
**2. 研究假设**（分别标明验证性假设 vs. 探索性假设）
**3. 各实验变量与设计类型**
**4. 各实验样本量确定依据**
- 效果量估计值及其来源文献
- 功效分析参数（α, power, 单侧/双侧）
- 计划样本量 + 排除缓冲说明

**5. 被试招募计划**
**6. 数据排除标准**（预先声明，逐条列出）
**7. 主要数据分析策略**（含所用软件/宏的名称和版本）
**8. 探索性分析声明**（列出哪些分析属于探索性，不用于假设检验）
**9. 阶段性预注册说明**
```
建议语言：
本研究采用阶段性预注册策略。Study 1 的数据在预注册提交时已收集完毕，因此属于
已收集数据的预注册（registered report with existing data）。Study 2 和 Study 3
将在预注册文档提交并存档后方才开始数据收集，其分析属于真正的验证性分析。
研究者承诺：预注册提交后，不再修改 Study 2 和 Study 3 的假设及主要分析策略。
```

## 文件六：伦理审查申请草案（研究规范层）

### 重要声明（必须在文件开头显示）
> 本文档是基于通用模板生成的草案。**您必须根据所在机构伦理审查委员会（IRB）的具体要求和官方表格，对本文件进行修改、补充和调整后再提交。** 不同机构的 IRB 对申请格式、附件要求有所不同，请以官方要求为准。

### 必须包含的内容：

**1. 研究摘要**（通俗语言，覆盖所有实验）

**2. 研究对象**
- 各实验被试的纳入/排除标准
- 招募方法
- 弱势群体说明（是否涉及，如涉及需专项说明）

**3. 研究程序**
- 各实验被试从参与到结束的完整流程
- 特别说明：如涉及目的隐瞒，需区分「目的隐瞒（concealment）」和「欺骗（deception）」的伦理边界

**4. 风险与收益评估**
- 使用「最小风险」标准框架
- 针对该研究触发的特定伦理问题（见 SKILL.md 中的伦理触发规则）提供专项处理方案

**5. 知情同意书草稿**（完整版，含以下要素）
- 研究简介（不透露真实假设但不包含虚假信息）
- 参与内容和预计时长
- 自愿原则和退出权利
- 报酬说明
- 数据保护承诺
- 联系方式

**6. 数据保密方案**
- 存储位置和访问权限
- 去标识化方案
- 数据保留期限
- 发表后开放数据计划

**7. 事后告知书草稿**（完整版）
- 研究真实目的解释
- 被试在研究中经历了什么（操纵内容的解释）
- 参与价值说明
- 联系方式

## 生成说明

- 所有文件均以 Markdown 格式输出，便于用户进一步编辑
- 文件四（方法部分写作提纲）中的填空位置用 `[X]` 或 `[描述]` 标注
- 所有引用文献均使用 APA 格式，且仅引用真实存在的文献
- 如有不确定是否存在的文献，需在文件中明确标注「请自行核实」
