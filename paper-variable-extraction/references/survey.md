# 分支 A · 问卷调查法 / Survey Methodology

适用于以量表施测、自陈报告为主要数据收集方式的文章（问卷、访谈结构化量表、量表二次使用等）。

## 提取范围

按角色分组逐个提取：**自变量 → 因变量 → 中介变量 → 调节变量 → 控制变量**。
分组输出，每组用二级标题；组内每个变量用三级标题。

## 样本与数据收集（先于变量记录）

问卷论文的样本常分**多波收集**（预测试 + 正式调查 + 补采），只写「n=204，两阶段调查」会丢掉一半信息。逐项记录：

| 项 | 要求 |
|---|---|
| 抽样框与抽样方式 | 名录/协会/面板；随机、便利还是滚雪球 |
| 每一波的发出 / 回收 / 可用 | 逐波列出，不要只给合计 |
| 响应率 | 每波与总体分别给；说明是否用加权或检验无响应偏差 |
| **n 的构成** | 各波如何合并成最终 n。**各波相加必须等于总 n**，不等就是有信息没说清 |
| 样本特征 | 年龄、性别、教育、职位、企业规模等，照原文数值 |
| 数据收集时间 | 年份或时段；原文没写就记「原文未提供」 |
| 测量时点 | 横断面（同一时点）还是纵贯（多时点）。**横断面 + 全自陈 = 共同方法偏差风险，必须在报告里点明** |

## 每个变量的字段清单

1. **变量名称 / 变量名称（EN）**
   - 中文名 + 英文原名
   - 变量角色（IV / DV / Mediator / Moderator / Control）

2. **概念性定义 / Conceptual Definition**
   - 作者对变量的理论/抽象定义，引用原文 + 中文翻译
   - 若文中未给出明确定义，写「原文未提供明确概念性定义」，**不要自行补写**

3. **测量量表 / Measurement Scale**
   - **题项 / Items**：逐字列出全部题项原文（编号照抄），每题附中文对照翻译。
     - 反向计分题保留原文并标注「(R) / 反向计分」
     - 多维度量表按维度分子组列出
     - 文章只给出样例题项（如"e.g., ..."）时，照抄并标注「原文仅提供样例题项」
   - **响应量尺 / Response Scale**：具体形式与锚点，如
     `7-point Likert scale (1 = Strongly Disagree, 7 = Strongly Agree) / 7点李克特量表（1 = 非常不同意，7 = 非常同意）`
     - 若是语义差异量表、频次量表、百分比分配等，按其形式描述
   - **信度 / Reliability**：具体指标 + 数值，如 `Cronbach's α = .92`；有 CR/AVE/ω/重测信度时一并列出；分研究、分维度给出时分别标注
   - **来源 / Source**：完整 APA 格式 + 采用方式（Adopted from / Adapted from）

## 输出格式示例

```markdown
### 变量 / Variable：Job Satisfaction / 工作满意度（因变量 DV）

**概念性定义 / Conceptual Definition**
> "…" —— 原文引用 + 中文翻译

**测量量表 / Measurement Scale**

**题项 / Items**
1. I feel fairly satisfied with my present job. / 我对目前的工作感到相当满意。
2. …（反向计分 / reverse-coded）

**响应量尺 / Response Scale**：7-point Likert scale (1 = Strongly Disagree, 7 = Strongly Agree) /
7点李克特量表（1 = 非常不同意，7 = 非常同意）

**信度 / Reliability**：Cronbach's α = .92

**来源 / Source**：Adapted from Weiss, D. J., Dawis, R. V., & Lofquist, L. H. (1967). *Manual for the Minnesota Satisfaction Questionnaire*. University of Minnesota.
```

## 常见遗漏点（务必检查）

- **附录只给样例题项时**：照抄并在 `items_given` 记实际条数，`missing_fields` 记 `items`。不要把 2 条样例当成完整量表，也不要因为「只给了样例」就跳过整列
- **正文与附录的题项数不一致**：很常见（正文说「改编了 9 个题项」、附录说「(5 items)」）。这是两个不同的问题——改编了几题 vs 最终保留几题。**如实并列，不要替作者挑一个**
- 量表附录（Appendix）与 Table 1 中的完整题项列表
- 多维度量表的维度名称与各维度题项归属
- 同一构念在不同研究（Study 1/2）中使用了不同量表 → 分别列出
- 控制变量若为人口统计变量（性别、年龄、教育），也要给出其编码方式
- 变量的聚合方式（如取均值、加总、因子得分）
