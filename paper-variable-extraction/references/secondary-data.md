# 分支 C · 二手数据法 / Secondary Data Analysis

适用于使用既有数据库、档案记录、公开统计、面板数据、网络抓取数据等的研究。

## 提取范围

**自变量 → 因变量 → 中介变量 → 调节变量 → 控制变量**，逐个列出。

## 每个变量的字段清单

1. **变量名称 / 变量名称（EN）**：中文名 + 数据集中原始字段名（如 `NY.GDP.MKTP.CD`）
2. **概念性定义 / Conceptual Definition**：理论定义（原文 + 中文翻译）
3. **数据来源 / Data Source**：**必须精确到可复现的粒度**
   - 数据库/数据集名称（如 World Bank Open Data、CNRDS、CSMAR、PSID、CHARLS）
   - 具体指标名与指标代码（Indicator code）
   - 数据表/文件名（如有）
   - 覆盖年份、版本/更新时点
   - 好的写法：`World Bank Open Data, Indicator: NY.GDP.MKTP.CD, 2000–2020`
   - 坏的写法：`来自世界银行`（过于笼统，禁止）
4. **测量细节 / Measurement Details**
   - 原始计量单位与口径（如「现价美元」「2010 年不变价美元」）
   - 编码规则：如「二分类变量，employed = 1，unemployed = 0」
   - 转换方式：如「取自然对数 log(GDP)」「滞后一期 L1.」「标准化 z-score」「Winsorize at 1%/99%」「按行业-年度中位数调整」
   - 聚合层级：如「省级年度加总」「企业层面」
   - 缺失值处理方式（如「剔除缺失样本」「线性插值」）
   - 信效度信息（若有，如多个指标合成的一致性、替代指标稳健性检验）

## 输出格式示例

```markdown
### 变量 / Variable：National GDP / 国家 GDP（自变量 IV）

**概念性定义 / Conceptual Definition**
> "…" —— 原文引用 + 中文翻译

**数据来源 / Data Source**：World Bank Open Data；Indicator: `NY.GDP.MKTP.CD`；覆盖年份 2000–2020；2023 年 6 月更新版

**测量细节 / Measurement Details**
- 口径：现价美元（current US$）
- 转换：取自然对数 log(GDP)，缓解右偏；滞后一期（L1.GDP）用于缓解反向因果
- 缺失处理：缺失年份剔除，最终样本 132 个国家 × 18 年
```

## 数据结构 / Data Structure（先于变量记录）

变量之前先说清数据长什么样，否则后续所有字段的口径都说不准。逐项记录：

| 字段 | 说明与取值 |
|---|---|
| **数据结构** | `Cross-sectional`（截面）/ `Panel`（面板）/ `Time-series`（时间序列）/ `Nested`（嵌套）/ `Cross-classified`（交叉分类）/ `Repeated cross-section`（重复截面） |
| **时间跨度** | 如「2009–2018，共 10 年」 |
| **Level 1 / Level 2 单位** | 如 Level 1 = 州-年观测，Level 2 = 州；Level 1 = 员工-月，Level 2 = 企业 |
| **观测数 vs 聚类数** | 两者都要给（如「500 个年度测量嵌套于 50 个州」），只写 n 会让读者误判有效样本量 |
| **估计方法** | OLS / 固定效应 FE / 随机效应 / 多层模型 MLM / GEE / FIML / 路径分析 path analysis；注明软件与版本（如 Mplus 8.0） |
| **组内相关** | ICC(1)、ICC(2) 等（多层模型文中常给出） |
| **时间维度的作用** | 时间是作为预测变量（trend）、层级（level 1）、还是跨层交互（Time × X）？ |

## 多指标合成变量 / Composite & Latent Variables（高频，勿拆散）

二手数据论文里，一个构念常由**多个档案指标合成**（如「性别分化-社会领域」= 生育率 + 劳动参与率性别差 + 堕胎法限制 + 家庭友好政策）。此时变量不是单一字段，必须记录三层：

**第 1 层 · 变量（潜变量）层面**
- 概念性定义、角色（IV / Mediator / DV）
- **构成指标数**（如「4 个指标」）
- **合成方式**：标准化后取均值 / 因子得分 / 加总 / 主成分；是否标准化
- **测量模型检验**：CFA 拟合指标（CFI、RMSEA、SRMR、TLI）与判断标准；因子载荷范围
- **方向编码**：高分代表什么（如「分数越高表示越强调女性的家庭职责、越性化女性、女性能动性越低」）——**反向计分的指标要逐个标明**

**第 2 层 · 指标（Indicator）层面**——逐条列表，粒度到「指标名 + 来源 + 口径 + 编码方向」：

| 指标 | 来源（数据库 + 年份） | 口径 / 单位 | 编码方向 | 标准化 | 覆盖度 |
|---|---|---|---|---|---|
| 生育率 Reproduction | Human Development Report (2014) | 每名女性平均生育数 | 正向 | 是 | 140 国 |
| 堕胎法限制 | Center for Reproductive Rights (2013) | 允许堕胎的理由数（满分 7） | **反向计分**，高分=更严格 | 是 | 140 国 |
| 家庭友好政策-陪产假 | World Bank (2010a) | 是否强制陪产假：1=否，0=是 | **反向计分** | 是 | 140 国 |

**第 3 层 · 跨研究操作化对照**——同一构念在不同研究用了不同指标时（如国家层面 vs 美国州层面），用一张表并列，不要重复描述两遍（见 `output-format.md`）。

## 网络抓取 / 文本与图像类二手数据的补充字段

若数据来自爬虫、API、文本编码、图像编码、档案编码：

- **抓取/编码来源**：平台名称、**接口（API / 网页 / 官方数据包）**、抓取时间范围、样本量
- **抽样与去噪规则**：按什么检索（关键词、hashtag、话题标签）、取前多少条、**剔除了什么**（垃圾内容、转售/广告、机器账号、**品牌官方账号发布的内容**）以及剔除数量
- **编码方案**：编码规则、编码者人数、编码者间信度（如 Krippendorff's α = .81、Cohen's κ = .76）
- **变量构造**：如「用词典法统计年报中数字化关键词词频，除以总词数」；图像类如「用分类器预测每张图是否含属性 a，再对全部图取概率均值」
- **单位与聚合**：观测单位（帖子/图像/用户/品牌）与聚合层级（如 图像→品牌），**聚合方式要写清是均值、中位数还是分位数**
- **平台偏差**：样本只覆盖某平台/某人群时，要记录并说明对结论外部效度的影响

> **若测量工具是作者自训的模型**（分类器、神经网络），本分支只记数据来源，模型怎么造、怎么验见 `computational-measurement.md`——两套字段都要填。

## 常见遗漏点（务必检查）

- 文末表格中的「变量定义表 / Variable Definitions」（通常一次性给出所有变量来源与构造）
- 附录里的数据来源与构造说明
- 稳健性检验中使用的替代指标（alternative measures）
- 工具变量（IV）/ 外生冲击变量的定义与来源（常被忽略）
- 样本筛选条件（导致样本量变化）
- **描述统计表 / Table 3 里出现但正文没解释的变量**：常标为 "supplementary variables"（补充变量），只在稳健性分析里作为协变量进入，n 往往比主分析小（如正文 n=140，补充变量 n=89）。这类变量最容易被整段漏掉
- **缺失数据的处理规则**：是剔除、赋零，还是插值？跨国研究常把「无搜索量」的国家赋值为最低分（如 Google Trends 无结果赋 1.0），这类规则必须记
- **缺失样本与总体的可比性检验**：作者常报告「纳入 vs 未纳入的国家在 GDP、HDI 上无显著差异 t(177)=…，p=…」，这是外部效度的关键证据，要记
- **各指标的数据年份不一致**：同一合成变量的不同指标可能来自不同年份（如工资差距 2018、机制指标 2013），逐个标注年份，并留意作者是否讨论了时序问题
