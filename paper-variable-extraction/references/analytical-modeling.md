# 分支 H · 分析模型 / Analytical Modeling

适用于**形式化建模**的论文：博弈论模型、最优化模型、比较静态分析、均衡分析、结构模型的理论部分。
判定线索：出现 "we model"、"utility function"、"equilibrium"、"first-order condition"、"comparative statics"、
"Proposition"、"Lemma"、"we show that … increases with …"、Hotelling / Cournot / Stackelberg 等模型名。

> **与 E（文献综述型理论构建）的分界**：E 从**文献**归纳出命题，H 从**假设**演绎出命题。
> E 的产物是"这个领域缺什么、应该研究什么"；H 的产物是"在这些假设下，X 上升会导致 Y 上升"。
> 判定问一句：**有没有形式化的目标函数或均衡？** 有 → H。

---

## 一、提取的核心不是命题，是"命题依赖什么"

分析模型的结论脱离假设就没有意义。同一句「质量型自有品牌能提高零售商利润」，
在"两期模型 + 品牌惯性 + 成本对等"下成立，换个设定就可能不成立。
**只抄命题不抄假设，等于把条件结论写成无条件结论——这是本分支最容易犯的错。**

所以提取顺序是：**设定 → 假设 → 参数 → 均衡 → 命题 → 比较静态 → 稳健性**。

## 二、七个提取块

### 2.1 模型设定（Setup）

| 项 | 要问什么 |
|---|---|
| **主体** | 谁在决策？消费者、零售商、制造商，各有几个 |
| **时序** | 几期？谁先动？信息在何时揭示 |
| **空间/竞争结构** | Hotelling 线性城市？圆形城市？Cournot？ |
| **消费者偏好** | 效用函数的形式与关键参数（质量评价 v(q)、价格敏感度） |
| **技术/成本** | 边际成本、固定成本、是否成本对等（cost parity） |
| **信息结构** | 谁知道什么；是否有广告传递价格信息 |

### 2.2 关键假设（Assumptions）

**逐条列出，尤其是作者自己承认"较强"的那几条。**

- 哪些是**为简化而设**（两期、两品牌、单品类、同质消费者）？
- 哪些是**实质性假设**（惯性存在、质量可观测、成本对等）？
- 作者在哪一段讨论了"放松假设会怎样"？——这段必须抄下来。

> 例：本文的核心假设是"品牌转换惯性存在且强度在消费者间离散分布"，
> 作者用近三页文献（Shugan 1980、Bawa 1990、Guadagni & Little 1983 等）为它做实证辩护。
> **这个辩护本身是论文的一部分，不能省略。**

### 2.3 参数与符号表

| 符号 | 含义 | 取值/范围 |
|---|---|---|

> **同一符号在不同论文里含义可能完全不同。** 跨论文比较前必须先对齐符号，不要直接搬。

### 2.4 均衡概念与求解

- 均衡概念：Nash / 子博弈精炼 / 对称均衡 / 贝叶斯纳什
- 求解方法：一阶条件联立、逆向归纳、数值求解
- **均衡的唯一性**：作者是否证明了唯一？没证明就要记下来
- **是否存在多重均衡**：若有多重，命题在哪一个均衡下成立

### 2.5 命题 / 结果（Propositions / Results）

很多论文不编号，直接用"我们证明/我们发现"叙述。**逐条提取，标注它依赖哪个假设。**

| 编号 | 命题（原文 + 中文） | 依赖的关键假设 | 类型 |
|---|---|---|---|
| P1 | … | 惯性存在 + 成本对等 | 比较静态 |
| P2 | … | 质量超过阈值 | 存在性条件 |

### 2.6 比较静态

"X 上升 → Y 上升/下降"是分析模型的主要产出形式。
必须记录：**变化方向、单调性、是否只在某区间成立、临界值是什么**。

### 2.7 稳健性（作者自述）

- 放松某假设后结论是否保持？作者是证明了还是"论证应当如此"？
- 有没有数值算例（numerical illustration）支持？
- **有没有附录给出证明？** 若只写"证明可向作者索取"，要在缺口清单里记下——这直接影响可复现性。

## 三、与实证部分的关系（三种，别混）

分析模型 + 实证的组合有三种，判定不同，评价标准也不同：

| 类型 | 特征 | 实证的角色 |
|---|---|---|
| **直接检验** | 从命题推出可检验的假设，做因果识别 | 强：能证伪模型 |
| **校准 / 数值模拟** | 用估计出的参数代入模型，看能否复现矩 | 中：能检验参数合理性 |
| **一致性佐证（本类）** | 用描述性相关/回归说明"数据方向与模型一致" | 弱：**不能证伪，只能说不矛盾** |

> **必须把类型写清楚。** 一致性佐证被写成"实证支持了理论"，是营销与管理论文里常见的过度表述。
> 本文自己在正文里写明 "no causal inferences can be drawn"——**这种自我限定要原样保留**，
> 不要因为读起来弱就删掉。

## 四、字段清单（映射到 Excel）

| 字段 | 所在表 | 填什么 |
|---|---|---|
| `method_type` | Studies | `Analytical Model` |
| `model_setup` | Studies | 主体、时序、竞争结构、偏好与成本的一段话摘要 |
| `key_assumptions` | Studies | 逐条列关键假设，含作者承认的强假设 |
| `solution_concept` | Studies | 均衡概念 + 求解方法 + 唯一性说明 |
| `model_results` | Studies | 命题/比较静态的摘要（逐条，编号） |
| `design` | Studies | `Analytical`（非实验设计） |
| `estimator` | Studies | 求解方法，如 `一阶条件联立 + 对称均衡`；有数值算例写 `数值求解` |
| `n` / `n_unit` | Studies | 纯分析模型写 `NA`；有数值算例写算例规模 |
| `hypothesis_id` | Hypotheses | 用 `Proposition-1` / `Result-1`（**不要硬编号成 H1**） |
| `test_type` | Hypotheses | `Derivation` |
| `supported` | Hypotheses | `Derived`（由推导得到，不是"观察到"） |
| `note` | Hypotheses | 实证部分是否一致、依赖哪条假设 |

> **`Derived` 与 `Observed` 的区别**：命题是被**证明**的，不是被**观察**的。
> 写成 `Observed` 会把演绎结论说成经验发现。

## 五、五条红线

1. **只抄命题、不抄假设** → 条件结论变成无条件结论。必须成对记录。
2. **不记作者自己承认的强假设** → 读者以为结论很稳。作者讨论"放松假设会怎样"的段落要抄。
3. **把"数据方向一致"写成"实证支持"** → 一致性佐证不能证伪模型。要写明是哪一种组合。
4. **不记证明是否可得** → 若只写"可向作者索取"，可复现性就无从判断，必须进缺口清单。
5. **靠文本提取抄公式** → PDF 的数学层常被拆成单个字符（实测：一个利润函数会被拆成 60 多行
   单字符）。**模型部分必须按图读，或只摘文字表述的结论，不要试图从文本层还原公式。**

## 六、常见遗漏点

- **消费者异质性的分布假设**：离散还是连续、支撑集是什么、是否随时间变化。
- **质量的可观测性**：消费者是否知道质量、如何学习（本文是"试用后才知道"）。
- **广告的角色**：广告的是国产品牌还是自有品牌，这改变了价格信息的传递路径。
- **两期结构的必要性**：为什么需要两期？一期的结论会怎样？作者通常有交代。
- **成本对等假设**：自有品牌常有成本优势，本文刻意设成对等以隔离"利润率"解释。
  **这个设定本身是识别策略的一部分**，要记。
- **临界值的含义**：如"质量须超过阈值"——阈值是多少、由哪些参数决定。
- **数值算例的参数取值**：若用算例展示，参数怎么选、是否做了敏感性。

## 七、输出格式示例（片段）

```markdown
### S1 · 分析模型（博弈论）

**模型设定**：两期、两家零售商（Hotelling 线性城市）、两个同质细分市场（质量敏感 / 价格敏感）；
消费者在第二期对第一期选择存在品牌转换惯性 δ，δ 在 [δ, Δ] 上离散分布。

**关键假设**
1. 自有品牌与国产品牌**成本对等**（刻意设定，用以隔离"利润率优势"这一替代解释）
2. 惯性存在且跨期、跨品牌恒定（作者用三页文献作实证辩护）
3. 单品类分析（作者论证扩展到多品类只会强化结论）
4. 消费者试用后才知质量

**均衡**：对称均衡，一阶条件联立；作者未证明唯一性（缺口）

**命题**
| 编号 | 命题 | 依赖假设 | 类型 |
|---|---|---|---|
| Proposition-1 | 质量型自有品牌提高零售商利润，即使无成本优势 | 惯性 + 成本对等 | 比较静态 |
| Proposition-2 | "廉价低质"策略反而强化价格竞争 | 质量低于阈值 | 条件反转 |
```

> 最后一行 `Proposition-2` 是**条件反转**——同一模型在质量低于阈值时结论方向相反。
> 这类"边界条件"是分析模型最有价值的部分，不能只记正面结论。
