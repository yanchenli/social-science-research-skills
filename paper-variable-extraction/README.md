# paper-variable-extraction

> 论文变量操作化信息提取 —— 把散落在正文、附录、脚注里的变量信息，整理成可复用的变量词典。

**版本**：1.0.0 ｜ **适用**：商科 MS / PhD / DBA 学生及教师 ｜ **规模**：SKILL.md + 9 份参考文件 + 1 个脚本

**中文** | [English](README.en.md)

---

## 它解决什么问题

读一篇实证论文时，变量信息从来不在一个地方：

- 概念定义在理论部分，题项在附录，信度在 Table 1 的脚注，量尺在方法段的半句话里；
- 多研究论文里，同一个构念在 Study 1 和 Study 3 用了不同量表；
- 元分析里，调节变量的「操作化」根本不是题项，而是**编码规则**。

结果就是：写文献综述时反复翻原文，做元分析编码时凭记忆填，两个人提取同一篇论文得到两套结果。

这个技能把「提取什么、按什么粒度、缺了怎么写」固定下来，并产出两份可直接用的东西：
**一份 Markdown 报告**和**一份 Excel 变量表**（列名跨论文一致，便于元分析编码）。

## 核心理念

**逐字，不编造。**

| 原则 | 含义 |
|---|---|
| **题项与刺激材料照抄** | 不做润色、不做概括。原文只给样例题项时，照抄并标注「原文仅提供样例题项」 |
| **缺失就写「原文未提供」** | Excel 里写 `NA`。**绝不编造题项、信度数值、APA 出处、指标代码** |
| **内部不一致如实并列** | 正文说「改编了 9 个题项」、附录标「(5 items)」——两个都记，不替作者挑一个 |
| **方法先判，再提取** | 用错方法的尺子，评语会很专业但完全跑偏 |

### 八条方法分支，各用一把尺子

| 分支 | 判定线索 | 提取重点 |
|---|---|---|
| A 实验设计 | 随机分配、刺激材料、操纵检验 | 刺激材料原文、操纵流程、操纵检验 |
| B 问卷调查 | 量表施测、Cronbach's α、Likert | 逐题项、量尺锚点、信度、量表出处 |
| C 二手数据 | 数据库、面板、公开统计 | 库/表/指标代码/年份、清洗与聚合规则 |
| D 质性 | 访谈、扎根理论、民族志、编码 | 抽样依据、编码方案、编码者间信度、主题树 |
| E 文献综述型理论构建 | 检索式、纳入文献数、编码段落数 | 检索策略、编码程序、饱和判据 |
| F 元分析 | 效应量、I²、漏斗图、fail-safe N | 效应量与调节变量编码（产出 EffectSizes 表） |
| G 计算测量 | 自训分类器、fine-tune、AUC、人类对照 | 训练数据与划分、模型性能、与人类判断的对照 |
| H 分析模型 | 效用函数、均衡、一阶条件、比较静态 | 设定、假设、均衡、命题、比较静态 |

> **G 与 C 的分界**：C 问「数据从哪来」，G 问「测量工具怎么造」。
> **H 与 E 的分界**：E 从文献归纳命题，H 从假设演绎命题。

## 工作流程

| 步骤 | 内容 |
|---|---|
| 0 | **获取论文全文**（含扫描件处理：渲染成图 → 密集表格放大到 ≥350 DPI 再读 → 同一数字交叉核对） |
| 1 | **逐个研究判定方法**（多研究论文可能是质性 + 问卷 + 实验 + 二手数据的组合） |
| 2 | **建立研究地图**（研究数量、各自目标、推进逻辑、方法分布、样本） |
| 3 | **提取变量与假设**（IV / DV / Mediator / Moderator / Control，含概念定义与操作化） |
| 4 | **输出两份产物**：Markdown 报告 + Excel 变量表 |

### 脚本与校验

`scripts/export_codebook.py` 把提取结果（JSON）导出为 Excel，并在导出前做结构校验：

```bash
python3 scripts/export_codebook.py codebook.json --validate    # 只校验
python3 scripts/export_codebook.py codebook.json out.xlsx      # 校验并导出
python3 scripts/export_codebook.py codebook.json --mermaid     # 只打印研究地图源码
```

校验会抓的问题包括：受控词表外的取值、变量名大小写不一致导致跨研究合并断链、
Mermaid 边指向不存在的节点、标注了题项数但题项表为空、信度数值超出 0–1、
分析模型缺假设或命题、计算测量缺模型说明。

> **依赖**：脚本需要 `openpyxl`（`pip install openpyxl`）。其余部分纯文本，无需任何依赖。

## 用法示例

```
这篇论文帮我提取所有变量和它们的操作化信息，要能看出每个量表用了哪些题项、信度多少。
另外给我一份 Excel，我要拿去做元分析编码。
```

技能会判方法分支、建研究地图、逐个变量提取（题项逐字 + 中英对照 + 量尺 + 信度 + 出处），
产出 Markdown 报告与列名固定的 Excel，并在缺口清单里列出原文没写的东西。

## 边界与注意事项

- **不替代精读。** 提取的是结构化信息，论文的论证质量仍需自己判断。
- **不做统计。** 只记录论文报告的结果，不重算、不推断。
- **原文没写的，就是没有。** 报告里会集中列出「信息缺口清单」，而不是用一个看起来合理的数字填上。
- **扫描件靠读图，不靠 OCR。** 密集表格必须放大后再读——实测过：整页读一张结构模型表会读错
  4 个路径系数，放大后才纠正。
- **Excel 列结构会随版本扩展。** 新增字段追加在固定位置之后，旧文件仍可读，但跨版本合并前建议核对列名。
